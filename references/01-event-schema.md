# 事件输入 Schema（Event Schema）

> 本文档定义如何从用户的自然语言描述中提取结构化事件，是整个单人自拍Vlog生成流程的起点。
>
> **核心原则：先确定发生了什么，再设计怎么拍。**

---

## 一、事件 Schema 结构

### 1.1 EVENT 七要素

每条视频必须首先明确以下7个核心要素：

| 要素 | 说明 | 示例 |
|------|------|------|
| **谁 (Who)** | 主角身份，同时也是摄影者和叙述者 | 30岁北漂程序员 |
| **什么时间 (When)** | 具体时间点或时间段 | 周五晚上十点半 |
| **什么地点 (Where)** | 物理空间位置 | 出租屋的书桌前 |
| **正在做什么 (Doing)** | 事件开始时人物的状态 | 刚加班到家，打开冰箱 |
| **遇到了什么 (Encounter)** | 触发事件的契机或冲突 | 发现冰箱里只剩下一盒过期牛奶 |
| **发生了什么变化 (Change)** | 事件过程中的转折 | 突然想起妈妈上周寄来的特产还在快递柜 |
| **最终产生什么情绪 (Emotion)** | 事件结束时人物的情绪落点 | 苦涩又温暖的笑 |

### 1.2 一条视频只能有一个核心事件

允许事件内部存在多个行为，但必须存在一个明确的核心：

> **观众看完以后，能够用一句话说清楚"这条视频发生了什么"。**

**正确示例：**
> 七十四岁的蒲松龄回头看自己一生，发现十九岁就是自己科举人生的顶点。

**错误示例（信息堆积）：**
> 蒲松龄介绍自己、介绍妻子、介绍聊斋、介绍科举、介绍柳泉……

## 二、核心事件提炼方法

### 2.1 提炼步骤

从用户自然语言描述中提取核心事件，遵循以下步骤：

```
用户描述 → 提取关键词 → 找到冲突/转折 → 聚焦一个瞬间 → 一句话总结
```

### 2.2 提炼标准

一个好的核心事件必须满足：

1. **有动作** —— 不是静态介绍，而是正在发生什么
2. **有变化** —— 开始和结束不一样
3. **有情绪** —— 不是冰冷的事实陈述
4. **有聚焦** —— 不贪多，只讲一件事
5. **可感知** —— 观众能在15秒内看懂

### 2.3 一句话公式

核心事件可以套用以下公式检验：

> **[人物] 在 [情境] 中 [做了什么/遇到了什么]，结果 [产生了什么变化/情绪]。**

## 三、价值判断方法

### 3.1 核心问题

事件必须首先判断价值，回答这个问题：

> **观众为什么愿意看？**

不是：
> "这个人物很有意思。"

而是：
> "这个人物的经历能不能让今天的人产生情绪、获得认知、产生共鸣或者觉得有意思？"

### 3.2 七种价值类型

| 价值类型 | 说明 | 典型场景 |
|----------|------|----------|
| **情绪价值** | 让观众产生情绪波动（感动、心疼、暖心、释然等） | 深夜加班接到妈妈的电话 |
| **认知价值** | 让观众获得新知识、新视角、新启发 | 发现一个被忽略的历史细节 |
| **共鸣价值** | 让观众觉得"这不就是我吗" | 社恐人士参加聚会的心理活动 |
| **娱乐价值** | 让观众觉得好笑、有趣、解压 | 笨手笨脚做饭翻车现场 |
| **社会观察价值** | 让观众反思社会现象和群体命运 | 小城市年轻人的出路在哪里 |
| **生活经验价值** | 让观众学到实用的生活技巧或人生经验 | 租房避坑指南（真实踩坑版） |
| **情绪宣泄价值** | 替观众说出他们想说但说不出的话 | 打工人对着空无一人的办公室吐槽 |

### 3.3 价值判断流程

1. 先问：这条视频最主要的价值是什么？（只能选一个主价值）
2. 再问：这个价值对目标观众够不够强？
3. 最后问：有没有办法把价值再聚焦、再放大？

## 四、普适性转化方法

### 4.1 为什么需要普适性

即使人物是历史人物、名人、特殊职业者，也必须翻译成今天的普通人能够理解的情绪。

> **特殊事件 → 普遍情绪**

### 4.2 普适性主题清单

优先选择普通人能够理解的普适性主题：

| 类别 | 主题 |
|------|------|
| **情感关系** | 家庭、婚姻、父母、子女、孤独、陪伴 |
| **生存压力** | 工作、钱、生计、生活压力、面子、人情 |
| **人生状态** | 老去、梦想、失败、遗憾、选择、后悔、尊严 |

### 4.3 转化方法

**第一步：找到具体事件**
> "科举失意"

**第二步：剥离具体外壳，找到内核情绪**
> 一个人在自己最擅长的领域，没有得到想要的结果

**第三步：翻译成现代人能直接感受到的语言**
> **"一个人最擅长的事情，偏偏没有给他想要的人生。"**

### 4.4 转化检验标准

转化后的表述，应该让一个完全不了解背景的人也能立刻产生情绪反应。

## 五、倒叙钩子开篇模式（爆款叙事结构）

### 5.1 为什么需要倒叙钩子

> **核心洞见：观众在前7秒决定要不要继续看。最激烈的情绪放在最前面，而不是按时间顺序平铺。**

40万赞爆款验证：杜甫vlog没有从"我叫杜甫，出生于公元712年"开始，而是从**茅屋被秋风破、南村群童欺我老无力**这个情绪最激烈的名场面直接切入。

**两种开篇模式对比：**

| | 顺序开篇（平） | 倒叙钩子开篇（爆） |
|---|---|---|
| **结构** | 出生→成长→高潮→结局 | 高潮名场面→自我介绍→回到起点展开 |
| **前7秒** | 铺垫信息，观众不知道为什么要看 | 情绪直接拉满，观众好奇"为什么会这样" |
| **留存率** | 前3秒流失严重 | 钩子留住人，后面慢慢展开 |
| **适用** | 短平快的单场景视频 | 一生/长跨度/多场景的人物vlog |

### 5.2 倒叙钩子的三幕结构

```
第一幕（0-7秒）：钩子场 —— 全片情绪最激烈的名场面，直接抛出来
    ↓
第二幕（7-16秒）：身份锚定 —— 人物近景自我介绍，预告"这条视频带你看看我的一生"
    ↓
第三幕（16秒-结尾）：时间线展开 —— 从起点开始按时间顺序推进，直到落幕
```

**第一幕·钩子场的选点标准：**
1. **情绪最极端** —— 选全片情绪峰值（最悲愤/最搞笑/最感动/最震撼）
2. **视觉冲击强** —— 画面有冲击力（狂风/洪水/大火/人群/极端环境）
3. **有悬念感** —— 观众看完会问"怎么搞成这样的？""发生什么了？"
4. **有经典认知** —— 如果是历史人物，优先选观众最熟悉的名场面

**第二幕·身份锚定的标准句式：**
> "大家好，我是[人名]，别人都说我是[标签]。这条视频带你看看我的[主题]。"

作用：让观众从"看戏"切换到"听博主讲故事"的观看模式，建立系列感。

### 5.3 钩子场的自检清单

- [ ] 钩子场是全片情绪最激烈的场景吗？
- [ ] 前7秒有完整的情绪爆发（不是半天才进入状态）
- [ ] 画面有视觉冲击力吗？（极端天气/人群/特殊环境）
- [ ] 看完钩子场观众会好奇"为什么会这样"吗？
- [ ] 钩子场和后面的时间线有呼应关系吗？（比如开篇是茅屋被破，后面再详细讲茅屋怎么建的、怎么被破的）
- [ ] 身份锚定段（7-16秒）有人物近景+自我介绍+预告吗？

> **适用场景：** 人物一生vlog、长跨度故事、多场景叙事（3个场景以上）。单场景短vlog不需要倒叙钩子。

## 六、名场面密度算法（爆款节奏密码）

### 6.1 什么是名场面密度

> **核心洞见：爆款不是"讲完一个故事"，而是"名场面的密集轰炸"。观众每20-30秒就有一个"我知道这个！"的认知爽点。**

**名场面 = 观众有集体记忆的经典瞬间**
- 历史人物：课本里的诗句、典故、著名事件
- 普通人：大家都经历过的生活场景（高考、加班、相亲、毕业）
- 通用认知：耳熟能详的歌曲、电影、网络梗

**杜甫vlog验证：** 170秒7个课本名场面 = 平均24秒一个认知爽点

| 名场面 | 对应诗句/典故 | 出现时间 |
|--------|--------------|----------|
| 茅屋为秋风所破歌 | 八月秋高风怒号 | 0s（开篇钩子） |
| 登泰山 | 会当凌绝顶 | 约40s |
| 追星李白 | 醉眠秋共被 | 约55s |
| 安史之乱 | 朱门酒肉臭路有冻死骨 | 约80s |
| 春望 | 国破山河在 | 约90s |
| 成都草堂 | 安得广厦千万间 | 约115s |
| 江南逢李龟年 | 落花时节又逢君 | 约145s |

### 6.2 名场面密度计算公式

```
名场面密度 = 总时长 ÷ 名场面数量
```

**健康密度区间：** 20-35秒/个
- 低于20秒：太密，观众喘不过气，每个点都没讲透
- 20-35秒：黄金密度，爽点不断又有呼吸空间
- 高于40秒：太疏，观众容易走神划走

**不同时长的名场面数量参考：**

| 视频时长 | 建议名场面数量 | 密度 |
|----------|---------------|------|
| 15秒 | 1个（核心名场面） | 15s/个 |
| 30秒 | 1-2个 | 15-30s/个 |
| 60秒 | 2-3个 | 20-30s/个 |
| 90秒 | 3-4个 | 22-30s/个 |
| 120秒 | 4-5个 | 24-30s/个 |
| 180秒 | 6-8个 | 22-30s/个 |

### 6.3 名场面的三种类型

| 类型 | 说明 | 举例 |
|------|------|------|
| **认知型** | 观众"学过/知道"的经典内容 | 课本诗句、历史事件、著名典故 |
| **情绪型** | 观众"经历过/懂"的普适情绪 | 落榜、失业、被欺负、久别重逢 |
| **梗类型** | 观众"会笑/会转"的网络梗 | 地球online、朋友圈、家人们、谁懂 |

**黄金搭配比例：认知型60% + 情绪型30% + 梗类型10%**

- 认知型负责"哇这个我知道"的认同感
- 情绪型负责"好心疼/好感动"的共情力
- 梗类型负责"哈哈哈太逗了"的传播欲

### 6.4 名场面排布的节奏原则

1. **首尾各一个重磅** —— 开头用最强钩子（倒叙），结尾用最共情的名场面收束
2. **中间波浪式** —— 不要连续两个同类型名场面（认知→情绪→梗→认知→情绪…）
3. **每3个一个小高潮** —— 不要平铺，每2-3个名场面要有一个情绪升级
4. **不要贪多** —— 宁少勿滥，每个名场面要讲透，不能走马观花

### 6.5 名场面自检清单

- [ ] 名场面密度在20-35秒/个的黄金区间吗？
- [ ] 有至少一个认知型名场面（观众"我知道这个"）
- [ ] 有至少一个情绪型名场面（观众"我懂这种感觉"）
- [ ] 有至少一个梗类型名场面（观众"哈哈哈太逗了"）
- [ ] 首尾各有一个重磅名场面吗？
- [ ] 同类型名场面没有连续出现吗？
- [ ] 每个名场面都有足够的情绪展开空间吗？（不是一句话带过）

## 七、从自然语言到结构化事件的提取流程

### 7.1 完整流程图

```
用户自然语言输入
    ↓
提取人物（Who）
    ↓
提取时间地点（When + Where）
    ↓
提取正在做的事（Doing）
    ↓
提取遇到的事/冲突（Encounter）
    ↓
提取变化/转折（Change）
    ↓
提取最终情绪（Emotion）
    ↓
一句话总结核心事件
    ↓
判断主价值类型（7选1）
    ↓
普适性转化检验
    ↓
输出：结构化 EVENT
```

### 7.2 提取技巧

- **如果用户描述很模糊**：主动补全合理细节，但必须基于常识和真实生活逻辑
- **如果用户描述很发散**：抓住最有冲突、最有情绪的那个点，砍掉其余
- **如果用户描述只有画面**：反向推导事件和情绪，让画面有意义
- **如果用户描述只有概念**：找到一个具体的生活场景把概念落地

## 八、事件拆解示例

### 示例1：深夜加班场景

**用户输入：**
> "一个女生深夜加班回家，很累，打开冰箱发现什么吃的都没有，然后突然笑了。"

**结构化提取：**

| 要素 | 内容 |
|------|------|
| 谁 | 28岁都市女白领 |
| 什么时间 | 周五晚上11点 |
| 什么地点 | 出租屋厨房 |
| 正在做什么 | 拖着疲惫的身体打开冰箱找吃的 |
| 遇到了什么 | 冰箱空空如也，只有半瓶矿泉水 |
| 发生了什么变化 | 愣了一下，然后自己被这个状态逗笑了 |
| 最终情绪 | 疲惫中带点自嘲的释然 |

**一句话核心事件：**
> 加班到深夜的女生打开空冰箱，被自己的狼狈逗笑了。

**主价值类型：**
> 共鸣价值 —— 打工人都懂的那种累到哭笑不得的瞬间

**普适性转化：**
> 拼命工作的人，回到家发现连一口热饭都没有，那种心酸又好笑的感觉。

---

### 示例2：历史人物场景

**用户输入：**
> "蒲松龄老年的时候，想起自己年轻时候考科举的事。"

**结构化提取：**

| 要素 | 内容 |
|------|------|
| 谁 | 七十四岁的蒲松龄，布衣老者 |
| 什么时间 | 某个深秋的午后 |
| 什么地点 | 聊斋书房里 |
| 正在做什么 | 翻自己年轻时写的文章 |
| 遇到了什么 | 翻到十九岁第一次考秀才的试卷，那是他科举人生的最高分 |
| 发生了什么变化 | 从翻书的漫不经心，到停下来，到沉默，到苦笑 |
| 最终情绪 | 一生的失意，都在那一笑里 |

**一句话核心事件：**
> 七十四岁的蒲松龄回头看自己一生，发现十九岁就是自己科举人生的顶点。

**主价值类型：**
> 情绪价值 + 认知价值 —— 一个人一生的失意，浓缩在一个瞬间里

**普适性转化：**
> 一个人最擅长的事情，偏偏没有给他想要的人生。

---

### 示例3：生活日常场景

**用户输入：**
> "一个男生在菜市场买菜，遇到以前的老同学，对方混得比他好很多。"

**结构化提取：**

| 要素 | 内容 |
|------|------|
| 谁 | 32岁普通上班族 |
| 什么时间 | 周六上午 |
| 什么地点 | 家附近的菜市场 |
| 正在做什么 | 蹲在地上挑西红柿，在算价格 |
| 遇到了什么 | 抬头撞见大学室友，对方西装革履，带着助理在拍探店视频 |
| 发生了什么变化 | 下意识想躲，犹豫了一下，还是站起来打招呼了 |
| 最终情绪 | 有点尴尬，但也释然了，继续挑自己的菜 |

**一句话核心事件：**
> 菜市场里，一个普通人撞见了人生轨迹完全不同的老同学。

**主价值类型：**
> 共鸣价值 + 社会观察价值 —— 同龄人之间的落差感

**普适性转化：**
> 人到中年，发现身边的人都走得比自己快，那种说不清的滋味。

## 九、事件完整性自检清单

在进入下一步之前，确保事件满足以下全部条件：

- [ ] 七要素完整（谁/时间/地点/做什么/遇到什么/什么变化/什么情绪）
- [ ] 能用一句话说清楚核心事件
- [ ] 只有一个核心事件，没有信息堆积
- [ ] 明确了主价值类型（7选1）
- [ ] 完成了普适性转化
- [ ] 观众看完能产生明确的情绪反应
- [ ] 事件适合用第一人称自拍视角呈现

**多场景/长跨度视频附加检查（3个场景以上）：**

- [ ] 采用了倒叙钩子开篇吗？（最激烈情绪前置）
- [ ] 钩子场是全片情绪峰值且有视觉冲击力
- [ ] 身份锚定段有自我介绍+内容预告
- [ ] 名场面密度在20-35秒/个的黄金区间
- [ ] 名场面类型搭配合理（认知60% + 情绪30% + 梗10%）
- [ ] 首尾各有一个重磅名场面
- [ ] 同类型名场面没有连续出现

> **如果以上有任何一项不通过，回到事件层重新提炼，不要继续往下走。**
