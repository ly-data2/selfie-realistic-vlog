# 分镜时间轴构建（Shot Timeline）

> 本文档定义如何将事件、行为、摄影整合成一条完整的时间轴。
>
> **核心原则：每个时间段必须同时包含叙事动作和摄影动作，二者同时发生。**

---

## 一、时间轴构建方法

### 1.1 推荐结构

每条视频必须先形成时间轴，推荐结构：

> **第0–X秒：事件 + 人物行为 + 自拍摄影**

### 1.2 构建流程

```
确定总时长
    ↓
划分大的时间段（根据事件阶段）
    ↓
为每个时间段填充9要素
    ↓
检查两条动作链是否同步
    ↓
验证切镜原则（行为决定切镜）
    ↓
检查前1秒留存
    ↓
检查身份连续性
```

### 1.3 时长建议

| 视频时长 | 推荐时间段数量 | 说明 |
|----------|----------------|------|
| 10秒 | 2-3段 | 短平快，信息密集 |
| 15秒 | 3-4段 | 最常用，节奏适中 |
| 30秒 | 4-6段 | 有起承转合的空间 |

## 二、智能节奏切分算法（给AI的判断规则）

> **核心原则：时间切片跟着内容节奏走，不机械均分。切片长度由台词长度、动作幅度、情绪浓度三者共同决定。**
>
> **硬约束：只用整数秒，不用小数/毫秒。最短2秒，最长5秒。**

### 2.1 三因素判定法

每个切片的长度，由以下三个因素共同决定，取**最紧的那个因素**决定切片长度：

| 因素 | 短切片（2秒） | 中切片（3秒） | 长切片（4-5秒） |
|------|-------------|-------------|----------------|
| **台词密度** | 短句子（7-12字），语速快 | 中等句子（12-20字），正常语速 | 长句子/停顿/留白 |
| **动作幅度** | 小动作（瞟一眼、嘴角动、翻一页纸） | 中动作（摊手、转头、整理东西） | 大动作（起身、走路、转身） |
| **情绪浓度** | 高（情绪转折点、关键信息点） | 中（叙述推进、普通对话） | 低（情绪留白、余味、思考） |

**判定口诀：**
- 句子短 + 动作小 + 情绪高 → **2秒**（干脆利落）
- 句子中等 + 动作中 + 情绪中 → **3秒**（正常节奏）
- 句子长/停顿 + 动作大 + 情绪低 → **4-5秒**（留白余味）

### 2.2 什么情况用2秒短切片

**使用场景：**
1. **短促的关键台词** — 一句话很短但信息量很大，需要快速打出去
   - 例："家人们，单靠写书养不起家人。"（14字，自嘲点）
2. **微小但重要的动作** — 一个小动作就是一个情绪节拍
   - 例：瞟一眼稿纸、嘴角一撇、喉结滚动一下
3. **情绪转折的节点** — 从一种情绪切换到另一种情绪的瞬间
   - 例：从笑 → 突然沉下来
4. **视线切换** — 看镜头 → 看旁边 → 看回来，每切一次就是一个节拍

**2秒切片的好处：**
- 台词短，唇形更容易对齐
- 节奏密，不拖沓
- 动作和台词绑定紧密，不容易散

**注意事项：**
- 连续2秒切片不要超过3-4个，否则节奏太碎
- 每个2秒切片之间，构图不要剧烈变化（景别大致保持）
- 视线/表情/微动作的变化是2秒切片的主要驱动力，不是景别变化

### 2.3 什么情况用3秒中切片

**使用场景：**
1. **中等长度的台词** — 15-20字左右，正常叙述速度
   - 例："二十八岁回乡教书，三十岁赴宝应做幕僚。"（18字）
2. **边做边说** — 手上有动作，嘴里同时说话，动作和台词各占一部分
   - 例：边整理纸稿边说、边走路边说
3. **情绪平稳的叙述段** — 没有强烈转折，就是在推进内容
4. **一个动作 + 一句话** 的完整小单元

**3秒是默认值。** 拿不准的时候，先用3秒。

### 2.4 什么情况用4-5秒长切片

**使用场景：**
1. **情绪留白** — 话说完了，但情绪还在延续，需要时间消化
   - 例：说完一句沉重的话，沉默1-2秒，低头看纸
2. **大动作完成** — 一个比较大的身体动作需要时间完成
   - 例：从坐着站起来、转身走向门口
3. **长句子 + 停顿** — 一句话比较长，说完后有个呼吸/停顿
4. **开场和收尾** — 开场需要建立氛围，收尾需要余味

**注意事项：**
- 4-5秒的切片里不能只有一句话念完，必须有动作/情绪的变化填充
- 长切片里的画面必须是"活的"，不能是静止的

### 2.5 节奏编排的波浪原则

好的节奏不是均匀的，而是波浪形的：

```
密 → 疏 → 密 → 疏 → 收尾留白
```

**15秒视频的推荐节奏波形：**

| 位置 | 节奏 | 切片长度 | 原因 |
|------|------|---------|------|
| 开头（0-4秒） | 较密 | 2-3秒 | 开场抓人，信息密度高 |
| 中段前半（4-9秒） | 中等 | 2-3秒交替 | 叙述推进，有张有弛 |
| 中段后半（9-13秒） | 最密 | 2秒为主 | 情绪转折/高潮，节拍快 |
| 收尾（13-15秒） | 最疏 | 2秒但留白感强 | 放慢，留余味 |

**反例（均匀切分=无聊）：**
> 4秒 → 4秒 → 4秒 → 3秒 （每段都一样长，没有起伏）

### 2.6 构图连续性铁律

> **不管切片多密，景别和角度不要剧烈跳变。**

| 连续切片之间 | 允许的变化 | 禁止的变化 |
|-------------|-----------|-----------|
| **景别** | 近景 ↔ 中近景（变化小） | 近景 ↔ 全景（跳变） |
| **角度** | 稍微转动（身体带动） | 角度突然大变 |
| **光线** | 同一光线下的微变化 | 光线突然变方向/色温 |
| **构图** | 人物位置小幅偏移 | 人物从左边跳到右边 |

**为什么：** Seedance 2.0 在短切片频繁切换时，如果构图剧烈变化，人物容易变脸、动作容易跳脱。保持构图大致稳定，只靠表情/视线/小动作来区分节拍，人物一致性会好很多。

### 2.7 弹性时长分配原则（核心经验）

> **核心洞见：镜头时长不要平均分配。内容多的给足时间，内容少的就短点。平均分配=重点不突出+过渡太拖沓。**

#### 2.7.1 为什么不能平均分配

**平均分配的问题：**
- 钩子段时间不够，情绪还没建立就切了
- 过渡段时间太长，观众觉得拖沓
- 峰值段时间不够，高潮还没到顶点就过去了
- 收尾段太仓促，没有余韵

**弹性分配的好处：**
- 重点内容给足时间，观众能充分感受
- 过渡内容快速通过，不浪费观众耐心
- 节奏有起伏，像波浪一样有张有弛
- 符合真人Vlog的真实节奏（遇到有趣的就多拍会，赶路就快进）

#### 2.7.2 四类镜头的时长基准

| 镜头类型 | 时长基准 | 说明 | 示例 |
|---------|---------|------|------|
| **钩子/峰值段** | 7-8秒 | 全片最重要的镜头，情绪浓度最高，给足时间 | 第1段钩子、第6段情绪峰值 |
| **场景展示段** | 5-6秒 | 新场景第一次出现，需要时间让观众看够 | 入城第一镜、码头第一镜 |
| **解说/过渡段** | 3-4秒 | 台词解说、场景过渡、信息传递，精简高效 | KPI达标、下一站预告 |
| **收尾/留白段** | 5-6秒 | 情感收束、余韵、留给观众回味 | 赏月收尾、情感落点 |

#### 2.7.3 弹性分配的四条黄金法则

**法则一：钩子和峰值给最多时间**

全片的第一个镜头（钩子）和情绪最高的那个镜头（峰值），一定是时间最长的。
- 钩子段：让情绪充分建立，观众被抓住
- 峰值段：让情绪充分释放，观众感受到高潮

**法则二：过渡和入场尽量短平快**

入场、过渡、转场这些功能性镜头，时间越短越好。
- 入场镜头：快速建立场景，2-4秒够了
- 过渡台词：说完就走，不要拖沓
- 转场预告：一句话带过，3秒以内

**法则三：新场景第一个镜头给足时间**

每个新场景的第一个镜头，时间要比后面的镜头长。
- 观众需要时间"进入"这个新场景
- 第一眼的震撼感需要时间建立
- 环境元素越多，给的时间越长

**法则四：情感收束给时间沉淀**

最后一个镜头，尤其是情感收尾的镜头，时间要充足。
- 话说完了，但情绪还在延续
- 观众需要时间消化和回味
- 收尾留白感比信息量更重要

#### 2.7.4 弹性分配模板（参考）

**15秒3镜头推荐分配：**

| 版本 | 镜头1 | 镜头2 | 镜头3 | 适用场景 |
|------|-------|-------|-------|---------|
| **钩子前置型** | 8秒 | 4秒 | 3秒 | 第一镜是钩子，需要充分建立情绪 |
| **峰值中间型** | 4秒 | 7秒 | 4秒 | 中间是情绪峰值/核心内容 |
| **收尾厚重型** | 4秒 | 4秒 | 7秒 | 收尾是情感落点，需要沉淀 |

**10秒2镜头推荐分配：**

| 版本 | 镜头1 | 镜头2 | 适用场景 |
|------|-------|-------|---------|
| **展示+解说** | 6秒 | 4秒 | 第一镜展示场景，第二镜解说+推进 |
| **冲击+回味** | 4秒 | 6秒 | 第一镜是冲击场面，第二镜是情感落点 |
| **均衡型** | 5秒 | 5秒 | 两段内容相当，没有明显主次 |

#### 2.7.5 分配步骤（实操方法）

**第一步：给每个镜头定性**
- 是钩子/峰值？→ 给最长时间
- 是场景展示？→ 给中等偏长时间
- 是解说/过渡？→ 给较短时间
- 是收尾/留白？→ 给中等偏长时间

**第二步：填入基准时长**
- 按四类镜头的基准填入初步时长
- 15秒的3镜头：比如 8+4+3=15

**第三步：校验总时长**
- 加起来等于总时长吗？
- 差1-2秒，在最不重要的镜头里调整

**第四步：检查节奏波形**
- 是不是波浪形的？（长→短→长 或 短→长→短）
- 有没有连续两个短镜头？（可以有，但不要连续3个）
- 最长的镜头是不是最重要的内容？

#### 2.7.6 判断信号：什么时候该加长，什么时候该缩短

**该加长的信号（满足2条以上就加时间）：**

| 信号 | 说明 | 加多少 |
|------|------|--------|
| 情绪浓度高 | 这一段是情绪峰值或重要转折点 | +1-2秒 |
| 新场景首次出现 | 观众第一次看到这个场景，需要时间消化 | +1-2秒 |
| 环境元素多 | 场景里NPC多、道具多、信息量丰富 | +1秒 |
| 台词有留白 | 话说完了但情绪还在延续，需要沉默时间 | +1-2秒 |
| 有行为链转折 | 人物状态发生明显变化（从走到停、从笑变严肃） | +1秒 |
| 是全片钩子 | 第一个镜头，决定观众要不要继续看 | +2-3秒 |

**该缩短的信号（满足2条以上就减时间）：**

| 信号 | 说明 | 减多少 |
|------|------|--------|
| 纯功能性过渡 | 只是交代"去下一个地方"，没有情绪含量 | -1-2秒 |
| 台词短且密 | 几句话快速说完，说完就走 | -1秒 |
| 场景观众已经看过 | 不是新场景，观众已经熟悉环境 | -1秒 |
| 纯解说无情绪 | 只是传递信息，没有情绪起伏 | -1秒 |
| 预告/转场台词 | "下一站""走"之类的过渡句 | -1-2秒 |

**实战口诀：情绪多加，信息多减；新场景多加，老场景减；钩子多加，过渡减。**

#### 2.7.7 台词字数与时长的对应关系

这是最实用的判断工具——根据台词字数反推最低时长，再加上动作和情绪的时间。

| 台词字数 | 最低说话时长（5字/秒） | 加上动作和情绪 | 建议镜头时长 |
|---------|----------------------|---------------|-------------|
| 10字以内 | 2秒 | +1-2秒动作 | 3-4秒 |
| 10-15字 | 2-3秒 | +2秒动作+情绪 | 4-5秒 |
| 15-20字 | 3-4秒 | +2秒动作+情绪 | 5-6秒 |
| 20-25字 | 4-5秒 | +2-3秒动作+情绪 | 6-8秒 |
| 25-30字 | 5-6秒 | +2-3秒动作+情绪 | 7-9秒 |

**注意：**
- 这是**最低时长**，不是标准时长。情绪重的段落还要再加1-2秒
- 台词密度越高，留给动作和情绪的时间越少，真实感越差
- 如果台词字数已经把时间占满了，说明台词太多了，应该减台词而不是加时长

#### 2.7.8 多段视频的整体节奏波形

超过3段的长视频（比如8段90秒），段与段之间也要有节奏波形，不能每段都是一个节奏。

**8段视频的推荐节奏波形（关汉卿项目实测）：**

```
段1（钩子·15秒）━╮
                 ┃  起：建立钩子，抓住注意力
段2（展示·10秒）─╯
段3（上升·10秒）━╮
                 ┃  承：场景展开，逐步升级
段4（上升·10秒）─╯
段5（低谷·10秒）━╮
                 ┃  转：情绪低谷，为峰值蓄力
段6（峰值·15秒）━╯  ← 全片最高点，给最长时间
段7（缓冲·10秒）━╮
                 ┃  合：从峰值下来，为收尾铺垫
段8（收尾·10秒）─╯  ← 情感收束，给足沉淀时间
```

**节奏设计原则：**
1. **开头钩子+结尾峰值/收尾** — 两头重，中间有起伏
2. **峰值前必须有低谷** — 没有低谷就显不出高峰（如第5段"差点不合格"就是为第6段"严重超标"蓄力）
3. **上升段要有梯度** — 一段比一段更热闹，一段比一段情绪高，不是一下子就到顶
4. **连续两段不要都是最高密度** — 观众会累，需要一段缓冲段来喘口气
5. **收尾段要降速** — 从热闹突然转到安静，反差感更强

#### 2.7.9 常见的时长分配错误

**错误一：平均主义**
```
❌ 15秒 = 5秒 + 5秒 + 5秒
（每段都一样长，没有重点，节奏平）
```

**错误二：头重脚轻**
```
❌ 15秒 = 8秒 + 4秒 + 3秒（但第三段是情感收尾）
（收尾太仓促，情绪还没沉淀就结束了）
```

**错误三：过渡太长**
```
❌ 10秒 = 3秒（入场）+ 4秒（核心）+ 3秒（转场预告）
（功能性镜头占了60%，核心内容只有40%）
```

**错误四：峰值时间不够**
```
❌ 全片情绪最高的段落只给了4秒
（观众情绪刚被调动起来就切了，高潮感完全没出来）
```

**错误五：台词塞太满**
```
❌ 5秒塞了30字台词
（6字/秒已经是上限了，塞太满=嘴型崩+没有动作时间+真实感为零）
```

#### 2.7.10 弹性时长分配案例（关汉卿8段）

| 段落 | 总时长 | 镜头分配 | 分配逻辑 |
|------|--------|---------|---------|
| 第1段·丽正门（钩子） | 15秒 | 8+4+3 | 钩子前置型，第一镜8秒建立认知失调钩子 |
| 第2段·主街 | 10秒 | 6+4 | 展示+解说，新场景第一镜给足时间看环境 |
| 第3段·积水潭 | 10秒 | 6+4 | 展示+解说，码头震撼感需要时间铺陈 |
| 第4段·斜街市 | 10秒 | 5+5 | 均衡型，美食内容前后各半 |
| 第5段·质孙宴（低谷） | 10秒 | 6+4 | 展示+解说，宫殿排面需要时间展现 |
| 第6段·勾栏（峰值） | 15秒 | 4+7+4 | 峰值中间型，中间7秒给情绪最高点 |
| 第7段·骑射场 | 10秒 | 4+6 | 冲击+回味，骏马飞驰冲击力强但短，解说给时间 |
| 第8段·赏月（收尾） | 10秒 | 4+6 | 冲击+回味，登楼快进，情感收束给足时间沉淀 |

**整体节奏波形验证：**
- 第1段（钩子·长）→ 第2-4段（上升·中）→ 第5段（低谷·中）→ 第6段（峰值·最长）→ 第7段（缓冲·中）→ 第8段（收尾·中长）
- 符合"起承转合"的经典节奏结构
- 峰值段在全片约67%的位置（60/90秒），是黄金分割点附近

### 2.8 细切片切分步骤（AI按这个流程来）

> 在弹性时长确定了每个大镜头的时间后，镜头内部的细切片按以下步骤切分。

**第一步：把台词拆成"语义单元"**
- 不是按字数拆，是按"一句话"或"一个意思"拆
- 每个语义单元 = 一句完整的话，或者一个完整的意思表达
- 估算每个语义单元的时长（正常语速：每秒4-5字）

**第二步：给每个语义单元配动作**
- 这句话对应的人物动作是什么？
- 动作是大还是小？
- 动作和台词是同时发生，还是先后发生？

**第三步：按三因素判定法确定每个切片的长度**
- 看台词密度、动作幅度、情绪浓度
- 取最紧的那个因素决定长度
- 全部用整数秒，不用小数

**第四步：检查节奏波形**
- 是不是波浪形的？（密-疏-密-疏）
- 有没有连续4个以上的2秒切片？（太碎了，合并1-2个）
- 有没有连续3个以上的4秒切片？（太慢了，拆细一点）

**第五步：检查构图连续性**
- 相邻切片的景别变化大吗？
- 角度是不是连续变化的？
- 人物在画面中的位置是不是大致稳定？

**第六步：总时长校验**
- 把所有切片加起来，等于总时长吗？
- 如果差1秒，在情绪最淡的那个切片里调整

### 2.9 切分自检清单

- [ ] 所有切片都是整数秒吗？（没有0.5秒、2.5秒这种小数）
- [ ] 最短的切片不短于2秒吗？
- [ ] 最长的切片不长于5秒吗？
- [ ] 每个切片都有动作+台词+情绪吗？（不是只有台词）
- [ ] 节奏是波浪形的吗？（不是均匀均分）
- [ ] 连续2秒切片不超过4个吗？
- [ ] 相邻切片构图变化小吗？（景别、角度没有跳变）
- [ ] 台词均匀打散了吗？（不是前半段塞满后半段空）
- [ ] 收尾有留白感吗？（不是戛然而止）
- [ ] 总时长加起来正确吗？

## 二点五、场景切换节奏（爆款核心规律）

> **核心洞见：视觉节奏不靠运镜带，靠场景切换带。一段一场景，场景即节奏。**
>
> **爆款公式 = 多场景快切 + 每段一个正在发生的事 + 视觉不重复**

### 2.5.1 为什么场景切换比运镜更重要

**之前的认知：** 15秒视频在一个场景里，靠运镜变化（推/拉/摇/侧）来制造视觉节奏。

**爆款实测认知：** 15秒视频如果只在一个场景里，无论怎么运镜，观众都会觉得"画面单调"。真正的视觉节奏来自**场景本身的变化**。

| | 单场景运镜法 | 多场景切换法 |
|---|---|---|
| **视觉变化来源** | 运镜推拉摇移 | 场景本身不同 |
| **观众感受** | "同一个人在一个地方说话" | "这个人正在经历不同的事" |
| **节奏来源** | 运镜节奏 | 场景切换节奏 |
| **信息量** | 低（背景不变） | 高（每段新环境新信息） |
| **真实感** | 中等 | 高（真Vlog就是走到哪拍到哪） |

### 2.5.2 场景切换的三个原则

**原则一：一段一场景，视觉不重复**

每段时间段对应一个独立的场景。两个时间段不能在同一个地点。

**贺知章爆款示例（13段13场景）：**
```
家→船→考场→官署→太常寺→泰山→曲江→东宫→酒馆→送别→村口
```

每段视觉完全不同：家里的床、船上的水、考场的人群、官署大门、泰山祭坛、曲江柳树……观众永远不会觉得"画面单调"。

**原则二：场景切换 = 叙事推进**

场景不是随机选的，每换一个场景，故事就往前推进一步。

| 场景 | 叙事推进 |
|------|---------|
| 家 | 小时候的贫困（铺垫） |
| 船 | 离家赶考（转折） |
| 考场 | 考中状元（高潮1） |
| 官署 | 做官升迁（推进） |
| 泰山 | 封禅大典（高潮2） |

> **切场景 = 切叙事阶段。** 不是为了好看而切，是故事走到了新阶段。

**原则三：场景和台词内容绑定**

每段的场景必须和台词内容强绑定。不能在考场说家里的事，不能在酒馆说做官的事。

| 场景 | 台词内容 | 绑定关系 |
|------|---------|---------|
| 船上 | "船开了，师傅慢点，书要掉水里了" | 在船上 → 船晃 → 书差点掉 |
| 曲江 | "你们看这柳叶……二月春风似剪刀" | 在柳树下 → 看到柳叶 → 随口吟诗 |
| 酒馆 | "掌柜的，金龟拿去，这顿酒我请" | 在酒馆 → 没带钱 → 金龟换酒 |

### 2.5.3 15秒能切几个场景？

**取决于视频总时长和每段的最短时长。**

| 总时长 | 推荐场景数 | 每段平均时长 | 说明 |
|--------|-----------|-------------|------|
| 10秒 | 2-3个 | 3-5秒 | 短平快 |
| 15秒 | 3-4个 | 3-5秒 | 最常用 |
| 30秒 | 5-7个 | 4-6秒 | 有叙事空间 |

**15秒切3-4个场景是最佳实践。** 少于3个会单调，多于4个会太碎。

### 2.5.4 场景切换的写法

**在Prompt里，场景切换用"时间码 + 新场景描述"来标识：**

```
0到3.5秒：[场景A描述] + [人物在场景A中的动作和台词]

3.5到7.0秒：[场景B描述] + [人物在场景B中的动作和台词]

7.0到11.0秒：[场景C描述] + [人物在场景C中的动作和台词]

11.0到15.0秒：[场景D描述] + [人物在场景D中的动作和台词]
```

**关键：场景描述不需要很长，一两句话点明地点+环境特征即可。** 场景细节靠参考图控。

### 2.5.5 场景切换节奏波形

场景切换也有节奏，不是均分的：

```
密（快建立）→ 中（叙述推进）→ 密（高潮/转折）→ 疏（收尾留白）
```

**15秒3场景推荐波形：**
- 第1段（0-5.0秒）：较长，建立场景和人物
- 第2段（5.0-10.0秒）：中等，推进叙事
- 第3段（10.0-15.0秒）：较短，收尾留余味

**15秒4场景推荐波形：**
- 第1段（0-3.5秒）：快建立
- 第2段（3.5-7.0秒）：推进
- 第3段（7.0-11.0秒）：高潮/转折，稍长
- 第4段（11.0-15.0秒）：收尾

### 2.5.6 场景切换的Seedance适配

**Seedance 2.0对场景切换的支持：**

- ✅ 15秒直出可以包含2-3个场景切换
- ✅ 场景切换用时间码 + 新场景描述来标识
- ⚠️ 4个以上场景切换风险较高，人物一致性压力大
- ⚠️ 如果场景切换后人物变脸 → 上传人物参考图 + 开启人物一致性锁

**降低风险的写法：**
- 场景切换时，用"他走到……""他来到……"做过渡，不是硬切
- 切换后的第一个动作要简单（走路、站定、看环境），给模型时间建立新场景
- 切换后的人物景别和上一个场景保持一致（比如都是胸像），降低变脸概率

### 2.5.7 场景切换自检清单

- [ ] 15秒内有至少2个不同场景吗？
- [ ] 每个场景视觉不重复吗？（不是同一个地方的不同角度）
- [ ] 场景切换和叙事推进绑定吗？（切场景 = 切故事阶段）
- [ ] 场景和台词内容绑定吗？（在什么场景说什么话）
- [ ] 场景切换有过渡吗？（不是硬切）
- [ ] 切换后人物景别和上一段一致吗？（降低变脸概率）

## 二点六、服装/外形破败曲线（无声叙事）

> **核心洞见：人物的外形变化是无声的叙事。观众不用听台词，光看衣服从新到旧、从整到破，就知道这个人经历了什么。**

40万赞爆款验证：杜甫从少年蓝袍（崭新）→中年绿袍（官服体面）→草堂绿袍（略有磨损）→晚年破绿袍（多处补丁破洞）→洪水时破衣赤足（几乎遮体），6个阶段的服装变化=他的人生下坡曲线，比台词更有力量。

### 2.6.1 外形曲线 = 人物命运的视觉化

台词说"我这一生很苦"是抽象的。但观众亲眼看到一个人从衣着光鲜到衣衫褴褛，那种冲击力是台词的10倍。

**作用：**
1. **无声叙事** —— 不用解释，观众自己能"读"出人物经历了什么
2. **阶段感** —— 每个剧情阶段对应一个外形状态，帮助观众定位"现在是哪个阶段"
3. **共情力** —— 看着一个人一步步变糟，观众会产生"眼看着他走下坡路"的心疼感
4. **真实感** —— 人的外形会随生活状态变化，一成不变=不真实

### 2.6.2 外形破败五段曲线（走下坡路型）

适用于：命运多舛、一生潦倒、由盛转衰的人物（杜甫、蒲松龄、落难才子等）

| 阶段 | 服装 | 发型/胡须 | 肤色/体态 | 精神状态 | 对应剧情 |
|------|------|-----------|-----------|----------|----------|
| **阶段一：意气风发** | 新衣、颜色鲜亮、面料好 | 整齐、有光泽 | 面色红润、体态挺拔 | 眼神有光、自信 | 少年/青年得志时期 |
| **阶段二：初入社会** | 略有褶皱、颜色稍暗 | 基本整齐 | 略带疲惫 | 有干劲但有点迷茫 | 刚开始工作/考试时期 |
| **阶段三：遭受打击** | 有磨损、袖口领口起毛 | 有点乱、不那么讲究了 | 有点憔悴、瘦了 | 眼神有失落但还撑着 | 第一次失败/挫折时期 |
| **阶段四：长期潦倒** | 有补丁、颜色褪得厉害、多处破损 | 花白、凌乱、长了不剪 | 面黄肌瘦、背有点驼 | 麻木、认命、但还有底线 | 长期穷困/漂泊时期 |
| **阶段五：绝境边缘** | 破烂不堪、遮不住身体、赤脚 | 全白、打结、脏 | 枯瘦、皱纹深、眼神空洞 | 虚弱、随时可能倒下 | 绝境/临终时期 |

**杜甫vlog对应验证：**

| 年龄段 | 外形阶段 | 画面特征 |
|--------|----------|----------|
| 少年（漫游时期） | 阶段一 | 蓝袍、意气风发、登泰山 |
| 中年（做官时期） | 阶段二→三 | 绿袍官服、朝堂上还算体面 |
| 50岁（草堂被破） | 阶段四 | 破绿袍、白须、多处补丁 |
| 58岁（洪水围困） | 阶段五 | 破衣赤足、枯瘦、白头巾 |

### 2.6.3 外形曲线的设计方法

**第一步：确定人生曲线方向**
- 走上坡路：越来越体面（底层逆袭型）
- 走下坡路：越来越破败（命运多舛型）
- 波浪形：起起落落（大起大落型）
- 平稳型：基本不变但有细节变化（日常vlog型）

**第二步：划分剧情阶段**
- 按人生节点划分（少年/青年/中年/晚年）
- 按事件节点划分（得志/受挫/谷底/反弹/终局）
- 每个阶段对应一个外形状态

**第三步：设计五个维度的变化**

| 维度 | 变化方向（下坡路） | 变化方向（上坡路） |
|------|-------------------|-------------------|
| **服装** | 新→旧→破→烂 | 旧→新→好→精致 |
| **发型胡须** | 整齐→凌乱→花白→全白 | 随便→整齐→讲究→有型 |
| **肤色体态** | 红润→憔悴→面黄肌瘦→枯瘦 | 瘦削→结实→富态→威严 |
| **配饰道具** | 有→少→无→只有一根拐杖 | 无→有→多→精致配饰 |
| **精神状态** | 有光→迷茫→麻木→空洞 | 黯淡→有希望→自信→从容 |

**第四步：控制变化速度**
- 不要突变：两个场景之间外形不能跳变太大
- 渐变原则：每个阶段比上一个阶段"更糟/更好"一点点
- 关键事件可以加速变化（比如战乱之后明显衰老）

### 2.6.4 注意事项

1. **Seedance适配：** 用参考图约束人物外形，每个大的外形阶段用一张参考图。不要在同一段Prompt里让外形剧烈变化（AI容易失控）。
2. **不要只靠服装：** 发型、肤色、体态、精神状态的变化同样重要，甚至更重要。脸的变化比衣服的变化更有冲击力。
3. **细节比整体更戳人：** 袖口磨破了、鞋上有泥、指甲缝里有灰——这些小细节比"衣服很破"更真实。
4. **反向曲线同样有效：** 逆袭类故事可以用"从破到新"的外形曲线，观众同样有爽感。

### 2.6.5 外形曲线自检清单

- [ ] 每个人生阶段有对应的外形状态吗？
- [ ] 外形变化是渐变的吗？（不是突然跳变）
- [ ] 五个维度都设计了吗？（服装/发型/肤色/配饰/精神）
- [ ] 关键事件之后有明显的外形变化吗？
- [ ] 外形变化和人物命运曲线一致吗？
- [ ] 有细节设计吗？（袖口/鞋/指甲/配饰等小细节）
- [ ] Seedance适配：每个大阶段有对应的参考图吗？

## 三、微表情节奏学（高级）

> **核心洞见：人类表情不是开关，是渐变的。写Prompt的人如果不懂这个，AI生成的人物就会像瞬间切换贴图一样生硬。**
>
> 本章是进阶内容，用于提升情绪戏的真实感和人物一致性。

### 3.1 微表情渐进原理

**错误认知：** 表情是"从A跳到B"的开关式变化
- 第2秒：平静
- 第2.1秒：愤怒（瞬间变了）

**真实生理：** 表情是肌肉慢慢收紧/放松的渐进过程
- 第0-1秒：平静
- 第1-2秒：眉头开始下压，嘴角微微绷紧（蓄力）
- 第2-3秒：肌肉持续收紧，下颌咬紧，鼻翼微张（接近顶点）
- 第3-3.7秒：爆发，眼神锐利，声线抬升（释放）
- 第3.7-4秒：稍微回落，稳住表情（收尾）

**为什么AI经常表情生硬：**
> 你只写了"他很生气"，没写"他怎么变生气的"。AI不知道肌肉是慢慢绷紧的，它直接给你一张"生气的脸"。

**正确的写法：**
不要写结果，写过程。
- ❌ 不好："他变得很愤怒"
- ✅ 好："眉头慢慢下压，嘴角一点点绷紧，下颌越咬越紧，最后眼神锐利起来"

---

### 3.2 蓄力-爆发模型

一套完整的情绪曲线有三层节奏：

```
压抑蓄力（慢）→ 触发释放（快）→ 稳住收尾（渐停）
```

**这是比例关系，不是精确的时间节点。** 不要在Prompt里写"前X秒蓄力，后Y秒爆发"——模型不会精确卡那个点。

| 阶段 | 大致占比 | 特征 | 唇形压力 |
|------|---------|------|---------|
| **蓄力期** | 前半段偏多 | 肌肉慢慢绷紧，情绪积累，微表情渐变 | 很小（可能不说话） |
| **爆发期** | 中段偏短 | 情绪触发，台词出口，生理反应同步 | 较大（有台词） |
| **收尾期** | 尾部留一点 | 情绪稍微回落，表情稳住，留余味 | 很小（沉默） |

**怎么用：**
把整个情绪过程写成一段连续的描述，不要切成"第几秒到第几秒是蓄力"。
让模型自然地从"慢慢绷紧"过渡到"开口说话"再过渡到"表情稳住"。

**写法模板：**
```
[片段整体时长，比如3.7秒]：[人物状态]，[表情慢慢变化的过程描述]，[开口说台词时的生理反应]，[说完后表情的收尾]
```

**示例（蒲松龄·悲愤情绪 · 3.7秒）：**
```
他眉头慢慢下压，嘴角一点点绷紧，下颌越咬越紧，眼神从平静变得锐利，身体微微前倾，然后开口说："十九岁那年就用完了。"声音发沉，鼻翼微张，颈肌收紧，说完后轻轻吐气，嘴角有一丝无奈的笑意，表情慢慢稳住。
```

> **重点：** 把"慢慢变→爆发→稳住"写成一个连续的过程，用"慢慢""渐渐""然后""说完后"这些词来引导节奏，而不是写精确的时间点。

---

### 3.3 情绪片段的黄金窗口

**情绪片段不是越短越好，也不是越长越好，有一个黄金区间。**

| 如果太短（<2.5秒） | 如果太长（>4.5秒） |
|-------------------|-------------------|
| 蓄力时间被压缩，肌肉来不及逐步收紧 | 蓄力时间过长，画面容易"发呆" |
| AI直接跳到"爆发脸"，丢失强忍的拉扯感 | 人物僵住不动，模型容易面部漂移 |
| 没有层次感，像瞬间切换贴图 | 长时间同一表情，五官发生变化 |

**黄金窗口：3–4秒**
- ✅ 足够长，让面部肌肉逐步收紧的微动作能展现
- ✅ 足够短，不会让画面静止，避免面部漂移
- ✅ 刚好容纳一套完整的情绪曲线（蓄力→爆发→收尾，收尾≥0.5秒）

> **注意：** 具体秒数（3.5/3.7/3.8）不是精确到毫秒的剪辑点，是**节奏暗示**——告诉模型"这是一个连续的情绪过程，给我平滑过渡，不要硬切"。小数位精确到0.5秒就够了，再细没有意义。

### 3.4 小数秒的真正作用（重要认知更新）

**核心认知：小数秒是整体节奏暗示，不是精确剪辑点。**

**正确理解：**
- 写 `0–3.7秒` 的意思是："这是一个大约3.7秒的连续过程，给我平滑过渡，不要粗暴切分"
- 不是说："请在第3.7秒那个精确帧点上结束"

**为什么需要小数秒？**
- 整数秒（0–3秒）给模型的感觉是"这是一段3秒的内容，差不多就行"
- 小数秒（0–3.7秒）给模型的感觉是"这是一个连续的过程，要把整段时间都用满做渐变"
- 效果就是：表情变化更平滑，不会提前停住发呆

**可以用任意小数吗？**
- ✅ 可以是2.6、3.2、3.7、3.8——任意小数都可以
- ✅ 小数位越"不整齐"，暗示"平滑过渡"的效果越强
- ❌ 但不要用0.1秒以下的片段做内部切分（比如"最后0.3秒如何如何"），模型感知不到

**一条重要的分界线：**
- ✅ **片段整体时长用小数秒** → 有意义，是节奏暗示
- ❌ **片段内部再拆小数微切片** → 没有意义，模型不会精确卡那些点

**什么时候用小数秒：**
- ✅ 情绪渐变的片段（蓄力→爆发→收尾是一个连续过程）
- ✅ 微表情丰富的段落
- ✅ 需要"呼吸感"的留白和收尾
- ❌ 纯叙述、纯动作的段落（用整数秒就行）

**一句话总结：**
> 整体用小数，内部不切片。用文字引导节奏，不用时间码卡节点。

### 3.5 句尾锚点模型（核心认知刷新）

**重要：这不是"台词后置"，是"很早就开口，但情绪爆发点在句尾"。**

两种思路的本质区别：

| | 思路A（错误理解） | 思路B（正确方案·句尾锚点） |
|---|---|---|
| 开口时机 | 后半段才开口 | **很早就开口（约0.6秒建立表情后）** |
| 表情变化时机 | 开口前表情就变完了 | **开口后表情先保持不变，读到句尾关键词才爆发** |
| 唇形压力分布 | 短时间集中爆发 | 长时间对口型但表情稳定 |
| 人脸漂移风险 | 中等（前半段无嘴部运动） | **低（大部分时间表情稳定+正常说话唇形）** |
| 真实感 | 像舞台表演（憋很久才说） | **像真实的人（边说边憋，最后绷不住）** |

#### 核心原理

```
0.6s 建立基础表情 → 随即开口说话 → 前面大部分台词维持原表情（只动嘴）→ 读到句尾锚点词时情绪爆发
```

**为什么这么设计：**

1. **真实感更强** — 现实中压抑的人不会憋很久才说话，而是一边说一边慢慢积蓄张力，直到句尾绷不住
2. **人脸漂移风险低** — 唇形任务占用整段大部分时长，但面部AU/核心情绪在绝大多数台词里保持稳定，仅在句尾局部突变
3. **0.6秒刚刚好** — 足够把基础表情建立到位，又不会空太久导致画面呆滞

#### 写法模板

```
[片段整体时长，比如3.7秒]：
[人物基础状态，先建立0.6秒左右的表情基准]，
随即开口说："[一整句台词，比较长]"，
[前面大部分台词时，面部维持原表情，只做正常说话的唇形]，
说到"[句尾锚点词]"时，[情绪爆发的生理反应：鼻翼张开/颈肌收紧/身体前探/声音变调]，
说完后，[表情收尾，留余味]
```

#### 示例（蒲松龄·悲愤情绪 · 3.7秒）

```
他眉头慢慢下压，嘴角一点点绷紧，下颌越咬越紧，建立起压抑的表情，
随即开口说："回头一看，我这辈子的科场好运，十九岁那年就用完了。"
前面说话时面部维持压抑的紧绷感，只动嘴唇，
说到"十九岁那年就用完了"时，鼻翼微张，颈肌收紧，身体微微前探，声音发沉，情绪在句尾爆发出来，
说完后轻轻吐气，嘴角有一丝无奈的笑意，表情慢慢稳住。
```

> **关键点：** 很早就开口，但情绪爆发、AU切换、生理动作，绑定在句子最后的关键词上。
> 前面一大段台词，面部表情不变，只有正常说话的唇形运动。

#### 怎么找句尾锚点词

不是所有词都能当锚点，锚点词需要满足：
- ✅ 是整句话的**情绪最高点**或**转折点**
- ✅ 读出来的时候**有力量感**（重音、停顿、声调变化）
- ✅ 放在句子的**后半段或末尾**

示例：
- "单靠写书**养不起家人**" → 锚点：养不起家人
- "十九岁那年**就用完了**" → 锚点：就用完了
- "看透官场浮华与**百姓苦难**" → 锚点：百姓苦难
- "聊斋女子身上依稀可见**她的模样**" → 锚点：她的模样

### 3.6 情绪曲线的9种基本模式

| 模式名称 | 曲线形状 | 适用场景 | 蓄力:爆发:收尾 |
|---------|---------|---------|--------------|
| **蓄力爆发** | 慢升快降 | 愤怒、激动、惊喜 | 6:3:1 |
| **慢慢沉落** | 慢降平稳 | 悲伤、失落、回忆 | 4:4:2 |
| **渐入佳境** | 慢升慢降 | 微笑、释然、温暖 | 5:3:2 |
| **瞬间愣住** | 快升慢降 | 惊讶、错愕、震惊 | 1:6:3 |
| **强忍泪水** | 平稳波动 | 隐忍、克制、感动 | 7:2:1 |
| **自嘲一笑** | 快升快降 | 自嘲、无奈、苦笑 | 3:4:3 |
| **若有所思** | 缓慢起伏 | 思考、回忆、犹豫 | 4:2:4 |
| **轻轻叹气** | 慢升快降慢收 | 叹息、无奈、接受 | 5:2:3 |
| **眼神柔化** | 缓慢下降 | 温柔、思念、爱意 | 6:2:2 |

> **提示：** 不用死记这些模式。写的时候问自己一个问题：
> "这个人的情绪是怎么来的？慢慢上来的，还是突然上来的？怎么下去的？突然收住，还是慢慢散掉？"
> 把这个过程写出来，就是对的。

### 3.7 微表情写作自检清单

- [ ] 表情是渐变的，不是瞬间切换的吗？
- [ ] 写了肌肉怎么变化的过程吗？（眉头慢慢下压、嘴角一点点绷紧……）
- [ ] 有蓄力期吗？（情绪不是一上来就拉满）
- [ ] 有收尾期吗？（情绪爆发后有一点点稳住的时间）
- [ ] 用了句尾锚点模型吗？（很早就开口，但情绪爆发点在句尾关键词上）
- [ ] 前面大部分台词时面部表情保持稳定吗？（只动嘴唇，AU不切换）
- [ ] 句尾锚点词找到了吗？（情绪最高点/转折点，在句子后半段）
- [ ] 情绪曲线有层次吗？（不是全程一个表情）
- [ ] 小数秒用对了吗？（暗示连续性，不是卡剪辑点）
- [ ] 运镜很克制吗？（不和面部表演抢注意力）

## 四、每个时间段必须包含的9个要素

每个时间段必须同时回答以下9个问题，缺一不可：

| 序号 | 要素 | 说明 | 检验问题 |
|------|------|------|----------|
| 1 | **发生什么** | 事件层面的进展 | 这一段时间里，故事推进了什么？ |
| 2 | **人物做什么** | 具体的物理动作 | 人物的手、脚、身体在做什么？ |
| 3 | **人物怎么说** | 台词内容和方式 | 人物说了什么？语气语速如何？ |
| 4 | **情绪怎么变化** | 情绪的流动 | 从什么情绪变成什么情绪？ |
| 5 | **人物看哪里** | 视线方向 | 看镜头？看旁边？看远处？看手上？ |
| 6 | **手机在哪里** | 摄影位置和角度 | 什么距离？什么角度？什么景别？ |
| 7 | **手机为什么发生移动** | 摄影因果 | 是人物什么动作带动了手机？ |
| 8 | **光线如何** | 环境光状态 | 什么光？从哪来？什么色温？ |
| 9 | **环境有什么声音** | 声音层次 | 环境底噪？行为声？人声？ |

> **关键：9个要素必须同时存在于每个时间段中，不能缺项。**

## 四、两条动作链

### 3.1 叙事动作与摄影动作

每个分镜必须同时拥有两条动作链：

| 动作链 | 负责什么 | 核心问题 |
|--------|----------|----------|
| **叙事动作** | 故事推进 | 发生了什么？人物做了什么？ |
| **摄影动作** | 让观众看到故事 | 画面怎么变化？观众看到了什么？ |

### 3.2 核心公式

> **叙事动作 → 摄影动作**

叙事动作是因，摄影动作是果。

**而不是：**
> 摄影动作 → 强行寻找叙事内容

不能先想"我要一个推镜"，然后给推镜找理由。
必须先想"人物会做什么动作"，然后这个动作自然产生了画面变化。

### 3.3 两条动作链的同步检验

| 检验项 | 通过标准 |
|--------|----------|
| 因果关系 | 每个摄影变化都能找到对应的叙事动作触发 |
| 时间同步 | 摄影动作慢半拍跟随叙事动作，不是同时也不是相反 |
| 强度匹配 | 动作大，镜头变化就大；动作小，镜头变化就小 |
| 节奏一致 | 叙事节奏快，镜头变化就快；叙事节奏慢，镜头变化就慢 |

## 五、切镜原则

### 4.1 行为决定切镜

镜头切换不能机械按照时间均分：
> 0–3秒 / 3–6秒 / 6–9秒

而应该根据以下变化触发：

| 触发类型 | 说明 | 示例 |
|----------|------|------|
| **行为变化** | 人物从一个动作变成另一个动作 | 从站着变成走路、从说话变成沉默 |
| **情绪变化** | 人物情绪发生明显转折 | 从笑变成沉默、从平静变成激动 |
| **空间变化** | 人物位置或环境发生变化 | 从室内走到室外、从胡同走到大街 |
| **信息变化** | 新的信息点出现 | 看到了什么东西、想到了什么事 |

> **原则：行为决定切镜。**

### 4.2 切镜时机

- 在动作最大的那个瞬间切（动作遮罩）
- 在情绪转折点切
- 在视线转移的瞬间切
- 在一句话说完的间隙切

### 4.3 避免的切镜方式

- 机械的时间均分切镜
- 一句台词换一个镜头（见下节）
- 没有原因的跳切
- 为了"丰富画面"而频繁切镜

---

## 六、一个时间段不等于一个镜头

### 5.1 核心概念

一个时间段内部可以有多个自然的画面变化，这些变化不一定是切镜。

**示例：**
> 第0–5秒：人物在胡同口说话。

内部可以包含：
> 站着 → 看招牌 → 说话 → 笑 → 转身 → 往里走。

因此5秒内可能存在：
> 自拍近景 → 身体转动 → 环境进入 → 行走自拍

### 5.2 变化的两种类型

| 变化类型 | 说明 | 触发方式 |
|----------|------|----------|
| **自然变化** | 人物行为带动的画面变化，不是切镜 | 人物转头、转身、前倾、行走 |
| **切镜** | 时间或空间上的跳跃，是剪辑 | 时间跳转、场景切换、角度跳变 |

### 5.3 原则

- 优先用自然变化，少用切镜
- 能用人物行为完成的画面变化，就不要切镜
- 切镜是最后的手段，不是默认选项

> **真实自拍是连续的，不是剪辑出来的。**

---

## 七、台词绝不堆镜头

### 6.1 核心原则

**不要：**
> 一句台词换一个镜头。

### 6.2 正确方式

台词应该允许人物：
> 边走边说、边翻书边说、边整理东西边说。

这样才是真人。

### 6.3 台词与镜头的关系

| 错误模式 | 正确模式 |
|----------|----------|
| 台词1 → 镜头1 | 人物做动作 → 边做边说 → 动作带动画面变化 |
| 台词2 → 镜头2 | 一句话可能跨越多个画面变化 |
| 台词3 → 镜头3 | 一个长镜头里可能说了好几句话 |

### 6.4 检验标准

如果你把台词去掉，画面中的人物行为仍然是合理的、连续的，那就是对的。
如果你把台词去掉，画面就变得莫名其妙，那就是错的。

## 八、前1秒留存锁

### 7.1 核心原则

> **前约1秒必须出现有效信息。**
>
> **第一秒让观众知道"为什么值得继续看"。**

### 7.2 有效信息的类型

第一秒可以出现以下任意一种：

| 类型 | 说明 | 示例 |
|------|------|------|
| **信息** | 直接给出关键信息 | "我今天发现了一件事..." |
| **冲突** | 呈现矛盾或冲突 | 空冰箱 + 人物错愕的表情 |
| **反常识** | 打破观众预期 | 七十四岁老人在玩智能手机 |
| **情绪** | 强烈的情绪状态 | 眼睛红红的，刚哭过 |
| **悬念** | 引起好奇心 | 人物神秘地说"你猜怎么着" |
| **人物身份** | 特殊的人物身份 | 穿着古装的人出现在现代街头 |
| **真实行为** | 有趣的真实动作 | 笨手笨脚地打翻了东西 |

### 7.3 禁止出现的情况

前1秒禁止长时间：
> 走路 → 看镜头 → 没有信息。

观众没有耐心等你铺垫。

### 7.4 留存锁检验

- [ ] 第1秒结束时，观众已经获得了某种有效信息
- [ ] 这个信息足以让观众想继续看下去
- [ ] 不是"先走路再说"的拖沓开场
- [ ] 第一帧画面就有内容，不是空的或模糊的

## 九、身份连续性

### 8.1 人物身份连续性

人物身份必须严格保持一致，除非剧情明确要求时间变化：

| 要素 | 连续性要求 |
|------|------------|
| 五官 | 不能变 |
| 脸型 | 不能变 |
| 发型 | 不能变 |
| 发色 | 不能变 |
| 年龄 | 不能变 |
| 体型 | 不能变 |
| 服装 | 不能变 |
| 配饰 | 不能变 |

**禁止：** 不同镜头之间人物突然变年轻、变胖、换脸、换发型、换服装。

### 8.2 场景连续性

连续镜头必须保持以下一致，除非剧情明确发生场景变化：

| 要素 | 连续性要求 |
|------|------------|
| 地点 | 同一地点 |
| 时间段 | 同一时间段 |
| 光线逻辑 | 同一光线逻辑 |
| 人物 | 同一人物 |
| 服装 | 同一服装 |
| 道具 | 同一道具 |
| 空间关系 | 同一空间关系 |

### 8.3 连续性检验方法

在时间轴上，把相邻时间段的人物/场景描述放在一起对比，看是否一致。
如果有变化，必须有明确的剧情原因（比如"换了一件衣服"必须是因为剧情里人物换了衣服）。

## 十、15秒视频完整时间轴示例

### 示例：深夜空冰箱

**总时长：** 15秒
**核心事件：** 加班到深夜的女生打开冰箱，发现空空如也，被自己的狼狈逗笑了。
**主价值：** 共鸣价值 —— 打工人的心酸与自嘲

---

**时间段1：第0-2秒 —— 钩子：打开空冰箱**

| 要素 | 内容 |
|------|------|
| **发生什么** | 女生加班回到家，打开冰箱找吃的 |
| **人物做什么** | 伸手拉开冰箱门，身体微微前倾 |
| **人物怎么说** | （还没说话，只有冰箱门打开的声音） |
| **情绪怎么变化** | 疲惫 → 期待 → 错愕 |
| **人物看哪里** | 看冰箱内部 |
| **手机在哪里** | 举在胸前，胸部以上景别，28mm |
| **手机为什么发生移动** | 人物前倾开门，手机跟着身体微微前倾，画面略微变紧 |
| **光线如何** | 厨房暖黄灯，冰箱内部的冷光映在脸上 |
| **环境有什么声音** | 冰箱门打开的声音、冰箱压缩机的嗡嗡声、远处的车流声 |

**前1秒检验：** 第1秒时冰箱门已经打开，观众看到空冰箱 + 女生错愕的表情 —— 有冲突、有悬念，通过。

---

**时间段2：第2-5秒 —— 反应：从错愕到无奈**

| 要素 | 内容 |
|------|------|
| **发生什么** | 发现冰箱是空的，情绪变化 |
| **人物做什么** | 愣住，手还扶着冰箱门，然后站直身体，手放下来 |
| **人物怎么说** | （没说话，吸了一口气） |
| **情绪怎么变化** | 错愕 → 无奈 → 有点想笑 |
| **人物看哪里** | 看冰箱 → 移开视线看地面 → 抿嘴 |
