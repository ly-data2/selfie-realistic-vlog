# Seedance 2.0 适配指南（官方文档校准版 V2.0）

> 本文档基于[火山引擎官方提示词指南](https://www.volcengine.com/docs/82379/2222480?lang=zh)及[最佳实践](https://seedance2.tech/docs/prompt-writing-guide)重新校准。
>
> **核心原则：用官方推荐的分镜顺序写，用官方符号系统标注，优先正面描述，负面约束作为补充。**

---

## 一、Seedance 2.0 真实能力边界（官方校准）

### 1.1 模型擅长什么（要多用）

| 能力 | 官方依据 | 运用方式 |
|------|---------|---------|
| **多场景转场** | 官方示例用"镜头1/2/3"组织不同场景 | 用分镜顺序写，每镜可换场景 |
| **多角色台词口型** | 官方示例有NPC台词 `{考得怎么样呀，过了吗}` | 用 `{台词}` 标注，每镜可含多角色对话 |
| **NPC出场互动** | 官方示例有"舍友们追着打闹起来" | NPC可以出场、说话、互动 |
| **环境动态变化** | 官方示例有"山风卷起衣摆和尘土" | 描述环境元素的动态变化 |
| **情绪连续转变** | 官方示例"先低头落寞→抬头憋不住笑意→哈哈大笑" | 用分镜写情绪渐变过程 |
| **人物一致性** | 官方推荐用 `@图片N` + 大头照锁定 | 人物锚点前置 + 参考图绑定 |
| **手持自拍质感** | 模型对"自拍视角""手持感"理解准确 | 开头声明自拍视角 |
| **光影写实** | 模型对具体光线方向理解力强 | 用具体光线术语（侧光/逆光/暖黄） |
| **文字生成** | 官方支持字幕、气泡等文字 | 用 `【字幕内容】` 标注 |
| **音频同步** | 模型生成同步音频 | 用 `<>` 标音效、`（）`标音乐 |

### 1.2 模型需要注意的方面（风险递减）

| 方面 | 官方依据 | 注意事项 |
|------|---------|---------|
| 精确时间码 | 官方："模型对精确时间支持不稳定" | 粗粒度时间码（5秒级节点）通常可行，细粒度（1-2秒级）风险较高。口型崩时优先改镜头顺序 |
| 高爆发动作 | 官方："尽量规避狂奔、大跳、剧烈翻滚等高爆发、大动态动作" | 用低缓连续动作（缓慢行走、轻轻抬手） |
| 多种运镜叠加 | 官方："一个镜头里尽量只指定1种运镜方式" | 每镜选1种运镜（推/拉/摇/移/固定） |
| 超长文本 | 最佳实践："两三句话，清楚比长好" | 精简有助于降低注意力预算压力，但结构清晰的长文本仍可执行 |
| 负面堆叠 | 最佳实践："长列表的no xxx往往适得其反" | 优先正面描述，负面约束作为补充。数量与总信息密度相关，非绝对上限 |
| 人物ID漂移 | 官方FAQ专章讨论 | 用参考图锁定+提示词前置锚定。多张参考图标注清晰时不必然漂移 |

## 二、官方提示词公式

### 2.1 官方进阶公式

```
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

简化记忆版（5层）：

```
Subject → Action → Camera → Style → Constraints
```

### 2.2 官方推荐的分镜时序写法

**核心规则：** 用"镜头1/镜头2/镜头3"按事件顺序组织，不强制限制每段时长，让模型根据剧情自然生成节奏。

每个镜头按以下逻辑组织：
1. **运镜或镜头切换方式** — "中景缓慢推近""固定机位""镜头切至…"
2. **主体动作与表情** — 核心角色的关键动作、神态变化
3. **位置或空间变化** — 场景、位置或空间关系
4. **音频信息** — 音效、人声或背景音乐

**官方正面示例：**
```
镜头1：街巷侧拍，男人缓慢起跑，带有急促的呼吸感。
镜头2：男人撞翻水果摊，镜头快速摇动并给到男人惊恐的特写。
镜头3：男人翻过矮墙消失，镜头缓慢拉远定格在空荡的街道。
```

### 2.3 官方实战示例（多场景+多NPC+情绪转变）

官方示例1（宿舍情感短剧）包含：
- 3个分镜，场景从走廊→室内
- NPC台词：`{考得怎么样呀，过了吗}`
- 情绪转变：落寞→憋不住笑意→哈哈大笑
- NPC互动：`舍友们追着打闹起来`

官方示例2（古风悬崖对手戏）包含：
- 3个分镜，场景切换
- 双角色对峙
- 环境动态：`山风卷起衣摆和尘土`
- 情绪转变：漫不经心→冷冽

## 三、特殊字符系统（官方规范）

| 信息类型 | 符号 | 示例 |
|---------|------|------|
| **台词** | `{}` | `{家人们，深夜了，我还在写}` |
| **音效** | `<>` | `<远处传来狗叫声>` |
| **音乐** | `（）` | `（背景中播放着轻柔的古琴曲）` |
| **字幕** | `【】` | `【1640年 淄川 书香人家】` |
| **参考图引用** | `@图片N` | `@图片1中的蒲松龄` |
| **参考视频** | `@视频N` | `参考@视频1的运镜方式` |
| **参考音频** | `@音频N` | `背景音效与@音频1同步` |

## 四、主体定义规范（官方写法）

### 4.1 单主体定义

```
将@图片1中穿旧青布长衫、戴黑色方巾的中年男人定义为主体1
```

核心要求：使用2-3个清晰、稳定的静态特征（服饰、发型、外观）进行描述。

### 4.2 多主体定义

```
将@图片1中穿旧青布长衫的中年男人定义为主体1，将@图片2中穿白裙的女子定义为主体2
```

### 4.3 后续指代规则

定义后必须持续使用同一标签：
- 定义为"主体1"后，后续都用"主体1"指代
- 不要中途换成"他""蒲松龄"等指代
- 每次涉及主体时需明确指代，避免省略

### 4.4 参考图最佳实践

| 素材类型 | 数量 | 说明 |
|---------|------|------|
| 角色锚定图（大头照） | 1张 | 仅面部，无表情最佳，无肩颈背景干扰 |
| 角色全身照 | 1张 | 锁定服装、体型 |
| 场景参考图 | 1张 | 锁定环境风格 |
| 运镜参考视频 | 1段 | 锁定镜头语言 |
| 音频参考 | 1段 | 锁定氛围节奏 |

总计4-5个素材为最佳实践建议值（省注意力预算），官方硬上限为9张。多角色/多场景可适当增加到6-7张，每张需写明用途和禁止事项。不要使用人物多视图（会导致ID漂移）。

## 五、Seedance 提示词黄金结构（V2.0）

### 5.1 正确的顺序

```
【第1位·权重最高】素材引用 + 主体定义 + 场景锁定
    ↓
【第2位】拍摄形式声明（自拍视角 + 质感）
    ↓
【第3位】分镜时序（镜头1/2/3，每镜含：运镜+动作+场景+音频）
    ↓
【第4位·权重最低】画质风格 + 约束条件（5-8条）
```

### 5.2 完整结构模板

```
参考@图片1中的[人物特征]锁定人物一致性：固定脸型、五官比例、眼睛、鼻子、嘴唇、肤色、发型、发量、年龄感，禁止五官漂移、脸型变形、换脸。@图片2作为[场景]仅用于场景结构、环境氛围、建筑布局，禁止将参考图内行人作为主角。

主体1本人手持手机前置自拍视角，即是拍摄者也是叙述者。一臂手持距离，广角前置镜头轻微畸变，vlog纪实抓拍质感。镜头运动完全来自身体移动：呼吸带来画面微弱浮动；转身时身体先动，镜头惯性滞后跟随。人物移动时自动曝光轻微波动，白平衡小幅自然偏移。笑意先从眼部、嘴角浮现，再缓慢扩散到全脸。口型变化联动眼睑、眉毛、鼻翼、脸颊肌肉，非独立嘴部运动。

镜头1：[运镜方式]，主体1[核心动作+表情]，[场景位置]。[音频信息]。{台词}。
镜头2：[运镜方式]，主体1[核心动作+表情变化]，[场景位置变化]。[音频]。{台词}。
镜头3：[运镜方式]，主体1[核心动作+情绪转变]，[场景位置]。[音频]。{台词}。

高清，[色调风格]，[光影描述]，[画质约束]。[3条核心约束条件]。
```

### 5.3 动作描述要求（官方四要素）

每个动作必须包含：**肢体部位 + 幅度 + 速度 + 力度**

| 要素 | 说明 | 示例 |
|------|------|------|
| 肢体部位 | 具体到头/手/肩/眼/嘴 | 右手手指 |
| 幅度 | 微小/中等/明显 | 微微 |
| 速度 | 缓慢/快速/突然 | 缓慢 |
| 力度 | 轻/重/用力 | 轻轻 |

完整示例：`右手手指轻轻攥紧衣角`、`嘴角缓慢上扬一点`、`肩膀微微颤抖`

### 5.4 情绪外化表达（官方对照表）

| 抽象情绪 | 外化为动作与细节 |
|---------|----------------|
| 悲伤 | 低头、肩膀微微颤抖、眼眶泛红、手指无意识地攥紧衣角、泪水在眼眶里打转但没有落下 |
| 喜悦 | 嘴角抑制不住地上扬、眉眼舒展、脚步变得轻快、下意识地哼起小曲 |
| 紧张/焦虑 | 频繁地看手表、手指不停敲击桌面、呼吸急促、眼神闪躲 |
| 愤怒 | 双拳紧握、下颌线紧绷、胸口剧烈起伏、眼神如刀般锐利、从牙缝里挤出话语 |
| 释然 | 长长地舒了一口气、紧绷的肩膀完全放松下来、脸上露出久违的淡淡的微笑 |

## 六、自拍Vlog适配规则

### 6.1 自拍视角声明（简化版）

放在主体定义之后，用2-3句话声明：

```
主体1本人手持手机前置自拍，即是拍摄者也是叙述者。一臂手持距离，画面有自然手持微晃。
```

不要长篇大论解释自拍逻辑，用正面声明代替负面禁令。

### 6.2 镜头变化写法（动作暗示镜头）

用人物身体动作带动镜头变化，不写抽象镜头规则：

| 人物动作 | 镜头变化描述 |
|---------|-------------|
| 身体前倾 | 手机随身体靠近，画面变紧 |
| 身体后靠 | 手机随身体远离，画面扩展 |
| 转身 | 手机跟着身体自然转动 |
| 走路 | 轻微上下起伏，自然手持感 |

### 6.3 多场景转场写法

在15秒单次调用内，可以用分镜实现多场景转场：

```
镜头1：主体1在[场景A]，[动作]。
镜头2：镜头切至[场景B]，主体1[动作]。
镜头3：主体1走到[场景C]，[动作]。
```

每镜换一个空间，但人物保持一致（靠参考图锁定）。

### 6.4 NPC出场写法

NPC可以用分镜引入：

```
镜头2：主体1走到村口茶摊，一个路过的商人坐下，商人笑着问{老板，茶免费喝？}，主体1点头。
```

NPC不需要参考图锁定时，用简单特征描述即可。

## 七、负面约束写法（官方校准）

### 7.1 核心原则

最佳实践明确："长列表的no xxx往往适得其反。描述你想要什么，而不是列举你害怕什么。"

### 7.2 只保留5-8条

按场景定制，不要通用堆叠：

**自拍Vlog通用约束（6条）：**
```
保持无字幕，不要生成水印Logo，人物面部稳定不变形，无多余手指，无第三人称视角，无美颜磨皮
```

**按场景追加1-2条：**
- 号舍场景：`无室外阳光直射`
- 村口场景：`无室内元素`
- 暴风雨场景：`无晴天光线`
- 落幕场景：`无明亮光线`

### 7.3 用正面描述替代负面

| 负面写法（弱） | 正面写法（强） |
|--------------|--------------|
| 不要第三人称视角 | 主体1本人手持手机前置自拍 |
| 不要稳定器 | 画面有自然手持微晃 |
| 不要美颜 | 真实皮肤带毛孔纹理 |
| 不要电影大片感 | 原生手机前置直出质感 |
| 不要朗诵腔 | 生活化聊天语气 |

## 八、微表情节奏与句尾锚点（保留，与官方兼容）

> 以下内容基于实测经验，与官方"情绪外化表达"和"动作过渡衔接"规则兼容。

### 8.1 蓄力-爆发模型

一套完整的情绪曲线分三层：

```
压抑蓄力（长）→ 触发释放（短）→ 稳住收尾
```

写法：不要写情绪结果，写肌肉运动过程。
- ❌ "他变得很愤怒"
- ✅ "眉头慢慢下压，嘴角一点点绷紧，下颌越咬越紧"

### 8.2 句尾锚点

开口很早，但情绪爆发点在句尾：

```
0.6秒建立基础表情 → 随即开口 → 大部分台词维持原表情 → 句尾锚点词时情绪爆发 → 收尾留余味
```

### 8.3 情绪曲线9种基本模式

| 模式 | 适用场景 | 蓄力:爆发:收尾 |
|------|---------|--------------|
| 蓄力爆发 | 愤怒、激动、惊喜 | 6:3:1 |
| 慢慢沉落 | 悲伤、失落 | 4:4:2 |
| 渐入佳境 | 微笑、释然、温暖 | 5:3:2 |
| 瞬间愣住 | 惊讶、错愕 | 1:6:3 |
| 强忍泪水 | 隐忍、克制、感动 | 7:2:1 |
| 自嘲一笑 | 自嘲、无奈、苦笑 | 3:4:3 |
| 若有所思 | 思考、犹豫 | 4:2:4 |
| 轻轻叹气 | 叹息、无奈、接受 | 5:2:3 |
| 眼神柔化 | 温柔、思念 | 6:2:2 |

## 九、最佳实践（官方+第三方综合）

### 9.1 生成策略

1. **一次生成2-3个版本** — 视频模型是概率性的，第二个或第三个往往是最好的
2. **一次只改一个变量** — 不通过时，只改prompt/参考图/运镜/时长中的一个
3. **先短后长** — 先用5秒验证构图和人物，确认后再加长到15秒
4. **先低后高** — 先用低分辨率验证，通过后再升分辨率

### 9.2 台词规则

- 台词总耗时不超过段时长上限
- 单句控制在15-20字以内
- 语速留出呼吸和停顿
- 台词语言统一，避免中英文混用（专有名词除外）
- 用 `{台词内容}` 格式标注

### 9.3 素材配置策略

功能角色分四种：
1. **角色锚定** — 锁定角色外观（大头照+全身照）
2. **场景定调** — 锁定环境与风格
3. **运镜参考** — 锁定镜头语言与动作节奏
4. **节奏氛围** — 用音频控制情绪、音色

推荐总计4-5个素材，不建议用满上限。

### 9.4 视频延长 vs 分段拼接

| 方式 | 适用场景 | 说明 |
|------|---------|------|
| 连续长镜头（视频延长） | 单场景文戏、长对话、情绪递进 | 沉浸式一镜到底 |
| 分段拼接 | 剧情转折、快切、蒙太奇 | 独立生成再剪辑 |

实际制作通常结合两种方式。

## 十、完整示例（V2.0格式）

### 蒲松龄书房自拍 · 15秒

```
@图片1中的穿旧青布长衫、戴黑色方巾、须发半白的中年男人定义为主体1。@图片2作为清代书房场景风格参考。

主体1本人手持手机前置自拍，即是拍摄者也是叙述者。一臂手持距离，画面有自然手持微晃。

镜头1：中近景固定，主体1坐在书案前，右手放下笔，抬头看向镜头，嘴角带着淡淡的倦意笑意，身后是昏暗的书房，油灯映在脸上明暗交替。{家人们，深夜了，我还在写。} <油灯噼啪声>

镜头2：主体1微微凑近镜头，压低声音，嘴角扯出一丝苦笑，眼眶微微泛红，身后暗处隐约可见一个白裙女子侧影站在墙边不动。{别怕，我身边经常有人。} <窗外风声>

镜头3：主体1拿起桌上茶碗喝了一口，视线越过茶碗看镜头，表情从苦笑慢慢转为平静，身后角落又隐约出现一个老者身影站在书架旁低着头。{别人怕鬼，我攒鬼。我叫蒲松龄，别人写诗，我写鬼。} <茶碗碰桌声，毛笔滚落声>

高清，低饱和暖黄冷调，油灯暖光为主四周偏暗，明暗对比强烈，原生手机前置直出质感。保持无字幕，不要生成水印Logo，人物面部稳定不变形，无多余手指，无美颜磨皮，无第三人称视角。
```

## 十一、实测翻车点（V2.1新增 — 基于蒲松龄vlog镜头1生成评估）

> 以下5条经验来自实际生成视频的逐帧评估（15秒、720x1280、24fps、15帧采样）。
>
> 每条经验包含：现象、规律、Prompt修复方向。

### 翻车点1：手部是AI视频的死亡线

**现象：** 每一帧有手部精细动作的画面都出现了不同程度的崩坏——握笔手指关节错位、攥衣角手指数量异常、持茶碗手指穿透碗壁。

**规律：** 手部精细动作是高崩坏风险区域。3次以上精细手部动作会显著增加崩坏概率，但不必然导致全面失败。风险与模型版本、参考图质量、动作复杂度都有关。

**Prompt修复方向：**
- 写字场景：优先用"右手搁在纸旁，手指微蜷"
- 喝茶场景：优先用"右手轻搭在茶碗边沿"
- 攥衣角：优先用"右手搭在胸前衣襟上"
- 原则：**优先用低风险动作词（搭/搁/轻放），高风险词（握/执/拿/攥）在参考图充足时仍可尝试**

### 翻车点2：服装描述必须精确到款式

**现象：** "红衣女子"被生成为现代蕾丝吊带睡裙，与清代书房场景严重违和。

**规律：** 只写颜色不写款式，模型会用训练数据里该颜色最常见的形象——大概率是现代服装。古装场景+现代服装=沉浸感断裂。

**Prompt修复方向：**
- ❌ "红衣女子" → ✅ "穿红色高领宽袖长裙的古装女子"
- ❌ "白衣女子" → ✅ "穿白色交领齐腰襦裙的古装女子"
- ❌ "白面书生" → ✅ "穿白色圆领袍的年轻书生"
- ❌ "绿裙女子" → ✅ "穿绿色对襟褙子的古装女子"
- 原则：**每个NPC必须写明：颜色 + 领口样式 + 袖口样式 + 裙袍类型**

### 翻车点3：超自然元素需要物理锚点

**现象：** "悬浮在空中的猫"没有视觉解释，看起来像bug不像超自然。"飘进来的女子"缺少运动轨迹，像突然出现。

**规律：** AI不能区分"应该悬浮的猫"和"错误的悬浮"。没有物理锚点的超自然元素会被当成品控问题。

**Prompt修复方向：**
- ❌ "悬浮在空中" → ✅ "倒挂在房梁上尾巴垂下来"
- ❌ "飘进来" → ✅ "从窗户飘进来脚不沾地裙摆拖在地面"
- ❌ "出现一个身影" → ✅ "从暗处走出来轮廓从模糊变清晰"
- ❌ "白狐变成女子" → ✅ "白狐四肢缓慢收拢身体拉长，皮毛褪去露出皮肤变成女子"
- 原则：**超自然变化必须写明变化过程（起点→过渡→终点），不能只写结果**

### 翻车点4：元素密度与质量成反比

**现象：** 最后一帧有5个角色+2只猫+2个鬼影，每个主体的渲染质量都明显下降——面部塑料感加重，手部崩坏加剧，透明度处理不自然。

**规律：** 单帧主体超过4个，每个主体的渲染质量都在下降。超过6个开始出现明显的质量断崖。

**Prompt修复方向：**
- 每镜头对话NPC保持1个
- 背景NPC（不说话）不超过2个
- 超自然元素（变身/悬浮/幽灵等）每镜头不超过3个
- 如果剧情需要更多角色，拆到不同镜头里，不要堆在一帧

### 翻车点5：自拍手势与古风场景冲突

**现象：** 前伸手臂的自拍姿态在古代场景里产生"时空错位感"——观众看到古人在自拍，沉浸感被打破。

**规律：** 自拍视角的"手臂前伸"在古风场景里会强化"假"的感觉。现代自拍手势+古代服装=认知冲突。

**Prompt修复方向：**
- 不强调手臂前伸，写"画面从人物下巴角度拍摄"代替"手持手机自拍"
- 或写"手机搁在书案上竖着拍，人物坐在桌前"——固定机位自拍
- 或写"画面微微仰视，从人物胸口高度拍摄"——暗示手持但不强调手臂
- 原则：**自拍视角用"拍摄角度"描述，不用"手臂前伸"描述**

## 十二、实测最佳写法速查（V2.1）

### 动作描述低风险/高风险词

> 风险等级基于实测经验，非绝对。参考图充分锁定时，高风险词也可执行。

| 动作类型 | 高风险词 | 低风险词 |
|---------|---------|---------|
| 手部 | 握、执、拿、攥、捏 | 搭、搁、轻放、微蜷 |
| 书写 | 执笔在纸上移动 | 右手搁在纸旁 |
| 喝水 | 拿起茶碗喝一口 | 右手轻搭在茶碗边沿 |
| 情绪 | 攥紧衣角 | 右手搭在胸前衣襟上 |
| 移动 | 狂奔、大跳 | 缓慢行走、微微侧身 |
| 转头 | 快速转头 | 缓慢转头 |

### NPC服装描述模板

```
穿[颜色]+[领口：高领/交领/圆领/对襟]+[袖口：宽袖/窄袖]+[服装类型：长裙/袍/褙子/襦裙]的[身份]
```

### 超自然变化描述模板

```
[起点状态] → [过渡过程：身体部位+变化动作+速度] → [终点状态]
```

示例：白狐四肢缓慢收拢 → 身体拉长皮毛褪去 → 露出皮肤变成穿红色高领宽袖长裙的女子

## 十三、信息密度天花板与拆段法则（V2.2新增 — 基于二次生成实测）

> 以下7条经验来自第二批生成视频的逐帧评估，核心发现：**单段视频的信息密度有参考上限，超出后模型可能降级执行。但这是参考线非硬天花板，不同模型版本、参考图配置、提示词结构下浮动较大。**

### 13.1 单段信息密度参考线

**规律：** 15秒单段建议不超过2个场景+2个说话人+3-4句台词。超出这个范围，模型可能降级执行策略：优先执行画面大框架，牺牲细节层（口型同步、微表情、精确时序）。但"降级"不等于"崩坏"——结构清晰、参考图充分时超出范围仍可执行。

**参考线（非硬限制）：**

| 维度 | 参考线 | 高风险线 |
|------|--------|---------|
| 场景数 | ≤2个 | ≥3个 |
| 说话人 | ≤2人 | ≥3人 |
| 台词句数 | ≤4句 | ≥5句 |
| 台词字数（15秒） | ≤30字 | ≥50字 |
| 微表情指令 | ≤5条 | ≥10条 |
| 身体动作指令 | ≤5条 | ≥10条 |
| 特效幻化 | 独占1段 | 与台词同段 |
| 时间锚点 | ≤2个/段 | ≥3个/段 |

### 13.2 多说话人切换是最大翻车点

**规律：** 单段内3个说话人频繁切换会显著增加口型不同步风险。风险程度与台词总字数、切换频率、参考图锁定质量相关。短台词+充分锁定的3说话人配置不必然失败。

**后果：**
- NPC台词变成画外旁白（模型放弃口型同步）
- 蒲松龄多句台词被合并为连续概述（模型跳过说话人切换）
- 书生台词保留但缺少回应（模型只执行了一个说话人）

**修复方向：** 如需多说话人对话，**优先拆段**。每段只1个说话人，NPC台词和蒲松龄回应分到不同镜头。

### 13.3 微表情与高密度台词互斥

**规律：** 当Prompt同时包含大量台词和大量微表情时，模型注意力被台词时序分配消耗殆尽，微表情执行率趋近于零。

**修复方向：** 微表情应作为低密度段落的点缀，而非高密度段落的叠加。台词密集的段落只保留2-3条最高价值微表情。

### 13.4 精确时间锚点是双刃剑

**规律：** 时间锚点帮助模型理解顺序，但过密的时间锚点（每2-3秒一个节点）反而会让模型重新组织时序，导致错乱。模型的时间感知是模糊的——它理解"先做什么再做什么"的顺序，但无法精确到"第5秒开始说第4句话"。

**修复方向：** 粗粒度时间锚点（如5秒一个节点）通常可行。3个5秒级锚点在结构清晰时可以执行。细粒度锚点（每1-2秒一个）风险较高。

### 13.5 竖屏+多台词需额外谨慎

**规律：** 竖屏（9:16）本身就有更高的字幕和胡言乱语风险，叠加大量台词时更应控制信息密度。

**修复方向：** 竖屏每段台词控制在25-30字以内。竖屏+多说话人切换+复杂特效=最高风险组合，应拆段处理。

### 13.6 特效幻化与台词不要同段

**规律：** 白狐幻化为红衣女子这个特效本身消耗大量模型注意力，如果同段还有台词需要口型同步，两者互相干扰。

**修复方向：** 复杂幻化特效与口型同步同段会争抢注意力预算。简单视觉特效（光影变化、雾气）与台词同段通常无碍。是否拆段取决于特效复杂度。

**正确结构：**
```
镜头1：[幻化特效独占，无台词]
镜头2：[幻化完成后，角色对话]
```

### 13.7 模型升级不解决架构性问题

**规律：** 模型升级提升的是时长上限和素材容量，对"单段内信息过载"问题无实质改善。架构性问题只能通过拆段解决。

**结论：** 不要指望模型升级来消化过载的Prompt。正确的做法是：**在Prompt架构层面控制信息密度，通过拆段解决复杂场景。**

## 十四、拆段决策树（V2.2新增）

当Prompt出现以下任一信号时，建议评估是否拆段。拆段是降低风险的有效手段，但不是唯一手段——更充分的参考图、更清晰的结构、更精简的台词也能补偿：

```
场景数 ≥ 3？ → 考虑拆段
说话人 ≥ 3？ → 考虑拆段
台词字数 > 30字（15秒段）？ → 减台词或拆段
特效幻化 + 台词同段？ → 考虑拆段（复杂幻化独占一段）
微表情指令 > 5条？ → 建议精简
时间锚点 > 3个/段？ → 建议精简
```

### 拆段示例

**原版（超载，1段15秒）：**
```
镜头1：白狐幻化成女子 + 女子说话 + 蒲松龄说话 + 巨蛇遮月
镜头2：书生幻化 + 书生说话 + 蒲松龄回应 + 鬼影抢书
镜头3：聂小倩飘进来 + 小倩说话 + 蒲松龄说话 + 小鬼倒挂
```
→ 3场景 + 3说话人 + 6句台词 + 2个特效 = 高风险组合，实测中全面崩坏。减少任一维度可显著降低风险

**拆段版（安全，3段各15秒）：**
```
第1段·镜头1：白狐幻化成女子（特效独占，无台词）
第1段·镜头2：蒲松龄说话 + 女子在身旁不说话
第2段·镜头1：书生幻化（特效独占，无台词）
第2段·镜头2：书生说话 + 蒲松龄回应
第3段·镜头1：聂小倩飘进来（无台词）
第3段·镜头2：小倩说话 + 蒲松龄回应
```
→ 每段2场景 + 1-2说话人 + 2-3句台词 = 安全

## 十五、Seedance执行率九维框架（V3.0 — 官方最佳实践对照版）

> 基于30秒12镜头水下短片（完美执行）与15秒3镜头蒲松龄钩子（多次崩坏）的对照分析，提炼出影响执行率的9个维度。**九维同时优化，执行率才能从30%拉到80%以上。**

### 对照案例

| 维度 | 水下短片（完美） | 蒲松龄钩子（崩坏） |
|------|----------------|------------------|
| 台词 | 0句 | 6句 |
| 说话人 | 0人 | 3人切换 |
| 口型同步 | 不需要 | 需要3人逐帧口型 |
| 微表情 | 0条（情绪靠肢体+眼睛状态） | 20条（嘴角/眼眶/法令纹…） |
| 情绪表达 | 状态化（黑点眼圆睁） | 过程化（嘴角一点点上扬→眼眶泛红→眉头微皱） |
| 每镜头时长 | 2-3秒（极短） | 5-6秒 |
| 镜头切换 | 硬切（每次切是全新镜头） | 缓推/横移（连续镜头内塞多事件） |
| 同时发生的事 | 每镜1-2件 | 每镜4-6件 |
| 环境描述 | 开头一次，后续不重复 | 每镜重复 |
| 负面约束 | ~3条 | 10+条 |
| 总字数 | ~1500字 | ~1800字 |

### 15.1 信息密度

**规律：** 15秒单段信息密度有参考上限。超出后模型可能降级执行，优先保画面大框架，牺牲口型/微表情/时序。但"降级"不等于"崩坏"，结构清晰+参考图充分时超出参考线仍可执行。

**参考线：** ≤2场景 + ≤2说话人 + ≤4句台词 + ≤30字（15秒段）

### 15.2 指令数量

**规律：** 每条指令占用注意力预算。指令越多，每条分到的预算越少，执行率越低。

**参考线（经验估算，误差±30%）：** 微表情约5条，身体动作约5条，负面约束约3条（低密度段可更多），总指令约20条/段。超出不必然失败，但风险递增。

### 15.3 计算复杂度

**规律：** 不同指令的计算成本差异巨大：
- 物体层（谁在画面里）：成本最低，执行率~100%
- 空间层（在哪里、多大）：成本低，执行率80-90%
- 动作层（做什么动作）：成本中，执行率60-70%
- 口型层（嘴唇和语音同步）：成本高，执行率30-50%
- 微表情层（眼眶泛红、法令纹收紧）：成本极高，执行率10-20%

**优化方向：** 判断每条指令属于哪个层级，确保核心需求不在最容易被牺牲的层。Vlog的台词属于口型层（高成本），必须单独拆段给足预算。

### 15.4 指令冲突

**规律：** 当两条指令在同一画面中互相矛盾时，模型不是选一个执行，而是尝试同时执行，结果两个都做不好。

**检查清单：**
- "手持晃动" vs "画面稳定" = 互斥
- "多人同框对话" vs "口型同步" = 互斥（多人切换时）
- "特效幻化" vs "口型同步" = 互斥（两者争抢预算）
- "低头写字" vs "抬头看镜头说台词" = 互斥（同一时间不能两个动作）

**优化方向：** 写Prompt时检查同一时间段内的指令是否存在物理矛盾，有则拆到不同镜头。

### 15.5 抽象层级

**规律：** 模型对不同层级指令执行率差异极大（见15.3）。越细粒度的指令越容易在预算紧张时被丢。

**优化方向：**
- 情绪表达尽量"状态化"不要"过程化"
  - ❌ 过程化："嘴角一点点上扬→眼眶缓慢泛红→眉头微皱"（逐帧渐变，成本极高）
  - ✅ 状态化："眼眶泛红，嘴角扯出苦笑"（状态锚点，一次执行）
- 只在低密度段落（无台词或台词极少）使用微表情
- 台词密集段落只保留2-3条最高价值状态锚点

### 15.6 时序分配模糊性

**规律：** 模型理解"先做什么再做什么"的顺序，但不理解"第5秒做这件事"。时间感知是相对的，不是绝对秒数。

**安全线：**
- 用"镜头1/镜头2"标明顺序和节奏，不写精确秒数
- 每段时间内的"需要精确同步的事件"越少越好
- 每段时间锚点不超过2个

**危险信号：** 当时间锚点过密时（每2-3秒一个节点），多个"大概在什么时候"互相干扰，导致时序错乱。

### 15.7 参考素材与Prompt的分工

**规律：** 参考图传递"长什么样"（形象、场景、光线），Prompt文字传递"做什么"（动作、台词、情绪）。当两者分工清晰时效率最高。Prompt里重复描述参考图已包含的信息时，白白消耗预算却不增加画面信息。

**分工原则：**
- 参考图负责：人物外貌、服装款式、场景风格、光线基调
- Prompt文字负责：动作、台词、情绪、运镜、时序
- **不要在Prompt里重复参考图已经锁定的信息**

**反面示例：** 旧版每段都重写"烛光从右侧照来，右半脸暖光"——开头定一次即可，参考图也包含光线信息。重复三次浪费三条指令的预算。

### 15.8 画面比例惩罚

**规律：** 9:16竖屏的注意力效率天然低于16:9横屏。竖屏画面纵向更长，人物占画面比例更大，模型需要在更小的画面面积里处理同样多的细节。同时竖屏训练数据量少于横屏，模型竖屏生成能力偏弱。

**补偿策略：** 把竖屏当作"隐形扣分项"，在其他维度上适当降低密度来补偿。竖屏每段台词控制在25-30字以内，说话人≤2人，微表情≤3条。

### 15.9 负面约束的隐藏成本

**规律：** 每条负面约束占用注意力预算，但不产生任何画面信息。它们的作用是"防止模型犯错"，但防的往往是预算紧张时才犯的错。预算充足时这些错本身不容易出现，负面约束价值递减；预算紧张时负面约束反而挤占正面画面的预算。

**参考线：** 负面约束数量与总信息密度负相关。低密度段可容忍8-10条负面约束，高密度段建议精简到3-5条。没有绝对上限，每条负面约束都有预算成本。

**核心3条（高密度段优先保留）：**
```
保持无字幕，不要生成水印Logo，人物面部稳定不变形
```

其余负面约束（无多余手指、无美颜磨皮、无第三人称视角等）在预算充足时模型通常不会犯，可以省略。

## 十七、景别-表情-情绪匹配原则（V5.0新增）

> **核心逻辑：景别越近，表情越细，情绪越强。三者必须同步递进，不能错配。**

### 17.1 三段式景别的情绪功能

| 时间段 | 景别 | 表情粒度 | 情绪强度 | 适合写什么 |
|--------|------|---------|---------|-----------|
| 第0-5秒 | 中近景（胸部以上） | 粗粒度 | 弱→中 | 打招呼、场景建立、人物出场、开场状态 |
| 第5-10秒 | 近景（肩以上） | 中粒度 | 中→强 | 对话互动、情绪推进、情节发展 |
| 第10-15秒 | 特写（面部为主） | 细粒度 | 强→最强 | 金句独白、情绪爆发、核心观点、收尾余韵 |

### 17.2 错配的典型问题

| 错配类型 | 表现 | 为什么不好 |
|---------|------|-----------|
| **开场就特写** | 第0秒直接怼脸，没有环境交代 | 观众不知道在哪、发生了什么，代入感弱 |
| **结尾还中景** | 最后5秒还在胸部以上，情绪没推上去 | 金句/情绪高潮没有视觉加持，冲击力弱 |
| **中景写微表情** | 中近景里写"眼眶泛红、嘴角微微抽动" | 景别太远，微表情看不见，写了也白写 |
| **特写写大动作** | 特写里写"转身、挥手、走路" | 景别太近，大动作出画，空间感混乱 |

### 17.3 表情粒度与景别对照表

| 表情类型 | 中近景（0-5s） | 近景（5-10s） | 特写（10-15s） |
|---------|:---:|:---:|:---:|
| **整体姿态**（站/坐/靠） | ✅ 适合 | ⚠️ 可带一笔 | ❌ 不适合 |
| **头部动作**（点头/摇头/转头） | ✅ 适合 | ✅ 适合 | ⚠️ 容易出画 |
| **嘴角大动作**（大笑/大哭/张嘴说话） | ✅ 适合 | ✅ 适合 | ✅ 适合 |
| **嘴角小动作**（抿嘴/嘴角上扬/苦笑） | ⚠️ 可见但弱 | ✅ 适合 | ✅ 适合 |
| **眼神变化**（看左/看右/眨眼） | ⚠️ 可见但弱 | ✅ 适合 | ✅ 适合 |
| **眼眶泛红/泪光** | ❌ 看不见 | ⚠️ 隐约可见 | ✅ 适合 |
| **面部肌肉微颤** | ❌ 看不见 | ❌ 看不见 | ✅ 适合 |
| **皮肤细节**（汗光/油光/皱纹/毛孔） | ❌ 看不见 | ⚠️ 隐约可见 | ✅ 适合 |

### 17.4 景别递进的实现方式（自拍专属）

竖屏Vlog的景别递进**不能用镜头推拉**，必须通过人物动作自然实现：

| 景别变化 | 实现动作 | 写法示例 |
|---------|---------|---------|
| 中近景 → 近景 | 身体微微向前探 | "身体微微向前探，画面随之变紧到近景" |
| 近景 → 特写 | 身体再向前探一点 | "身体再向前探一点，画面推到面部特写" |
| 特写 → 近景 | 身体向后靠 | "身体向后靠，画面拉回到近景" |
| 近景 → 中近景 | 身体向后靠更多 | "身体向后靠在椅背上，画面拉远到中近景" |

> ⚠️ **禁止：** 写"镜头推近""镜头拉远""焦距变化""zoom in/out"。
> 这些都是第三人称摄影语言，会破坏自拍视角。

### 17.5 景别-情绪同步递进模板（15秒标准段）

```
第0-5秒（中近景·胸部以上）：[人物出场/打招呼/场景建立]，表情[粗粒度：微笑/严肃/惊讶]，说{[开场台词]}。[环境/背景交代]。<开场音效>

第5-10秒（近景·肩以上·身体微探）：身体微微向前探，画面随之变紧到近景。[互动/对话/情节推进]，表情[中粒度：嘴角上扬/皱眉/眼神变化]，说{[中段台词]}。<事件音效>

第10-15秒（特写·面部为主·身体再探）：身体再向前探一点，画面推到面部特写。[金句/情绪高潮/核心观点]，表情[细粒度：眼眶泛红/泪光/肌肉微颤]，说{[结尾金句]}。说完嘴唇缓缓合拢。<收尾音效>
```

## 十八、水下短片最佳实践对照（为什么0台词12镜头不崩）

**核心答案：0台词 = 注意力预算释放40%+。**

水下短片30秒12镜头~1500字完美执行，核心原因是**0台词0口型同步**，模型把全部注意力给了画面、运动、光影、流体物理。

### 可迁移到Vlog的经验

| 水下短片做法 | Vlog可迁移方式 |
|------------|--------------|
| 0台词，情绪靠肢体+眼睛状态 | 台词不可避免，但可以缩减到最低必要量 |
| 情绪状态化（黑点眼圆睁） | 情绪写状态锚点不写渐变过程 |
| 每镜2-3秒只1-2件事 | 有台词镜头每镜只1个说话人+1-2句 |
| 硬切（每镜独立干净任务） | Vlog可用硬切代替连续运镜 |
| 环境开头一次写完 | 环境集中描述，后续不重复 |
| 动作物理可见（尾摆/拍击） | 动作写大肌肉群可见位移 |
| 负面约束~3条 | 负面约束砍到3条核心 |

### Vlog的先天矛盾

Vlog的核心是**人说话**，不能0台词。这意味着：
- Vlog天生比动作片更难（口型同步是最高成本指令）
- **拆段策略对Vlog不是优化，是刚需**
- 真正需要拆的是有台词的段——台词才是注意力杀手，不是镜头数

### 拆段决策（升级版）

```
镜头有台词？
├── 无台词 → 可与其他无台词镜头合段
└── 有台词
    ├── 说话人≤2 + 台词≤30字 → 可独立成段
    └── 说话人≥3 或 台词≥50字 → 必须拆段
        └── 特效幻化 + 台词同段？ → 必须拆段（幻化独占一段）
```

### 18.5 关键经验总结

1. **台词是注意力第一杀手**：水下短片30秒12镜头0台词完美执行，证明0台词=预算释放40%+。Vlog不能0台词，但可以缩减到最低必要量。

2. **复杂幻化特效与口型是高风险组合**：两者同段会争抢预算。简单视觉特效+短台词同段不一定崩。是否拆段取决于特效复杂度。

3. **环境描写集中一次最省预算**：水下短片开头花300字写环境，后续12镜头不重复。V4同样开头一次写完，省下的预算给了口型和动作。

4. **情绪状态化>过程化**：写"眼眶泛红，嘴角自嘲"（状态锚点），不写"嘴角一点点上扬→眼眶缓慢泛红→眉头微皱"（肌肉渐变过程）。前者一次执行，后者逐帧渐变成本极高。

5. **硬切>连续运镜**：硬切让每个镜头是干净独立任务，连续运镜（缓推/横移）要在一个长镜头内处理多事件时序，复杂度更高。

6. **负面约束≤3条**：每条负面约束占预算但不产生画面。预算充足时模型不会犯那些错，负面约束价值递减。只留3条核心（无字幕/无水印/面部稳定）。

## 二十、实测成功模板（V4.0新增 — 三段式15秒口型稳定版）

> **来源**：2026-09-17 蒲松龄vlog实测验证。用户提供的"3个独立角色+多轮对白+长镜头"方案因信息过载触发超时/中断。改为**"单段15秒、2说话人、30-35字台词、逐句口型标注"**结构后，画面与口型同时稳定。

### 19.1 成功结构解析（七段式）

```
1. 参考图锚定（@图片1-4）
    ↓
2. 场景+机位+光影（环境一次写完）
    ↓
3. 第0-X秒：第1句对话（NPC进场+说话+主角回应）
    ↓
4. 第X-Y秒：第2句互动（主角转场+新NPC出现+对话）
    ↓
5. 第Y-15秒：独白收束（主角面对镜头+情绪升华）
    ↓
6. 画质风格声明
    ↓
7. 负面约束（无水印/无logo/无字幕）
```

### 19.2 核心成功要素（七条经验法则）

| 法则 | 具体要求 | 为什么有效 |
|------|---------|-----------|
| **法则1：单段≤2说话人是低风险配置** | 建议一段视频最多2个角色开口 | 3人以上会显著增加面部锁定冲突+口型切换风险。短台词+充分锁定时可能不崩 |
| **法则2：台词30-35字是低风险区间** | 15秒台词建议控制在30-35字 | 低于30字可能内容不够；超过40字会显著增加口型风险，但语速慢、停顿多时可能不崩 |
| **法则3：逐句口型标注** | 每句说话前加"嘴唇随每个字清晰地一开一合" | 正面指令告诉模型嘴巴该干什么，比"不要歪嘴"有效10倍 |
| **法则4：不说话写"嘴唇紧闭"** | 没台词的角色明确写"嘴唇紧闭不说话" | 防止模型让背景角色乱张嘴 |
| **法则5：环境只写一次** | 开头定灯光、色调、前景、景深，后续不重复 | 环境重复=浪费注意力预算 |
| **法则6：前景遮挡+纵深** | "书案+古籍+烛台"作为前景虚化遮挡下沿 | 一个细节建立自拍真实感，画面纵深立即出来 |
| **法则7：冷暖对比光** | 主光源暖黄+环境光冷蓝，左右脸明暗对比 | 比单一光源更有电影感，且模型执行率高 |
| **法则8：三层声音结构** | 环境底噪（持续低）+ 事件音（点缀）+ 配乐（随剧情渐入渐出） | 声音有层次，氛围感强，不抢人声注意力 |

## 二十一、古人今话Vlog爆款铁律（V8.0新增 — 10万赞爆款拆解）

> **来源**：拆解播放量100万+、点赞10万+的「王勃直播人生」爆款视频，提炼可复用的创作规律。
> **适用**：历史人物自拍Vlog、古人今话穿越感、第一人称传记类短视频。

### 21.1 结构铁律：危机开场 + 倒叙 + 首尾呼应

**公式：** 把人物扔到全片最低谷/最危机的时刻 → "趁还没凉透，从头聊聊" → 倒叙一生 → 结尾回到开场场景形成闭环。

**为什么有效：**
- 开场就抛悬念，观众立刻被抓住（前3秒留存率翻倍）
- 倒叙比顺叙更有戏剧张力，观众知道结局但想看过程
- 首尾呼应结构完整，余韵悠长

**蒲松龄版应用：**
- 开场：48岁号舍越幅事件，"答题卡窜行了，零分。趁我还没缓过来，从头聊聊我这倒霉催的一辈子"
- 中间：按年龄倒叙回去（10岁→18岁→19岁→21岁→25岁→26岁→31岁→40岁→72岁→76岁）
- 结尾：聊斋完稿"都是人间的事，留给后人看吧"，与开场的"倒霉催"形成一生的呼应

### 21.2 节奏铁律：每段一个"预期违背"（立flag→打脸）

**公式：** 每15秒段落内部，先立flag（我稳了/我赢了/我牛逼）→ 立刻反转（然而并没有）

**为什么有效：**
- 短视频喜剧黄金公式，观众永远被吊着
- 小波浪嵌套大波浪，情绪永远在动，不会腻
- 15秒内有起有伏，观众来不及划走

**典型打脸模板：**
```
"王府上班，这把怎么看都稳吧？" → "得，被赶出来了"
"手感爆棚，这把稳了！" → "答题卡窜行了，零分"
"排位赛开启，冲上王者！" → "打了一辈子还是青铜"
"五万卷书随便看，赚了！" → "考了五十年，换这么个东西"
```

### 21.3 视觉基因铁律：全片统一视觉体系

**不是单个画面美，而是全片有统一的"系列感"。**

| 维度 | 统一规范 | 为什么重要 |
|------|---------|-----------|
| 色彩体系 | 低饱和冷灰+土黄+赭石为主，暖光仅在高光时刻短暂出现 | 古朴质感统一，观众看一眼就知道是这个系列 |
| 光线体系 | 阴天柔和散射光、室内窗侧光为主，阴影柔和不生硬 | 避免光影跳戏，保持沉浸感 |
| 材质基调 | 粗布麻衣、风化木构、泛黄纸张、氧化铜器 | 古旧感的核心在材质，不在"滤镜" |
| 构图体系 | 中心/三分线、中近景为主、每段必有前景虚化遮挡 | 构图稳定，观众注意力在人物和台词上 |
| 摄影基调 | 第一人称手持、平视角度、呼吸感晃动 | Vlog真实感的来源 |

**应用方法：** 写提示词前先定「全片视觉基因表」，所有镜头严格遵循，确保系列感。

### 21.4 道具叙事铁律：展示而非讲述

**公式：不说"我当官了"，而是把官印、案卷、官服一一扫过镜头。**

| 事件 | 讲述式（差） | 展示式（好） |
|------|------------|------------|
| 中秀才 | "我中秀才了！" | 手指在榜单上划，停在"蒲松龄"三个字上 |
| 分家破产 | "我分到三间破屋！" | 踢了一脚破碗，碗转了一圈，抬头一脸无语 |
| 坐馆毕家 | "毕家有五万卷书！" | 从书橱抽出一卷书，鼻子凑近深吸一口，闭眼笑了 |
| 聊斋完稿 | "书写完了！" | 朱笔圈完最后一个句号，笔尖顿住没抬起 |
| 岁贡生 | "得了个贡生" | 把贡生牌翻过来，背面是空白的，拇指慢慢摩挲 |

**为什么有效：**
- 道具即信息，画面即叙事，不用嘴讲省台词预算
- 道具动作比纯说话更有画面感，观众记得更牢
- 道具可以承载隐喻（空白的贡生牌=五十年一场空）

**应用原则：** 每段至少1个道具展示动作，用道具讲故事，不用嘴讲。

### 21.5 年龄锚点铁律：手上的细节比脸上更真实

**人物年龄变化不能只靠"白发"，手上的细节是人物的年轮。**

| 年龄 | 手部细节 | 为什么真实 |
|------|---------|-----------|
| 10岁 | 握笔浅红印、小指蹭书页 | 孩子的手，稚嫩但有学习痕迹 |
| 19岁 | 握笔茧、墨渍 | 青年读书人，常年握笔 |
| 25岁 | 关节发红（冻的）、门板绳勒痕 | 贫寒过冬、体力劳动 |
| 31岁 | 船缆绳红痕、代笔厚茧 | 奔波劳碌、替人写公文 |
| 40岁 | 翻书薄茧、书虫蛀粉 | 常年翻书、坐馆安定 |
| 48岁 | 握笔厚茧、颤抖痕迹 | 中年手抖、考试紧张 |
| 72岁 | 老年斑、旧伤疤 | 老人的手，一生的痕迹 |

**为什么有效：**
- 观众潜意识里会注意到手，但自己说不出来为什么真实
- 手上的细节比脸上的皱纹更有"故事感"
- 每只手都是一部微缩的人物传记

### 21.6 运动-情绪对应铁律：晃动就是情绪

**自拍视角的晃动不是随便晃的，晃动的节奏=人物的情绪状态。**

| 状态 | 晃动特征 | 身体动作 |
|------|---------|---------|
| 平静说话 | 呼吸传导的微浮动，缓慢均匀 | 只有胸部起伏 |
| 兴奋得意 | 晃动幅度略大，频率略快 | 身体微晃，头部微动 |
| 疲惫失意 | 晃动变慢变沉，偶尔下坠感 | 肩膀垮着，头微低 |
| 行动中（走路/搬东西） | 重心交替转移的颠簸感 | 全身有节奏晃动 |
| 刚停下 | 晃动先大后小，慢慢稳定 | 身体先动后停，呼吸接续 |
| 崩溃/震惊 | 画面骤然变紧（猛探头），然后僵住 | 身体猛地前倾，然后僵直 |

**应用原则：** 每段的晃动模式和情绪绑定，写提示词时一起写。

### 21.7 声音铁律：5层混音 + 精确分贝

**声音通道不挤占画面预算，可以做得很丰富，但要层次分明。**

| 层级 | 内容 | 音量参考 | 作用 |
|------|------|:---:|------|
| 第1层 | 主角人声（台词） | 100% | 绝对核心 |
| 第2层 | 近景动作音（翻书/搁笔/衣料） | -18db | 活人感、临场感 |
| 第3层 | 中景环境音（人群/雨声/虫鸣） | -20db | 画面丰富度的声音延伸 |
| 第4层 | BGM（配乐） | -20db | 情绪铺垫，不抢人声 |
| 第5层 | 氛围声（空间低频/空旷感/闷感） | -25db | 空间感、沉浸感 |

**关键原则：**
- 谁说话谁靠前，配乐永远不盖人声
- 声音有远近层次，不是所有声音一样大
- 动作有声音反馈（翻书有声、搁笔有声、走路有声）

### 21.8 画面隐喻铁律：不说一句话但全是戏

**最高级的叙事是画面叙事。每段至少1个无声画面细节，承载情绪/隐喻/命运。**

**爆款案例中的隐喻手法：**
| 画面细节 | 隐喻含义 |
|---------|---------|
| 落榜生影子斜扫过"蒲松龄"名字 | 高光之下藏隐忧，命运的阴影已经逼近 |
| 雨滴洇开榜单上的"蒲"字 | 命运的眼泪，名字被抹去，功名成空 |
| 蓬蒿种子飘向屋顶破洞的光柱 | 破败中的希望，种子=素材=写作的生命力 |
| 贡生牌翻过来是空白的 | 五十年功名一场空，什么也没留下 |
| 指纹印在未干的墨迹上 | 他的生命痕迹将印在这些文字里 |
| 炊烟飘进来模糊了树影 | 人间烟火气，文字融入生活 |
| 烛火被风吹矮又弹回 | 人生大起大落，灭不了 |

**应用方法：** 每段设计1个"不说一句话但全是戏"的画面细节，放在段尾或情绪转折点。

### 21.9 结尾铁律：留遗憾，不要圆满

**最有力量的结尾，不是胜利宣言，而是一声叹息。**

| 结尾类型 | 效果 | 观众反应 |
|---------|------|---------|
| 圆满胜利（"我赢了"） | ⭐⭐ 正确但没劲 | 看完就划走 |
| 遗憾开放式（"在路上"） | ⭐⭐⭐⭐⭐ 最有力量 | 点赞收藏反复看 |
| 悲壮牺牲（"来不及了"） | ⭐⭐⭐⭐ 有冲击力 | 感动但沉重 |

**古人今话Vlog的理想结尾：**
```
"写了一辈子鬼狐，有人说我不务正业。
可这人间真话，哪是能直接说的？
——你们慢慢读，我先撤了。"
```

不说"赢了"，不说"圆满"，留一个开放的、略带遗憾的、在路上的状态。
观众看完心里空一块，才会点赞收藏反复看。

```
动曝光轻微波动，白平衡小幅自然偏移。背光背景轻微过曝，面部曝光不均匀，高光为
自然阳光反射，非人工布光。笑意先从眼部、嘴角浮现，再缓慢扩散到全脸，笑容克
制真实。口型变化联动眼睑、眉毛、鼻翼、脸颊肌肉，非独立嘴部运动。
```

**位置2：参考图引用区（开头@图片N处）**
```
参考@图片1[人物]锁定人物一致性：固定脸型、五官比例、眼睛、鼻子、嘴唇、肤色、
发型、发量、年龄感，禁止五官漂移、脸型变形、换脸。@图片2[场景]仅用于场景结
构、环境氛围、建筑布局，禁止将参考图内行人作为主角，禁止复制参考图内可读文字。
```

### 22.4 参考图分工规则详解

| 参考图类型 | 用途 | 禁止事项 | 写法 |
|-----------|------|---------|------|
| 人物锁定图 | 固定脸型/五官/发型/年龄感 | 禁止复制影棚背景、静态姿势、四视图版式 | "锁定人物一致性：固定脸型、五官比例…禁止五官漂移、换脸" |
| 场景参考图 | 场景结构/环境氛围/建筑布局 | 禁止将参考图内行人作为主角，禁止复制可读文字 | "仅用于场景结构、环境氛围…禁止将参考图内行人作为主角" |
| 表情参考图 | 笑容/表情参考 | 禁止复制参考图发型和服装 | "仅用于表情参考" |

> **核心原则**：每张参考图必须写明"用来干什么"和"不能干什么"，否则模型会全盘复制参考图内容。

## 二十三、行为链写作法（V5.3新增 — 第三方最优提示词拆解）

> **来源**：2026-09-19 用户提供的第三方最优提示词（北京胡同Vlog），实测效果超越工程版。
> **核心发现**：把口型、表情、呼吸、视线、镜头惯性写成**因果相连的行为链**，而非独立指令。模型按链条顺序执行，结果"像活人"而非"像表演"。

### 23.1 指令式 vs 行为链式

| 写法 | 特征 | 模型行为 | 结果 |
|------|------|---------|------|
| **指令式** | "口型同步""表情自然""呼吸浮动""镜头惯性"四条独立指令 | 各做各的，互不关联 | 像表演 |
| **行为链式** | "说完话→嘴没合上→笑意残留→眼睛带笑意看镜头→转身→身体先动→镜头慢半拍" | 按链条顺序执行，每一步是上一步的结果 | 像活人 |

**本质区别**：指令式告诉模型"做什么"，行为链式告诉模型"从哪开始→怎么过渡→到哪结束"。模型不需要理解"什么是自然"，只需按链执行。

### 23.2 行为链五要素

一条完整的真人行为链包含五个环节，缺一不可：

```
① 台词发音细节 → ② 情绪余韵 → ③ 视线轨迹 → ④ 身体动作 → ⑤ 镜头物理反应
    ↓               ↓             ↓            ↓              ↓
"说得快而含混"   "嘴没合上"    "看镜头一下"  "转身往前走"   "镜头惯性慢半拍"
```

**① 台词发音细节（口型层）**

不只写台词内容，写发音方式：

| 要素 | 写法 | 举例 |
|------|------|------|
| 语速 | 快/慢/连读/含混 | `"不要门票"说得快而含混` |
| 停顿 | 换气/犹豫/停一下 | `停了一下才接"图个自在嘛"` |
| 吞音 | 含混带过 | `"不就"两个字含混带过` |
| 尾音 | 拖长/收住/上扬 | `"嘛"字尾音拖长` |
| 换气 | 句间换气 | `中间换了一口气才说"知足"` |
| 声量 | 放轻/放大 | `声音放轻` |

> **为什么有效**：模型不只生成"说了什么"，而是生成"怎么说的"——口型、节奏、气息全部跟着发音描写走。

**② 情绪余韵（表情层）**

说完话后表情不立刻切换，写余韵的完整时序：

```
说完话
  → 嘴角停留在说话末尾状态（不立刻变化）
  → 眼睛先出现笑意
  → 嘴慢慢咧开
  → 笑出来
  → 肩膀颤了两下
  → 颤动传导到画面微弱晃动
  → 低头
  → 抬头看镜头
```

> **为什么有效**：笑不是"指令笑"，是从说完话的嘴型开始→眼部→嘴角→全脸→肩膀→画面的完整传导链。模型按链执行，笑有层次、有过程。

**③ 视线轨迹（注意力层）**

每段写明视线从哪到哪，不写"看向镜头"一句话了事：

| 时机 | 视线轨迹 |
|------|---------|
| 说话前 | 扫了一眼身后招牌 |
| 说话时 | 看向镜头 |
| 说完后 | 带着笑意看了镜头一下 → 飘到侧前方看路 |
| 走路时 | 瞥了一眼车把手 → 看向胡同尽头远处 → 收回来看镜头 |
| 最后凑近 | 视线下垂看了一眼地面 → 抬头看镜头 |

> **为什么有效**：视线是观众判断"真不真实"的第一信号。真人不会死盯镜头，视线游走才有活人感。

**④ 身体动作（动作层）**

只写有因果的动作，不写无目的的动作：

| 动作 | 因果 |
|------|------|
| 转身往前走 | 因为说完了，要走 |
| 手臂自然收回 | 因为走路不需要举着手机 |
| 凑了半步 | 因为要说最后一句重要的话 |
| 肩膀颤了两下 | 因为笑出来了 |

> **为什么有效**：每个动作都有原因和结果，不是"随机动一下"。

**⑤ 镜头物理反应（镜头层）**

镜头不自主运动，是身体运动的物理结果：

```
呼吸传导到肩膀→手臂→手机→微弱浮动
走路重心交替→画面颠动
转身时身体先动→镜头惯性慢半拍→扫过侧面→找回主角
停步后→呼吸成为画面唯一运动来源
笑到肩膀颤→传导到画面微弱晃动
低头→抬头→镜头惯性偏高→再找回面部
转身瞬间→眼镜/衣领/头发边缘极轻微动态模糊
走过光影交界→自动曝光轻微变化
```

> **为什么有效**：镜头运动的物理因果链清晰，模型不需要"决定怎么运镜"，只需模拟物理传导。

### 23.3 行为链写作模板

每个时间段按以下结构写：

```
第X-X秒，事件：[一句话概括事件]

[环境+光线一句]。[主角位置+入画范围+焦段]。[环境细节1-2个]。

[主角动作链]：[身体先动]→[动作]→[视线轨迹]→[开口说话]：{台词}

台词发音细节：
  - [语速/含混/连读/停顿/换气/尾音/声量]

说完后[情绪余韵链]：[嘴型停留]→[眼部变化]→[嘴咧开]→[笑出来]→[肩膀颤]→[传导到画面]→[低头/抬头]→[镜头惯性反应]

[镜头物理反应]：[转身/移动时的惯性滞后/曝光变化/动态模糊]

<环境贴身声效>
```

### 23.4 四类有效约束详解

行为链中真正起作用的不是"口型同步"这种工程要求，而是以下四类约束：

**A. 发音节奏约束**
```
"不要门票"说得快而含混
"图啥啊"轻而快，"不就"两个字含混带过
停了一下才接"图个自在嘛"
"嘛"字尾音拖长
"算一天"连读，中间换了一口气才说"知足"
```
比"口型与音频同步"具体10倍——不只生成"说了什么"，而是生成"怎么说的"。

**B. 说话后的余韵约束**
```
说完嘴没合上
笑意残留嘴角
嘴角停留在说话末尾的状态没有立刻变化
眼睛先出现笑意，嘴慢慢咧开
```
这是自然感的核心。AI视频最常见的假感来自：说完立刻闭嘴、表情瞬间切换、笑像突然贴上的。余韵约束直接解决这个问题。

**C. 面部肌肉联动约束**
```
笑意从说完最后几个字开始残留并缓慢展开
眼睛先出现笑意，嘴慢慢咧开
肩膀颤了两下，颤动传导到画面微弱晃动
```
让口型不再只是嘴唇运动，而是整个面部和身体都参与。

**D. 镜头惯性约束**
```
转身时身体先动，镜头因惯性慢半拍
停步后呼吸成为画面唯一运动来源
镜头因惯性慢半拍偏高再找回面部
```
手机前置自拍的真实感很大程度来自：镜头不是稳定的、镜头比身体慢、停了之后还有呼吸、晃动不是随机抖而是有传导链。

> **为什么这四类比"口型精准同步"更有效**：模型不需要理解"什么是精准"，只需要按节奏描述执行。快/含混/停顿/换气/尾音拖长是模型可操作的具体行为；"口型同步"是不可操作的技术指标。

### 23.5 "无意义动作"原则

真人最真实的特征是有大量不服务于任何叙事目的的小动作：

```
偶尔偏头、眨眼、肩膀微动、重心微调
衣服惯性晃动
```

> **关键句式**："不服务于任何叙事目的"——这句话很重要。AI视频常犯的错是每个动作都像被安排好的。但真实自拍里，人会有很多没目的的小动作。加这句告诉模型：这些小动作不需要有理由，像真人一样随机出现就行。

### 23.6 行为链与活人逻辑的关系

行为链是活人逻辑（第七章）的**实现层**：

```
活人逻辑（理念层）：
  环境事件先发生 → 人物先回应环境 → 才对镜头分享
      ↓
行为链（实现层）：
  环境声效先出 → 身体先动 → 视线先扫环境 → 才看镜头说话
  → 说完嘴没合 → 笑意余韵 → 视线飘走 → 脚步继续
```

活人逻辑管"先做什么后做什么"，行为链管"每一步怎么过渡"。

### 23.5 正反对比

**❌ 指令式（像表演）：**
```
主角面朝镜头说：{嘿，这地方好，不要门票。}
说完嘴角保留笑意。转身时镜头惯性滞后。
```

**✅ 行为链式（像活人）：**
```
主角吸气，视线扫了一眼身后招牌，说：{嘿，这地方好，不要门票。}
"不要门票"说得快而含混，说完嘴没合上，笑意残留嘴角，眼睛带着
还没收住的笑意看了镜头一下，随即转身往前走。转身时身体先动，
镜头因惯性慢半拍，扫过招牌侧面再找回主角背影侧前方，转身瞬间
眼镜边缘和衣领边缘有极轻微动态模糊。
```

**差异**：指令式3行，行为链8行。但行为链的每一行都是链条的一环，模型按链执行就行；指令式的3行模型要自己脑补"怎么笑""怎么转身""镜头怎么跟"。

### 23.7 两层优化法：硬约束+自然表演

当行为链导致效果波动时，可拆成两层写：

**第一层：硬约束（稳定性）**
```
口型与台词逐字同步，嘴唇开合自然，无嘴部错位、面部闪烁、下颌漂移。
人物全程同一人，五官比例、眼镜、发型、服装稳定。
```

**第二层：自然表演（自然感）**
```
说话有连读、吞音、停顿和换气；说完后表情不立刻切换，笑意缓慢展开；
视线在镜头和环境之间自然游走；身体动作带动镜头惯性变化。
```

> **适用场景**：单人、近距离、生活化、分享式Vlog适合行为链写法（一层足够）；多人、复杂场景、高信息密度段适合两层写法（硬约束保底+自然表演加分）。

## 二十四、比喻陷阱（V5.5新增 — 写物理动作，不写比喻）

> **来源**：关汉卿中秋Vlog创作踩坑经验（2026-09）
> **核心发现**："像XX一样""如同"这类比喻词是提示词中的毒药。AI模型是视觉思维，它看不到"像"这个抽象词，只看到两个具象概念然后合成。

### 24.1 为什么比喻是陷阱

AI模型是**视觉思维**，它处理的是画面，不是修辞。

当你写"像举着令牌一样举着月饼"时，模型的处理过程是：
1. 识别到"举着令牌" → 生成一个举令牌的画面
2. 识别到"举着月饼" → 生成一个举月饼的画面
3. 然后它把两个概念**混合**到一起

结果：月饼上长出令牌的纹路，或者手的姿势僵硬不自然。

> **核心原理**：比喻是观众大脑完成的，不是模型渲染的。
>
> 你写物理动作 → 模型渲染画面 → 观众看到画面 → 观众自己产生联想
>
> 中间那步"联想"是观众的工作，你替观众做了，模型会当真。

### 24.2 正反对比

| 错误（比喻） | 正确（物理动作） |
|-------------|-----------------|
| 像举着令牌一样举着月饼 | 往前虚点一下 |
| 如同皇帝登基一般走上台 | 背着手，步子放慢 |
| 眼睛像星星一样亮 | 抬头看天，眼中有光 |
| 声音如同洪钟 | 声音放大，中气十足 |
| 像个孩子一样蹦蹦跳跳 | 笑着蹦了两下 |
| 美得像画一样 | 停下脚步，看呆了 |

### 24.3 检验方法

写完一条指令后问自己：
> **如果我是一个只会画画、不会中文修辞的人，我能画出这个画面吗？**

- 能 → 合格（是物理动作/状态）
- 不能 → 不合格（是比喻/抽象概念）

### 24.4 常见比喻黑名单

以下表达全部禁止，必须替换成物理动作：

| 禁止使用 | 替换为 |
|---------|--------|
| 像……一样 | （直接写动作结果） |
| 如同 / 仿佛 / 好似 | （直接写状态） |
| 宛如 / 犹如 | （直接写画面） |
| 就像……似的 | （直接写行为） |
| XX感爆棚 / 拉满 | （写出具体表现） |

> **配套文档**：详细的注意力预算优化方法见 `12-attention-budget-optimization.md`。

## 二十五、注意力预算优化三原则（V5.5新增 — 微表情2节点/动作3条/台词2句）

> **来源**：关汉卿中秋Vlog创作经验沉淀（2026-09）
> **核心原则**：注意力预算不是越多越好，是越精准越好。

### 25.1 原则一：微表情最多2个节点

**一个镜头一个核心情绪，微表情锚点最多写2个（起始状态+关键转折点）。**

| 节点 | 写法 | 作用 |
|------|------|------|
| 起始状态 | "绷着脸" | 情绪起点 |
| 关键转折点 | "说完咧嘴笑" | 情绪切换瞬间 |

**错误**（4个节点，预算爆了）：
```
嘴角慢慢上扬→咧开→笑出声→笑到弯腰
```

**正确**（2个节点，执行率高）：
```
绷着脸→说完咧嘴笑
```

> 模型是"关键帧插值"思维，你给两个状态，它自动补过渡。你写五个节点，它一个都执行不好。

**微表情权重**：微表情执行率约为动作指令的0.5倍。超过3条基本全丢。

### 25.2 原则二：5秒镜头动作≤3条

以5秒为基本单位，动作指令数量上限：

| 时长 | 动作指令上限 |
|------|-------------|
| 5秒 | 3条 |
| 10秒 | 5条 |
| 15秒 | 7条 |

**动作优先级（从高到低）**：
```
主运动（走路/转身） > 关键手部动作（拿东西/指方向） > 头部动作（转头/低头） > 身体微动（肩膀/重心）
```

**砍掉所有过程描写副词**："不自觉地""慢慢地""缓缓地""轻轻地"——这些词不产生视觉结果，只消耗预算。直接写动作结果。

| 错误 | 正确 |
|------|------|
| 慢慢地转过身 | 转过身 |
| 缓缓地举起酒杯 | 举起酒杯 |
| 不自觉地抬起手 | 抬起手 |

### 25.3 原则三：5秒镜头台词≤2句

| 时长 | 台词上限 | 推荐 |
|------|---------|------|
| 5秒 | 2句 | 1句 |
| 10秒 | 3句 | 2句 |
| 15秒 | 5句 | 3-4句 |

**口型+微表情抢预算，二选一**：
- 信息密集段（讲知识点）：多台词 + 1个微表情
- 情绪爆发段（笑/哭/惊讶）：少台词 + 2个微表情

**双说话人必须硬切分隔**：两个说话人不要写在同一段时间区间里，用镜头硬切分开，各算各的预算。

### 25.4 镜头风险评级表（速查）

| 风险等级 | 动作数 | 台词数 | 微表情数 | 预期执行率 |
|---------|--------|--------|---------|-----------|
| 低风险 | ≤2 | 1句 | ≤2 | 80%+ |
| 中风险 | 3-4 | 2句 | 2-3 | 50-70% |
| 高风险 | ≥5 | ≥3句 | ≥4 | <40% |

> **配套文档**：完整的优化步骤、正反对比、权重计算见 `12-attention-budget-optimization.md`。定量审核见 `08-attention-budget-audit.md`。

## 二十六、感官细节法（V5.5新增 — 替换抽象形容词）

> **来源**：关汉卿中秋Vlog创作经验沉淀（2026-09）
> **核心发现**：抽象形容词（繁华/热闹/富庶）走脑子，观众用理解；感官细节（香味/声音/触感）走身体，观众用感受。Vlog要的是代入感，所以写感官细节，不写抽象形容词。

### 26.1 抽象形容词 vs 感官细节

| 类型 | 例子 | 观众反应 |
|------|------|---------|
| 抽象形容词 | 繁华、热闹、富庶、盛大、美丽、壮观 | 脑子理解，没感觉 |
| 感官细节 | 香味、声音、触感、温度、味道 | 身体感受，代入感强 |

> **核心区别**：抽象词走脑子，感官细节走身体。观众记住的是身体的感受，不是脑子里的概念。

### 26.2 五感优先级（Vlog适用）

```
听觉 > 嗅觉 > 视觉补充 > 触觉 > 味觉
```

视觉是画面本身提供的，所以提示词中重点补其他感官——尤其是听觉和嗅觉，它们是台词可以传达的。

### 26.3 替换对照表

| 抽象形容词 | 替换为感官细节 |
|-----------|---------------|
| 大街上很热闹 | 耳边全是吆喝声和嗑瓜子的声音 |
| 节日气氛很浓 | 风里飘着桂花香，到处都是灯笼的红光 |
| 美食很多 | 烤羊肉串的香味直往鼻子里钻，旁边炸糕的油锅滋滋响 |
| 环境很雅致 | 丝竹声细细的，檀香飘过来，桌上的茶杯冒着热气 |
| 夜晚很安静 | 远处有几声狗叫，脚步踩在青石板上嗒嗒响 |
| 人很多 | 说话声混在一起，有人在笑，有人在喊，脚步声杂沓 |

### 26.4 在提示词中的写法

感官细节放在**环境描写**里，每段至少1个听觉细节+1个嗅觉细节：

```
[环境+光线]。夜风里飘着桂花香，远处有笛声。
[主角动作+台词]
```

> **为什么有效**：台词里写感官细节，不是为了"文笔好"，是为了让观众的大脑自动补全环境。观众听到"桂花香"，脑子里就会浮现秋天的街道——这是免费的场景渲染，不消耗视觉注意力预算。

> **配套文档**：完整的创意框架（质检员人设/喜剧频道轮换/隐藏暗线/伪互动）见 `13-creative-framework.md`。

## 二十七、实战注意事项八条（V6.0新增 — 蔡伦Vlog v12质检体系沉淀）

> **来源**：蔡伦Vlog v12版质检体系 + 多轮实测翻车经验总结
> **核心原则**：这些是"红线规则"——不是建议，是必须遵守。违反了大概率出问题，遵守了能显著提升生成质量。

### 27.1 提示词长度红线

| 模型 | 字数上限（含参考图声明和尾注） | 超过后果 |
|------|------------------------------|---------|
| 2.0 Fast | ≤ 1500字 | 后半段指令被忽略，口型/动作崩 |
| 2.5 | ≤ 2500字 | 中段细节丢失，人物一致性下降 |

**执行方法**：
- 写完提示词后，数字数（包括所有文字，不含图片本身）
- 超长时优先砍：环境修饰词 → 次要道具细节 → 过渡动作描述
- 绝对不能砍：人物锚点、核心情绪、关键动作链、负面约束

### 27.2 时间轴分段红线

| 模型 | 单段最多分镜数 | 超过后果 |
|------|--------------|---------|
| 2.0 Fast | ≤ 3段 | 第3段之后口型对不上，动作逻辑混乱 |
| 2.5 | ≤ 5段 | 第5段之后人物漂移，场景穿帮 |

**执行方法**：
- 长内容必须拆成多段生成，后期剪辑拼接
- 每段之间留1秒重叠帧，方便剪接
- 每段必须有完整的起承转合，不能半段切

### 27.3 不要写帧率指令

**为什么删**：模型不兑现帧率指令，写了也没用，还占字数。

**删除清单**：
- ❌ "30fps"
- ❌ "60fps"
- ❌ "24帧"
- ❌ "高帧率"

**替代写法**：用"流畅自然""动作连贯"等描述效果，不指定具体帧率。

### 27.4 不要写抽象注意力路径

**为什么删**："注意力从A移到B再到C"是认知层面的抽象描述，模型无法直接执行，等于废话。

**替换原则**：把抽象的"注意力/视线移动"，改成**具体的视线落点+身体动作**。

| 抽象写法（删） | 具体写法（留） |
|--------------|--------------|
| 注意力从脚边移到脸上 | 低头看了一眼脚边的纸堆，马上抬回来 |
| 视线在工坊里扫了一圈 | 眼珠往左边瞟了一下，又收回来 |
| 注意力集中在炉火上 | 眼睛盯住炉子，不眨眼了 |

### 27.5 NPC出场方式：用"已经在那了"

**为什么**：模型生成"从远处走来"的长距离行走非常不稳定——容易腿崩、比例崩、透视崩。

**正确写法**：
- ✅ "父亲站在对面，背对着光"（已经站在那里了）
- ✅ "舍友坐在床边，正在玩手机"（已经坐在那里了）
- ✅ "店小二从柜台后面探出头"（短距离探出，不是走过来）
- ❌ "父亲从远处慢慢走过来"
- ❌ "一个人从街那头向他走来"

**如果必须有行走**：控制在2-3步以内，且是中近景，不要全景长距离行走。

### 27.6 材质描写密度

| 模型 | 材质锚点数量 | 例子 |
|------|------------|------|
| 2.0 Fast | 2-3个 | "旧木台面有面粉和油渍""竹蒸笼有渍痕磨损" |
| 2.5 | 4-5个 | 加"蒸汽半透明团雾状""灶膛炭火暗红带白灰"等 |

**执行方法**：
- 每段场景描写，先列所有能想到的材质细节，然后按模型版本砍到上限
- 优先级：人物身上的（最关键）→ 前景道具 → 中景 → 背景
- 材质描写要具体，不要"很旧""很破"这种形容词，要写"哪里旧、怎么破"

### 27.7 NPC嘴唇：有台词必须补"嘴唇张合"

**为什么**：NPC如果有台词感（说话、喊叫、默念），但提示词里没写嘴的动作，模型经常生成"有声音但嘴不动"的情况。

**执行方法**：
- 每一个有台词的NPC，在台词描述后面补一句嘴部动作
- 嘴部动作要跟台词情绪匹配

| 台词情绪 | 嘴部动作描述 |
|---------|-------------|
| 正常说话 | 嘴唇张合，语速平稳 |
| 惊讶/质问 | 嘴微张，嘴唇动得快 |
| 小声/低语 | 嘴唇轻轻动，幅度很小 |
| 发怒/大喊 | 嘴张得大，嘴唇用力 |

**写法模板**：
```
父亲声音很低：
{明天，跟人走。}
嘴唇张合幅度小，语速慢。
```

### 27.8 身体先行原则

**为什么**：直接写手部动作，模型容易生成手的位置不对、比例不对、动作僵硬的情况。先动身体，手自然跟上，动作就顺了。

**核心逻辑**：
```
身体重心移动 → 姿态变化 → 手臂跟上 → 手部动作
```

**对比**：

| 直接写手（错） | 身体先行（对） |
|--------------|--------------|
| 他伸出右手去拿竹简 | 他往前倾了倾身子，右手跟着伸出去，拿起竹简 |
| 他把手机往下压了压 | 他手腕轻轻往下一压，镜头跟着往下晃了一下 |
| 他抬手擦了擦汗 | 他肩膀抬了抬，右手顺势抹了一把额头的汗 |
| 他把纸举起来看 | 他往后退了半步，双手把纸举到眼前，低头看 |

**执行方法**：
- 写任何手部动作之前，先想："身体的重心/姿态会怎么变？"
- 把身体变化写在前面，手部动作跟在后面
- 动作链越长越顺，越短越容易崩
