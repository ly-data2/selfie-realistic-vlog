# 钩子场设计框架（黄金1-2秒停留系统）

> 核心原则：效果 > 稳定。稳定但平庸的视频，不如冒险但有冲击力的视频。
> 目标：让人停下来 → 让人看完 → 让人记住。
>
> **上游文档**：[00-four-track-framework.md](./00-four-track-framework.md) 四轨评估体系 — 钩子设计服务于A轨「5秒完播率」和「收藏率」，不为钩子而钩子

---

## 一、为什么钩子场是命门

### 1.1 滑动式浏览的残酷现实

短视频平台用户是"滑动式浏览"，不是"点开看"：

| 时间点 | 用户决策 | 决定因素 |
|--------|---------|---------|
| 第0.5秒 | 停不停？ | 画面冲击力 |
| 第1-2秒 | 看不看？ | 好奇心强度 |
| 第3秒 | 继续还是划走？ | 钩子深度 |
| 第12-15秒 | 看下一个还是点赞？ | 回味/共鸣 |

**15秒视频的真实结构：**
```
第0-1秒：停  ← 让刷视频的人手指停下
第1-3秒：钩  ← 让他想知道"然后呢"
第3-12秒：看  ← 正片内容
第12-15秒：转 ← 想看下一个 / 点赞评论
```

### 1.2 钩子强度分级

| 等级 | 钩子类型 | 停留率预估 | 适用场景 |
|------|---------|-----------|---------|
| S级 | 打破第四面墙（角色直接跟观众说话） | 70%+ | 奇幻/悬疑/喜剧 |
| A级 | 视觉冲击（反常画面/不可能出现的东西） | 60%+ | 所有类型 |
| B级 | 悬念开头（"你绝对想不到……"） | 50%+ | 知识/故事类 |
| C级 | 正常开头（人物出场+介绍） | 30%以下 | 尽量避免 |

## 二、五种钩子场设计方案

### 方案A："她已经在那儿了"（A级）

**原理**：不是角色走进来，而是她已经在画面里了——观众没准备，措手不及。

**画面**：
- 第0帧：蒲松龄低头写字。身后右侧景深处，红衣女子静静地站着，一动不动看着他。
- 观众反应："等等……她什么时候站那儿的？！" → 手指停下
- 第1-3秒：蒲松龄缓缓抬头，像是感觉到了什么。
- 观众反应："他发现了吗？" → 被钩住

**优点**：不需要特效，省预算，模型易生成
**缺点**：冲击力中等，需要观众仔细看才能发现
**适用**：预算紧张、追求稳定性的版本

---

### 方案B：影子不对劲儿（A级）

**原理**：画面里有"不该有的东西"——影子和人动作不一致。

**画面**：
- 第0帧：蒲松龄对着镜头说话，他身后墙上的影子，和他的动作不一样。
- 观众反应："他的影子……怎么回事？" → 毛骨悚然，停下来看
- 第1-5秒：影子慢慢变成一个女子的轮廓。

**优点**：诡异感强，不需要人物走动
**缺点**：影子动作不一致的技术难度高，容易崩
**适用**：超自然/悬疑题材

---

### 方案C：打破第四面墙（S级）⭐ 推荐

**原理**：角色直接对着镜头（观众）说话，打破次元壁——观众瞬间从"旁观者"变成"参与者"。

**画面**：
- 第0帧：红衣女子的脸凑近镜头，几乎贴满画面，嘴角带笑，眼神直勾勾看着观众，手指放在唇边做"嘘"的手势。
- 观众反应："？？？她在跟我说话？！" → 手指一停
- 第1-3秒：镜头缓缓后拉（或女子后退），身后逐渐露出——蒲松龄坐在书案前低头写字，完全不知道身后有人。
- 观众反应："我的天！她站在他身后！他还不知道！" → 必看
- 第2-5秒：女子对着镜头轻声说："嘘——他还不知道我来了。"
- 观众反应：毛骨悚然+好奇心拉满

**优点**：冲击力最强，停留率最高
**缺点**：技术难度最高，需要拆段生成
**适用**：奇幻/悬疑/喜剧，钩子场专用

---

### 方案D：反常识开头（A级）

**原理**：画面内容违背观众的常识预期。

**例子**：
- 古人拿着手机自拍（我们的Vlog就是这个设定，但开头要强化）
- 清朝人说网络用语
- 鬼在跟人讨价还价

**优点**：喜剧效果强，反差感直接
**缺点**：用多了会审美疲劳
**适用**：喜剧/反差题材

---

### 方案E：危机开头（B级）

**原理**：一开场就是危机/冲突/紧张时刻。

**例子**：
- "大人，您的考卷又被打回来了！"
- "先生，官府的人来了！"
- 画面：满地碎纸，蒲松龄站在中间发呆。

**优点**：叙事张力强，观众想知道"发生了什么"
**缺点**：需要上下文，单独看可能不知所云
**适用**：剧情中段的钩子，不适合开篇第一个镜头

---

## 三、方案C详细拆解：打破第四面墙

### 3.1 完整15秒结构

```
第0-1秒  【停留】女子贴脸嘘 → 0.5秒抓住人
第1-3秒  【钩子】镜头后拉，露出身后的蒲松龄 → 好奇心拉满
第3-5秒  【对话1】女子对观众说"嘘——他还不知道我来了" → 诡异感
第5-7秒  【过渡】蒲松龄抬头，发现女子 → 剧情展开
第7-10秒 【对话2】女子和蒲松龄对话 → 正片内容
第10-15秒【收束】蒲松龄对着镜头说主题句 → 留钩子+点题
```

### 3.2 三幕式钩子逻辑

1. **破墙**（0-1秒）：角色直接看镜头、跟观众说话 → 打破安全距离
2. **揭秘**（1-3秒）：镜头后拉/场景展开，揭示更大的画面 → "原来如此"
3. **留悬**（3-5秒）：说一句模棱两可的话 → "然后呢？"

三幕走完，观众已经被牢牢钩住，接下来的正片他会认真看。

## 四、拆段生成策略（方案C专用）

### 4.1 为什么要拆

方案C的核心难点：**镜头推拉过程中，两个人物的面部都要保持一致。**

模型在推拉镜头时，人物面部容易变形、漂移。如果两个人都在动+推拉，双重不稳定。

**解决方案：拆两段，各保一个人。**

### 4.2 拆分方式

| 段落 | 时长 | 主角 | 参考图优先级 | 核心任务 |
|------|------|------|-------------|---------|
| **第1段** | 0-5秒 | 红衣女子 | 女子大头照 > 场景 > 蒲松龄背影 | 保证女子脸不崩+打破第四面墙的冲击力 |
| **第2段** | 5-15秒 | 蒲松龄 | 蒲松龄大头照 > 场景 > 女子全身 | 保证对话+情绪+主题表达 |

### 4.3 衔接设计

**衔接点**：第5秒左右

两段共享的关键元素：
- 相同的书房场景（同一张参考图）
- 相同的光源方向和色温
- 相同的空间站位（女子在右、蒲松龄在左）
- 相同的前景遮挡（古籍烛台）

**第1段结尾画面**：女子刚说完"嘘——他还不知道我来了"，蒲松龄缓缓抬头，眉头微皱。

**第2段开头画面**：蒲松龄抬头看向右侧女子方向，眉头微皱。女子站在他身后右侧。

→ 两段的衔接帧几乎一样，后期拼接无缝。

### 4.4 第1段（钩子段）提示词结构

```
@图片1作为红衣女子大头照参考（表情灵动、眼神有戏）。@图片2作为清代书房场景参考。@图片3作为蒲松龄背影/侧面参考。

画面开头是@图片1的红衣女子脸部特写，几乎贴满画面。她嘴角含笑，眼神直勾勾看着镜头，右手食指放在唇边做"嘘"的手势。烛光从左前方照来，左半脸暖光，右半脸冷蓝阴影。书案上泛黄古籍和铜烛台作为前景虚化遮挡画面下沿。近景，手持拍摄带轻微晃动，焦点锁定女子面部。

第0-2秒：红衣女子凑近镜头，脸几乎贴满画面，嘴角含笑，眼神直勾勾看着镜头，右手食指放在唇边做"嘘"的手势。烛火在她脸上微微晃动。 <烛火噼啪声，持续低>
第2-4秒：女子缓缓后退，身后的画面逐渐展开——清代书房、书案、一个低头写字的男人背影。女子后退两步停下，依然看着镜头方向。 <衣料窸窣声，极轻>
第4-5秒：女子站在男人身后一步远，嘴唇随每个字清晰地一开一合，声线轻软带点戏谑，说：{嘘——他还不知道我来了。}。说完嘴唇合拢，嘴角笑意更深。男人还在低头写字，完全没察觉。

4K超高清，真实皮肤带毛孔纹理，五官清晰不变形、服装发型一致，画面主体清晰、电影质感，布料有自然褶皱，毛发分明，不要生成水印，不要生成logo，保持无字幕。时长：5秒，比例：9:16。
```

### 4.5 第2段（正片段）提示词结构

```
@图片1作为蒲松龄面部参考（面容清瘦、须发半白）。@图片2作为清代书房场景参考。@图片3作为红衣女子全身照参考。

深夜清代书房，蒲松龄坐在书案前面朝右侧。烛光从左前方照来，左半脸暖光，右半脸冷蓝月光阴影。书案上泛黄古籍和铜烛台作为前景虚化遮挡画面下沿。中近景，手持拍摄带轻微晃动，焦点锁定蒲松龄面部。

第0-3秒：蒲松龄缓缓抬头，看向右侧女子方向，眉头微皱。红衣女子站在他身后右侧，嘴唇紧闭不说话，嘴角含笑。 <毛笔停顿声>
第3-7秒：女子歪头看向蒲松龄，嘴唇随每个字清晰地一开一合，说：{先生，今晚写我吗？}。说完嘴唇合拢。蒲松龄低头瞥了她一眼，嘴角微微上扬，嘴唇随每个字清晰地一开一合，语气随和，说：{写你。}。说完嘴唇合拢。 <衣料窸窣声>
第7-15秒：蒲松龄转回面朝镜头，烛光照亮左半脸，嘴角带着淡淡的自嘲。他看着镜头，嘴唇随字张合，声线低沉沙哑，说：{人人怕鬼我写鬼……他们不知道，鬼比人真。}。说完嘴唇缓缓合拢，右手的毛笔轻轻搁回桌面。烛火晃了一下，画面缓缓暗下去。 <烛火噼啪声，持续低> <笔尖碰纸声>

配乐：开头低沉古琴铺底，对话时鼓点轻轻加入，独白时配乐渐弱只剩古琴余韵。配乐音量始终低于人声。
4K超高清，真实皮肤带毛孔纹理，无美颜磨皮，五官清晰不变形、服装发型一致，画面主体清晰、电影质感，布料有自然褶皱，毛发分明，不要生成水印，不要生成logo，保持无字幕。时长：10秒，比例：9:16。
```

## 五、风险与保底方案

### 5.1 风险清单

| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|---------|
| 女子贴脸特写脸崩 | 中 | 高 | 用女子大头照做@图片1，权重最高，多生成几次选最好的 |
| 镜头后拉/女子后退时变形 | 高 | 中 | 改成"女子从画面右侧凑近镜头"（从右往左移，比推拉稳） |
| 两段衔接不上 | 中 | 中 | 两段用同一张书房参考图，空间站位一致，衔接帧尽量相同 |
| 蒲松龄背影不像 | 低 | 低 | 第1段他是背影/侧面，无所谓，第2段转正后用参考图锁定 |

### 5.2 保底方案（方案C降维到B+级）

如果推拉效果太差，退而求其次：

- **去掉推拉**，改成"女子从画面右侧凑近镜头"（横向移动比前后移动稳）
- 女子从右侧进入画面，凑近到近景，说"嘘——"，然后退后一步
- 蒲松龄在她身后抬头

效果还是比方案A强（因为有打破第四面墙的"嘘"），但生成稳定性大幅提升。

## 六、钩子场自检清单

写完钩子场后，用以下问题自检：

- [ ] **第0.5秒测试**：只看第0帧画面，陌生人会不会停下来？
- [ ] **第2秒测试**：看到第2秒，观众会不会想知道"然后呢"？
- [ ] **钩子深度**：这个钩子能撑多久？3秒？5秒？还是全程？
- [ ] **主题关联**：钩子和视频主题有关系吗？还是为了钩而钩？
- [ ] **可实现性**：模型大概率能生成出来吗？还是太天马行空了？
- [ ] **保底方案**：如果效果不好，有没有降维的替代方案？

**至少通过前3项，才算合格的钩子场。**
