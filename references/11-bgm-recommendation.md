# BGM推荐系统（V1.0）

> **系统定位**：为Vlog提示词配套背景音乐推荐，供后期剪辑添加。
>
> **核心原则**：BGM服务情绪不抢戏。人声永远最清楚，BGM补情绪底色，环境音补真实感。
>
> **重要**：BGM不在AI生成范围内，全部后期剪辑添加。提示词中只写音效标注 `<>` 和配乐标注 `（）`，BGM推荐作为独立文档输出。

---

## 一、混音原则

| 声音层 | 基准音量 | 说明 |
|--------|---------|------|
| 人声（台词） | 100%（0db） | 始终最优先 |
| BGM（高潮段） | -18db | 情绪峰值段 |
| BGM（常规段） | -20db | 大多数时候 |
| BGM（背景段） | -25~-28db | 静谧段（读书、回忆、完稿等） |
| 环境音（主要） | -18~-20db | 婴儿哭声、鞭炮声、心跳声等 |
| 环境音（氛围） | -22~-25db | 风声、虫鸣、油灯噼啪等 |
| 动作音 | -18~-22db | 笔尖划纸、脚步、翻书等 |

**混音口诀**：人声永远最清楚，BGM服务情绪不抢戏，环境音补真实感。

## 二、每段BGM推荐格式

每个镜头的BGM推荐包含以下要素：

```
### 镜头N · 标题 · 年份（年龄）

**节奏曲线：** 情绪节点1 → 情绪节点2 → 情绪节点3

| 时间节点 | 乐器/风格 | 具体描述 | 音量 |
|---------|----------|---------|------|
| 0-5s 镜头1 | 乐器 | 音乐描述 | -XXdb |
| 5-10s 镜头2 | 乐器 | 音乐描述 | -XXdb |
| 10-15s 镜头3 | 乐器 | 音乐描述 | -XXdb |

**推荐曲目参考**：
- 乐器A：参考曲目名
- 乐器B：参考曲目名
- 整体：参考氛围

**剪辑要点**：关键卡点、转场处理、注意事项
```

## 四、转场衔接规则

### 4.1 衔接方式

| 方式 | 效果 | 适用场景 |
|------|------|---------|
| 乐器延续 | 情绪连贯 | 同情绪段内（如出生→少年） |
| 乐器切换+渐变 | 情绪转弯 | 情绪变化段（如教书→辞幕） |
| 骤停+骤起 | 冲击感 | 蒙太奇闪切、情绪暴击 |
| 骤停+静默 | 暴击留白 | 落榜、越幅崩溃 |
| 同乐器不同音区 | 时间流逝 | 年龄跳跃段 |

### 4.2 常用转场模式

```
情绪上升段：前段尾音 → 后段主乐器渐入
情绪下降段：前段主乐器淡出 → 后段主乐器从低音切入
情绪暴击段：前段最高点骤停 → 静默1-2秒 → 后段低音慢慢进入
蒙太奇段：每段硬切，音乐骤停骤起
首尾呼应段：开头乐器 = 结尾乐器，形成闭环
```

## 五、首尾呼应设计

全片首尾应使用同一乐器形成闭环：

```
开场（镜头0）：箫声单音铺底，回忆感
    ↓ ... 全片 ...
结尾（镜头N）：箫声收束，释然感
```

**设计要点**：
- 开头和结尾的乐器音色要能连上
- 开头箫声低、慢、单音；结尾箫声可以从低到高再渐弱
- 结尾最后留1-2秒纯空白，让观众缓一下

## 六、骤停设计（关键转折点）

### 6.1 什么时候用骤停

| 场景 | 骤停时机 | 效果 |
|------|---------|------|
| 情绪暴击 | 越幅发现、落榜确认 | 前段越嗨，停的时候越狠 |
| 蒙太奇闪切 | 每个画面切换 | 冲击感，观众来不及反应 |
| 打破预期 | 说完关键台词后 | 突出台词，留白 |

### 6.2 骤停后的处理

```
骤停 → 1-2秒静默（只有环境音/心跳声）→ 下一乐器从低音慢慢进入
```

**不要骤停后立刻接高潮音乐**——要给观众1-2秒"消化"时间。

## 七、输出规范

### 7.1 何时输出BGM推荐

在第五步Prompt编译完成后，作为附加文档输出BGM推荐清单。

### 7.2 输出格式

```

| 阶段 | 主乐器 | 情绪基调 |
|------|--------|---------|
| 钩子 | 箫 | 回忆 |
| ... | ... | ... |

### 逐段推荐

（按镜头顺序列出每段的BGM推荐表格）

### 转场衔接建议

（列出相邻段之间的音乐衔接方式）

### 音量参考表

（列出各声音层的基准音量）
```

## 八、与提示词的关系

| 位置 | 提示词中写什么 | BGM推荐文档中写什么 |
|------|--------------|-------------------|
| 台词 | `{台词内容}` | 对应时间的音乐描述 |
| 音效 | `<音效描述，-XXdb>` | 不重复（BGM文档只写音乐） |
| 配乐 | `（乐器描述，-XXdb）` | 展开为完整的3段式推荐 |
| 后期标注 | 【后期添加花字/字幕】 | 【后期添加BGM】+ 具体推荐 |

> **关键**：提示词中的配乐标注 `（）` 是给AI模型的氛围参考，BGM推荐文档是给剪辑师的详细指南。两者不冲突，BGM推荐文档是提示词配乐标注的展开版。
