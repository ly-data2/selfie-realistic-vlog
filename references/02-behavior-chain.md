# 行为链方法论（Behavior Chain）

> 本文档定义真人行为的生成逻辑，确保人物行为符合真实人类的思考和行动模式。
>
> **核心原则：人在生活，而不是在面对摄影机表演。**

---

## 一、真人思考链

### 1.1 思考链七步模型

人物不能按照"AI认为合理"的方式思考，必须按照真人的思考模式：

> **看到 → 感受 → 联想到 → 犹豫 → 决定 → 行动 → 事后反应**

| 步骤 | 说明 | 可观察表现 |
|------|------|------------|
| **看到** | 感官接收到信息 | 视线停留、瞳孔变化、头部微动 |
| **感受** | 第一情绪反应 | 表情微变、呼吸变化、身体僵硬/放松 |
| **联想到** | 脑中浮现相关记忆或想法 | 眼神移开、皱眉、抿嘴、停顿 |
| **犹豫** | 内心挣扎、权衡 | 视线飘忽、手指动作、换重心、吞咽 |
| **决定** | 做出选择 | 眼神定住、吸一口气、身体姿态变化 |
| **行动** | 执行决定 | 具体动作、开口说话 |
| **事后反应** | 行动后的余波 | 笑、叹气、沉默、自我修正 |

### 1.2 真人思考的特点

允许且应该出现以下"不完美"：

- 想到一半换话题
- 说错一点
- 自我修正
- 吞掉部分话
- 先说结果再解释
- 说话不完全严谨
- 情绪先出来，逻辑后补
- 明明知道答案仍然犹豫
- 说完后自己笑
- 说完后沉默半秒
- 说到某个人时突然改变语气

> **关键：真人的思考不是线性的、不是完美的、不是高效的。**

## 二、行为链基本结构

### 2.1 五段行为链

人物必须拥有真实行为链，基本结构：

> **看到 → 反应 → 行动 → 说话 → 再行动**

| 阶段 | 内容 | 示例（翻书场景） |
|------|------|------------------|
| **看到** | 感官触发点 | 翻书翻到某一页，停下来 |
| **反应** | 情绪/表情反应 | 眼神定住，嘴角动了一下 |
| **行动** | 第一个物理动作 | 手指轻轻摩挲书页 |
| **说话** | 开口表达 | 抬眼看镜头，说一句话 |
| **再行动** | 说话后的动作 | 继续翻书，笑一下，放下书 |

### 2.2 禁止行为

**绝对禁止：**
> 坐着说完15秒台词，一动不动。

真人不会静止不动地说话，一定会有伴随动作。

## 三、行为三要素

每个行为都必须同时具备以下三个要素：

### 3.1 行为原因

> **为什么做？**

- 不是为了"让画面好看"而做
- 不是为了"展示给观众"而做
- 必须是人物在那个情境下自然会做的

**正确：** 因为紧张，所以手指无意识地抠手机壳
**错误：** 因为要丰富画面，所以加一个手的动作

### 3.2 行为结果

> **做完之后发生什么？**

- 动作会产生物理后果
- 动作会影响后续行为
- 动作会改变人物状态

**示例：**
- 翻书 → 书页发出声音 → 人物停顿了一下
- 叹气 → 肩膀沉下来 → 说话声音也变低了
- 转身 → 手机跟着转 → 画面里出现了新的东西

### 3.3 行为残留

> **动作结束之后身体不会立即归零。**

这是真实感的重要来源。动作有惯性，情绪有余波。

**常见残留表现：**
- 笑完以后嘴角仍然保留一点笑意
- 说完以后嘴巴不会瞬间闭死
- 转身后身体还保持上一动作的惯性
- 哭完以后还在抽鼻子
- 生气之后呼吸还没平复
- 放下东西后手还保持那个姿势半秒

> **口诀：动作停了，身体还没收完。**

## 四、微动作库

### 4.1 16种真实微动作

加入少量真实微动作，服务于真实感，不要为了"丰富动作"机械添加。

| 微动作 | 适用场景 | 情绪暗示 |
|--------|----------|----------|
| **吸气** | 惊讶、紧张、决定前、情绪转折 | 内心波动 |
| **呼气** | 放松、叹气、释然、无奈 | 情绪释放 |
| **眨眼** | 思考、惊讶、不适、说谎（慎用） | 内心活动 |
| **眼神短暂移开** | 思考、回忆、不好意思、回避 | 内心转向 |
| **抿嘴** | 忍耐、思考、不同意、忍住不哭/笑 | 情绪压抑 |
| **嘴角轻微上扬** | 想到好笑的事、自嘲、欣慰 | 正面情绪萌芽 |
| **喉结吞咽** | 紧张、哽咽、忍住情绪 | 强烈情绪 |
| **鼻翼轻微变化** | 生气、激动、哭泣前兆 | 情绪升级 |
| **轻微皱眉** | 困惑、回忆、不舒服、认真 | 认知活动 |
| **手指无意识动作** | 紧张、焦虑、等待、思考 | 内心不安 |
| **整理衣服** | 紧张、在意形象、不知所措 | 社交焦虑 |
| **换重心** | 不自在、等待、想走了 | 身体状态变化 |
| **身体轻微前倾** | 认真、说重要的事、靠近对方 | 投入/重视 |
| **说话时轻微点头** | 强调、说服自己、真诚 | 话语确认 |
| **笑完后继续笑** | 真的好笑、停不下来、越想越好笑 | 真实笑意 |
| **说完后停留一瞬** | 等对方反应、自己也在回味、说完有点空 | 话语余韵 |

### 4.2 微动作使用原则

1. **少量原则** —— 15秒视频中出现2-4个微动作即可，不要堆砌
2. **服务原则** —— 微动作必须服务于情绪和情境，不能无意义添加
3. **变化原则** —— 微动作应该有出现、有持续、有消失，不是一直做
4. **个体差异** —— 不同性格的人微动作频率和类型不同

## 五、视线锁规则

### 5.1 核心原则

人物不能一直盯着镜头。自然自拍状态下，视线是变化的。

> **人在生活，而不是在面对摄影机表演。**

### 5.2 四种状态下的视线规则

| 状态 | 视线方向 | 比例参考 |
|------|----------|----------|
| **说话时** | 适度看镜头，偶尔移开 | 约60%-70%看镜头 |
| **思考时** | 看旁边、看地面、看远处、看正在做的事情 | 基本不看镜头 |
| **行走时** | 主要看前方和环境，偶尔瞟一眼镜头 | 约20%-30%看镜头 |
| **情绪变化时** | 允许短暂避开镜头 | 完全移开，然后慢慢回来 |

### 5.3 视线变化的节奏

- 不要一秒钟切三次视线
- 不要一直死死盯着镜头
- 视线移动应该有原因（想到什么、看到什么、情绪变化）
- 视线移开后要回来，不要一直不看镜头

## 六、表情表达方法

### 6.1 核心原则

**禁止直接写抽象情绪词：**
> "人物表现悲伤。"
> "人物很开心。"
> "人物陷入回忆。"

**必须写成可观察的具体行为：**
> 想到妻子后视线慢慢移开，嘴角笑意消失，吸一口气，再重新看向镜头，说话声音明显低下来。

### 6.2 情绪四阶段过程

情绪必须具有过程，不是瞬间切换：

> **触发 → 变化 → 表达 → 残留**

| 阶段 | 说明 | 悲伤示例 |
|------|------|----------|
| **触发** | 什么东西触动了情绪 | 翻到和妻子的合照 |
| **变化** | 情绪从无到有、从淡到浓的过程 | 手指停顿，眼神慢慢暗下来 |
| **表达** | 情绪到达顶点的外在表现 | 吸一口气，视线移开，喉结动了一下 |
| **残留** | 情绪退去后的余波 | 再看镜头时，眼睛还有点红，声音低了半度 |

### 6.3 常见情绪的可观察表达

| 情绪 | 不要写 | 应该写 |
|------|--------|--------|
| **开心** | "人物很开心" | 嘴角先扬起来，眼睛弯了，笑出一点声，笑完还剩一点笑意挂在脸上 |
| **难过** | "人物表现悲伤" | 说到这里声音低下来，视线移开，吸一口气，再回头时眼眶有点红 |
| **尴尬** | "人物很尴尬" | 笑了一下但眼睛没笑，挠了挠后颈，换了个重心，视线飘向别处 |
| **释然** | "人物释然了" | 长长呼一口气，肩膀沉下来，嘴角动了动，像是在笑又像不是 |
| **紧张** | "人物很紧张" | 手指无意识抠着手机壳，咽了一下，说话语速比刚才快一点 |
| **回忆** | "陷入回忆" | 眼神看向斜上方，停顿两秒，嘴角微微动了一下，像是想起了什么 |

### 6.4 情绪表里不一设计（共情力放大器）

> **核心洞见：最强的共情，不是"他哭了所以我哭"，而是"他在笑但我心疼"。嘴上说的和脸上/动作里传的不一样，观众会自动补全中间的落差。**

40万赞爆款验证：青年杜甫落榜，笑着说"大不了下次再考嘛"，但眼里全是泪——这个表情比号啕大哭更戳人。

#### 6.4.1 表里不一的五种经典模式

| 模式 | 嘴上说的 | 表情/动作传的 | 观众感受到的 |
|------|----------|--------------|-------------|
| **笑着哭** | "没事""挺好的""大不了再来" | 眼眶红、嘴角在抖、笑比哭还难看 | 心疼、懂事的心酸 |
| **咬牙说狠话** | "我不在乎""随便吧" | 拳头攥紧、下颌绷紧、声音发颤 | 嘴硬心软、逞强的脆弱 |
| **平静说痛苦** | "我儿子饿死了"（语气平淡） | 视线空洞、手指抠进肉里、身体微微晃 | 极致的痛已经哭不出来了 |
| **自嘲式骄傲** | "我就是唐朝最倒霉的诗人" | 说的时候自己先笑了，眼里有光 | 历尽千帆的豁达 |
| **温柔说告别** | "拜拜了家人们，咱们诗里见" | 气息微弱、嘴角带着笑意、眼神很柔 | 温柔的悲伤、释然的离去 |

#### 6.4.2 为什么表里不一比直白表达更强

**直白表达（弱）：** 人物哭 → 观众知道"他很伤心" → 情绪距离远

**表里不一（强）：** 人物笑但眼里有泪 → 观众心里咯噔一下 → 主动补全"他其实很难过但不想说" → 观众自己完成了共情

> **原理：** 观众不是被台词感动的，是被自己"读懂了人物没说出口的情绪"这件事感动的。

#### 6.4.3 表里不一的设计方法

**第一步：确定表层情绪**（人物嘴上说什么、想表现出什么）
- 比如：假装没事、假装坚强、假装开心、假装不在乎

**第二步：确定深层情绪**（人物真正的感受是什么）
- 比如：其实很痛、其实很在意、其实快撑不住了

**第三步：设计"泄漏点"**（深层情绪从哪些细节漏出来）
- 眼睛：眼眶红、泪光、视线躲闪
- 嘴角：在抖、笑到一半僵住、抿嘴
- 声音：发颤、沙哑、语速突然变了
- 手：攥紧、抠、不自觉的小动作
- 呼吸：屏住、深呼吸、吸气时带颤音

**第四步：控制泄漏程度**
- 轻微泄漏（高手级）：只有眼眶红了，其他都正常
- 中等泄漏（共情强）：嘴角在抖，声音有点颤，但还在笑
- 全面泄漏（情绪爆发）：笑着笑着就哭了，再也撑不住

> **黄金法则：泄漏点越少越克制，观众越心疼。能用眼睛说完的，就不要用嘴说。**

#### 6.4.4 表里不一的自检清单

- [ ] 全片至少有一个"表里不一"的表情设计吗？
- [ ] 表层情绪和深层情绪有明显反差吗？
- [ ] 泄漏点是细节（眼睛/嘴角/手）而不是大哭大喊吗？
- [ ] 泄漏程度和剧情阶段匹配吗？（前期克制，后期可以释放）
- [ ] 观众能"读懂"人物没说出口的情绪吗？

## 七、自然说话规则

### 7.1 真人说话不是播音腔

允许且应该出现以下"不完美"：

| 特征 | 说明 | 效果 |
|------|------|------|
| **语速变化** | 有时快有时慢，不是匀速 | 真实感 |
| **吞音** | 有些字发音不清、一带而过 | 口语感 |
| **连读** | 字和字连在一起说 | 自然感 |
| **换气** | 说话中间吸气、呼气 | 生理真实 |
| **轻微口头禅** | "嗯""那个""就是说""你懂吧" | 生活化 |
| **半句话停顿** | 说到一半停下来，想一下再继续 | 思考同步 |
| **句尾拖一点** | 最后一个字拉长一点点 | 口语特征 |
| **情绪影响语速** | 激动时变快，难过时变慢 | 情绪同步 |
| **边走边说** | 走路时说话有呼吸声和停顿 | 场景真实 |
| **边做事情边说** | 手上做事，嘴上说话，注意力不全都在说话上 | 生活感 |

### 7.2 语速基准

**默认基准：**
> **1秒 ≈ 5个汉字**

**15秒理论最大值：**
> 约75字

**实际推荐：**
> **55–70字**

**剩余时间留给：**
- 呼吸
- 行为
- 环境声
- 表情
- 情绪变化

> **绝对禁止：为了填满时间而疯狂塞台词。**

### 7.3 台词分配原则

- 前3秒：钩子信息（让观众想继续看）
- 中间：核心内容（事件+情绪）
- 最后：落点/余韵（让观众记住）
- 不要平均分配字数
- 情绪重的地方，语速慢，字数少
- 情绪轻的地方，语速快，字数多

## 七点五、台词铁律（最重要）

> **核心洞见：Vlog的真实感来源于当下感受的直接表达，不是回忆总结。**
>
> **爆款公式 = 当下正在经历 + 被打断的真实感 + 环境互动 + 古人说网络用语的差异感**

### 7.5.1 铁律一：台词必须是"正在发生"，不是"回忆过去"

**这是区分"真Vlog"和"假Vlog"的第一条线。**

| | 回忆式（假） | 当下式（真） |
|---|---|---|
| **本质** | 站在人生终点总结回顾 | 此刻正在经历这件事 |
| **举例** | "我教了半辈子书，也做过幕僚" | "师傅慢点啊，我这书要掉水里了！" |
| **时态** | 过去式（我做过、我去过、我曾经） | **现在进行时（我正在、你看、快看这个）** |
| **感觉** | 像在做人生总结 | 像在拍真实的记录 |

**判断方法：写完每句台词，问自己：**
- 这句话是"正在发生"还是"我在讲过去的事"？
- 如果是讲过去 → 改成正在经历那个时刻

**改写示例：**
- ❌ "我当年在宝应做过幕僚" → ✅ "今天太常寺来调人，让我过去管礼仪"
- ❌ "我认识过一位顾姑娘" → ✅ "对了，幕府时还认识了位顾姑娘"
- ❌ "我考中了状元" → ✅ "家人们我考中了！名字就在上面！"

> **关键：不是不能提过去的事，而是要用"当下想起来的口吻"说出来，不是用"总结人生的口吻"说出来。**

### 7.5.2 铁律二：台词必须有"打断感"

**真实的人说话不是从头说到尾的，会被外部事件打断。**

**四种打断方式：**

| 打断类型 | 说明 | 示例 |
|----------|------|------|
| **外部事件打断** | 说话被身边发生的事打断 | "我考中了，名字就在上面，哎等会你们先别急，我鞋快被踩掉了" |
| **突然想起打断** | 说到一半突然想起别的事 | "今天带你们来曲江看柳，你们看这柳叶……对了，先说个事" |
| **和弹幕互动打断** | 像在回应观众的弹幕 | "你们先别一块催，我总得一处一处去" |
| **环境干扰打断** | 被环境中的声音/事物干扰 | "船开了，今天我要离开永兴——师傅慢点！书要掉水里了" |

**打断感的正确写法：**
```
[正常说话] + [突然被打断] + [处理打断的事] + [回到正题或岔开新话题]
```

**示例：**
> "家人们，我今天带你们看——（被门槛绊了一下）——哎没事，带你们看我新买的砚台。"

> **每15秒视频至少有1次打断。** 不打断 = 念稿子。

### 7.5.3 铁律三：每段必须有环境互动

**真实Vlog里世界是活的，有NPC，有对话对象，有环境物件。**

**不能一个人对着手机说15秒。**

**三种环境互动：**

| 互动类型 | 说明 | 示例 |
|----------|------|------|
| **和NPC对话** | 和身边的路人/同伴/老板说话 | "掌柜的，今天没带钱，金龟拿去" / "贺公使不得使不得" |
| **和环境物件互动** | 和身边的物品产生物理交互 | 翻书、端碗、扶门、捡东西、被绊一下 |
| **对环境反应** | 对环境中的声音/景象做出反应 | 听到鸟叫回头看、被风吹眯眼、踩到水坑骂一句 |

> **每段至少1次环境互动。** 一个人对着手机说到底 = 假。

### 7.5.4 铁律四：古人说现代话的反差感

**古人身份 + 网络用语 = 天然笑点，这是自拍Vlog爆款的核心差异。**

| 手法 | 示例 |
|------|------|
| **固定开场词** | "家人们" — 每段固定开场，建立亲切感 |
| **网络梗当口头禅** | "升升升"、"这排面够大了吧"、"我就是这的人" |
| **典故当段子讲** | 看到→随口说出自己的诗，不是背诵而是即兴 |
| **用古人身份玩现代梗** | "别人都是穷困潦倒被贬流放，我就不一样了，我这辈子，顺极了" |

**注意：** 反差感要自然，不能硬塞。古人说"家人们"是因为他在拍Vlog，不是因为他在古代用这个词。这种"穿越感"本身就是笑点。

### 7.5.5 铁律五：台词逻辑链必须通顺

**每句台词之间要有逻辑勾连，不能跳。**

**正确示例（贺知章）：**
> 做幕僚 → 赈济灾民 → 看到百姓苦 → "对了，幕府时还认识了位顾姑娘" → 印象太深 → 写进聊斋

逻辑链：**做事→看到→想起→印象深→写进书**

**错误示例（我们之前的蒲松龄）：**
> 做幕僚 → 赈济灾民 → "认识了一位顾姑娘，聊斋里的女子都有她的影子"

逻辑断了：认识→直接跳到"聊斋里有她的影子"，缺了"为什么会写进去"的逻辑。

**检查方法：** 把每句台词连起来读，看逻辑链通不通。不通 → 补上中间环节。

### 7.5.6 台词铁律自检清单

- [ ] 台词是"正在发生"还是"回忆过去"？（正在发生 ✅）
- [ ] 有至少1次"打断感"吗？（被打断/突然想起/弹幕互动/环境干扰）
- [ ] 有至少1次环境互动吗？（NPC对话/物件交互/环境反应）
- [ ] 有反差感设计吗？（古人+现代用语/典故当段子）
- [ ] 台词之间的逻辑链通顺吗？（没有跳跃）
- [ ] 有固定开场词吗？（"家人们"之类，建立亲切感）

> **如果以上有任何一项不通过，台词必须重写。**

## 七点六、Seedance密度安全线（实测经验）

> **核心洞见：不是15秒太短，是15秒里塞了太多东西。模型有注意力预算天花板，超出后自动降级——优先保画面大框架，牺牲口型/微表情/时序。**
>
> 以下规则基于两轮实际生成视频的逐帧评估，详见 `07-seedance-adapter.md` 第十三~十八章。

### 7.6.1 台词密度安全线

台词是注意力第一杀手。水下短片30秒12镜头0台词完美执行，证明0台词=预算释放40%+。Vlog不能0台词，但必须控制密度。

| 维度 | 安全线 | 危险线 | 后果 |
|------|--------|--------|------|
| 15秒台词字数 | ≤30字 | ≥50字 | 模型放弃口型同步，台词变画外旁白 |
| 说话人数量 | ≤2人 | ≥3人 | NPC台词变旁白、多句被合并为连续概述 |
| 台词句数 | ≤4句 | ≥5句 | 后半段不是在正常说话而是在乱说 |
| 竖屏补偿 | ≤25-30字 | — | 竖屏本身有惩罚，需额外降密度 |

**铁律：** 15秒单段台词总量不超过30字（竖屏25字）。超出=必崩。

### 7.6.2 NPC对话规则

**实测结论：一个镜头只安排一个NPC对话。**

| 规则 | 说明 | 原因 |
|------|------|------|
| 每镜对话NPC ≤1个 | 一个镜头只一个NPC说话 | 多说话人切换几乎必然导致口型不同步 |
| 背景NPC ≤2个 | 不说话的NPC可以出现在画面中 | 背景NPC提供视觉丰富度但不占口型预算 |
| NPC出场方式 | 从暗处走出、轮廓从模糊变清晰 | 避免"突然出现"的bug感 |

**关键区分：** "一个NPC对话"不是说画面只有一个NPC——背景可以有NPC走动、站立、做小动作，他们只是不说话。背景NPC的存在增加了画面的视觉丰富度和烟火味。

**正确写法：**
```
镜头1：主体1坐在书案前。身后红衣女子从暗处走出，停在主体1身后。女子问{先生，今晚写我吗？} 主体1头也不抬。{写你。}
```
→ 1个对话NPC + 主体1 = 2说话人，背景无其他对话NPC = 安全

### 7.6.3 情绪状态化锚点（替代过程化描述）

**实测结论：写"状态锚点"不写"肌肉渐变过程"。**

| 写法 | 示例 | 执行率 | 原因 |
|------|------|--------|------|
| ❌ 过程化 | "嘴角一点点上扬→眼眶缓慢泛红→眉头微皱" | 10-20% | 逐帧渐变，计算成本极高 |
| ✅ 状态化 | "眼眶泛红，嘴角扯出苦笑" | 60-70% | 一次执行，模型理解"最终状态" |

**状态锚点速查表：**

| 情绪 | 状态锚点写法（✅） | 不要写（❌） |
|------|-------------------|-------------|
| 自嘲 | 眼眶泛红，嘴角自嘲 | 嘴角缓慢上扬然后又垂下 |
| 隐忍 | 嘴角绷紧又松开 | 嘴角一点点绷紧 |
| 苦笑 | 嘴角扯出苦笑 | 嘴角慢慢拉出苦笑 |
| 落寞 | 眼神空了，声音低了 | 眼神慢慢黯淡下去 |

**原则：** 情绪描写像"拍照"——定格一个瞬间状态，不像"录像"——描述变化过程。

### 7.6.4 微表情密度安全线

| 维度 | 安全线 | 危险线 |
|------|--------|--------|
| 微表情指令 | ≤5条/段 | ≥10条/段 |
| 身体动作指令 | ≤5条/段 | ≥10条/段 |
| 总指令 | ≤20条/段 | ≥30条/段 |
| 负面约束 | ≤3条 | ≥8条 |

**微表情与高密度台词互斥：** 台词密集的段落只保留2-3条最高价值状态锚点。微表情应作为低密度段落的点缀。

### 7.6.5 自检清单（Seedance密度版）

- [ ] 15秒台词总量≤30字？（竖屏≤25字）
- [ ] 每镜头对话NPC≤1个？
- [ ] 说话人总数≤2人？（3人是风险线）
- [ ] 情绪描写是"状态锚点"不是"渐变过程"？
- [ ] 微表情≤5条/段？
- [ ] 负面约束≤3条？

> **以上任一项不通过，需在行为链层面缩减密度。详见 `07-seedance-adapter.md` 九维优化框架。**

## 十、行为链连贯性校验（核心更新）

> **核心洞见：物理不冲突 ≠ 行为链连贯。动作之间没有因果关系，就是一堆零散动作的堆砌，模型执行出来就是僵硬的。**
>
> **连贯的行为链 = 真人会按这个顺序做这些事。**

### 10.1 连贯性的四个层次

| 层次 | 检查内容 | 不通过的后果 |
|------|---------|-------------|
| **第一层：物理兼容** | 左右手/四肢/道具不冲突 | 手部崩坏、道具消失、人物变形 |
| **第二层：因果连贯** | 动作之间有先后逻辑关系 | 动作像随机播放，没有节奏感 |
| **第三层：情绪连贯** | 情绪是渐变的，不是开关式的 | 表情生硬，像切换贴图 |
| **第四层：人设连贯** | 行为符合人物性格和身份 | 前后不像同一个人 |

> **注意：** 第一层物理兼容详见 `15-physical-compatibility.md`。本章重点讲第二到第四层。

### 10.2 因果连贯：动作链的"所以然"

每个动作都要能回答：**"为什么做完A会做B？"**

#### 10.2.1 连贯的行为链长什么样

```
看到月饼 → 低头看 → 嘴角往上挑（觉得有意思） → 抬眼看镜头 → 说话
```

每个箭头都有因果：
- 看到月饼 → 低头看（注意力被吸引）
- 低头看 → 嘴角挑（觉得月饼有意思/想起了什么）
- 嘴角挑 → 抬眼看镜头（想跟观众分享这个想法）
- 抬眼 → 说话（开口表达）

#### 10.2.2 不连贯的典型问题

**问题1：动作是孤立列表，不是链条**
```
❌ 站着 → 拍灰 → 举月饼 → 笑 → 说话
（拍灰和举月饼之间是什么关系？拍完灰为什么要举月饼？）
```

**问题2：动作顺序反了**
```
❌ 说话 → 笑 → 看到有趣的东西
（应该是先看到 → 笑 → 说话，不是先说再笑再看）
```

**问题3：情绪跳变**
```
❌ 坏笑 → 严肃 → 又笑了
（情绪像开关，没有渐变过程）
```

**问题4：行为链太密**
```
❌ 5秒内：站稳 → 拍灰 → 举月饼 → 坏笑 → 说话 → 挑眉 → 视线飘走 → 收回
（8个动作塞5秒，真人做不到，模型也执行不了）
```

### 10.3 动作密度安全线

> **核心洞见：不是动作越多越生动。连贯的3个动作 > 零散的8个动作。**

#### 10.3.1 每5秒动作密度标准

| 类型 | 安全线 | 说明 |
|------|--------|------|
| **主动作** | 3-4个/5秒 | 推动叙事的核心动作 |
| **辅助微动** | 2-3个/5秒 | 呼吸、眨眼、重心转移等背景微动 |
| **总动作节点** | 5-6个/5秒 | 主动作+辅助微动 |

**主动作 vs 辅助微动的区别：**

| 类型 | 定义 | 示例 |
|------|------|------|
| **主动作** | 观众能明显看到的、推动叙事的动作 | 低头看、转头、走路、停下、笑出来 |
| **辅助微动** | 不注意就发现不了的、增强真实感的小动作 | 呼吸起伏、眨眼、重心微调、嘴角微颤 |

#### 10.3.2 为什么动作多了反而僵

- 模型的注意力预算有限，动作太多=每个动作都做不到位
- 真人5秒内也做不了8个不同的主动作
- 动作之间没有留白，看起来像快进，不自然

**口诀：宁少勿滥，少而精 > 多而散。**

### 10.4 情绪连贯：渐变原则

#### 10.4.1 情绪不能是开关

| ❌ 开关式（僵硬） | ✅ 渐变式（自然） |
|-----------------|-----------------|
| "他很开心" | "嘴角先扬起来，眼睛弯了，笑出一点声" |
| "他突然严肃起来" | "笑意慢慢收回去，嘴角放平，眼神沉下来" |
| "说完笑了" | "说完嘴角往上挑，笑意从最后几个字开始展开" |

#### 10.4.2 情绪的三种渐变模式

| 模式 | 说明 | 写法示例 |
|------|------|---------|
| **慢慢上来** | 情绪从无到有，逐渐增强 | "嘴角先动了一下，然后笑意慢慢展开" |
| **慢慢散去** | 情绪从有到无，逐渐消退 | "笑完了，嘴角还留着一点笑意，慢慢收回去" |
| **层层递进** | 情绪有层次地升级 | "先抿嘴忍→忍不住笑出声→越笑越厉害" |

> **重要：** 情绪描写是"状态锚点+渐变暗示"，不是逐帧动画。用"慢慢""渐渐""先...然后..."等词引导节奏，不要写精确秒数。

### 10.5 道具连贯：不能凭空出现也不能凭空消失

#### 10.5.1 道具出现的三种合理方式

| 方式 | 说明 | 示例 |
|------|------|------|
| **开头就在** | 镜头一开始道具就在手上/身上/旁边 | "左手举着一块缺角月饼于胸前" |
| **拿起来** | 有明确的"从哪里拿出来"的动作 | "从怀里掏出一块月饼" |
| **别人递过来** | NPC把道具递给主角 | "侍者端着金碗走过来，递到面前" |

#### 10.5.2 道具消失的三种合理方式

| 方式 | 说明 | 示例 |
|------|------|------|
| **放下去** | 有明确的放下动作 | "把月饼放在桌上" |
| **一直拿着** | 本段内道具始终在手上 | "左手月饼仍然举在胸前" |
| **送出画面** | 道具还在但出画了 | "转身走了，月饼移出画面" |

#### 10.5.3 绝对禁止

- ❌ 道具凭空出现（上一秒空手，下一秒手里多了东西）
- ❌ 道具凭空消失（上一秒举着，下一秒没了）
- ❌ 道具换手（上一秒左手，下一秒右手）
- ❌ 道具状态跳变（上一秒完整，下一秒缺了一块）

### 10.6 行走状态连贯：不要否定前态

#### 10.6.1 常见错误

```
❌ "说完转身继续往前走"
（"继续"是废话，转身之后本来就是往前走，不需要"继续"来否定"刚才停了"）

❌ "转回身体继续走"
（"转回身体"暗示刚才身体转过去了，"继续走"暗示刚才停了——两个否定式描述，模型会困惑）
```

#### 10.6.2 正确写法

```
✅ 一直在走："脚步加快，沿主街继续推进"
（明确行走状态在持续，只是速度变了）

✅ 从走到停："脚步放慢下来，最后停在城门前"
（有明确的减速→停下过程）

✅ 从停到走："随即大步朝城门洞里走了"
（有明确的启动动作）
```

**原则：** 行走状态要么"走"要么"停"，状态变化要有明确的过渡动作。不要用"继续走""转回身体走"这种否定式描述。

### 10.7 行为链连贯性自检清单

- [ ] **物理兼容吗？** 左右手/道具/空间有没有冲突？（详见 15-physical-compatibility.md）
- [ ] **动作有因果吗？** 每个动作之间都能说出"因为A所以B"吗？
- [ ] **主动作数量合理吗？** 每5秒3-4个主动作，不超6个总节点？
- [ ] **情绪是渐变的吗？** 不是开关式切换，有过程有残留？
- [ ] **道具有逻辑吗？** 不凭空出现/消失/换手/跳变？
- [ ] **行走状态连续吗？** 没有"转回身体继续走"这种否定式描述？
- [ ] **人设统一吗？** 行为符合人物性格，前后不像两个人？
- [ ] **是真人会做的吗？** 把自己代入人物，你会按这个顺序做这些事吗？

> **以上任一项不通过，在行为链层面修正，不要进入下一步。**

## 十一、完整行为链拆解示例

### 示例：深夜打开空冰箱

**事件：** 加班到深夜的女生打开冰箱，发现空空如也，被自己的狼狈逗笑了。

**完整行为链拆解：**

| 时间 | 思考链 | 行为链 | 微动作 | 视线 | 表情过程 | 台词 |
|------|--------|--------|--------|------|----------|------|
| 0-1s | 看到：冰箱门打开 | 伸手拉开冰箱门 | 手指因为冷缩了一下 | 看冰箱内部 | 疲惫（初始状态） | — |
| 1-2s | 感受：怎么又空了 | 愣住，手还扶着冰箱门 | 眨眼两次 | 视线扫过空荡的冰箱 | 从疲惫到错愕 | — |
| 2-3.5s | 联想到：这周已经第三次了 | 站直身体，手从冰箱门上放下来 | 抿了一下嘴 | 视线移开，看地面 | 从错愕到无奈 | — |
| 3.5-5s | 犹豫：是笑还是叹气 | 换了个重心 | 喉结动了一下（吞咽） | 视线还是没回来 | 从无奈到想笑 | — |
| 5-7s | 决定：算了，笑吧 | 转过头看镜头 | 嘴角先扬了半边 | 视线回到镜头 | 笑意浮现 | "你猜怎么着..." |
| 7-11s | 行动：开口吐槽 | 身体靠在冰箱门上，一只手还扶着门 | 说话时轻微点头 | 大部分时间看镜头，偶尔移开 | 笑着说，越说越好笑 | "...我家冰箱比我脸还干净。" |
| 11-13s | 再行动：笑出声 | 笑出了声，头歪了一下 | 笑完还在笑，停不下来 | 笑着看镜头 | 笑意达到顶点 | （笑声） |
| 13-15s | 事后反应：笑完了有点无奈 | 收住笑，但嘴角还扬着 | 呼了一口气 | 视线又移开一下再回来 | 笑意残留，带点苦涩 | "算了，点外卖吧。" |

**行为三要素验证：**
- 行为原因：加班晚归饿了 → 开冰箱找吃的 → 发现空的 → 情绪变化
- 行为结果：拉开冰箱 → 看到空的 → 情绪变化 → 说话吐槽 → 决定点外卖
- 行为残留：笑完嘴角还扬着、说完后停顿半秒、视线移开再回来

**字数统计：**
- 实际台词约25字
- 加上停顿、笑声、呼吸，15秒刚好
- 符合"55-70字为满，留出行为和情绪空间"的原则
