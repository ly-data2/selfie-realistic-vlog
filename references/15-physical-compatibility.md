# 物理兼容性校验体系（Physical Compatibility Check）

> **核心原则：写每一个动作之前，先问——"用哪只手做？这只手现在有空吗？"**
>
> **物理不冲突 ≠ 行为链连贯。物理校验是第一道关，过了之后还要过行为链连贯性校验。**

---

## 一、为什么需要物理校验

### 1.1 常见的崩坏源头

写 Prompt 时最容易犯的错误不是"动作少了"，而是**动作之间互相打架**——左手既要举着东西固定不动，又要拍衣服、又要指方向、又要抹眼角。模型不知道该执行哪个，结果就是：

- 手的数量变了（3只手、4只手）
- 道具时有时无（月饼出现→消失→又出现）
- 动作僵硬（不知道左手该放哪，干脆钉死）
- 人物崩坏（手部崩坏蔓延到面部）

**这些问题的根源不是"模型能力不够"，是"指令本身就矛盾"。**

### 1.2 物理校验是第一道关

物理校验在行为链设计完成后、Prompt编译前执行。如果物理上就矛盾，后面再怎么优化注意力预算都没用。

```
行为链设计 → 物理校验 → 行为链连贯性校验 → 镜头映射 → ...
```

## 二、左右手铁律

### 2.1 基本分工

| 手 | 固定职责 | 能做的动作 | 不能做的事 |
|----|---------|-----------|-----------|
| **右手** | 永远前伸持机 | 持机（固定），手臂随身体晃动 | 任何额外动作（挥手、指方向、拿东西等） |
| **左手** | 状态可变，本段开头必须明确 | 摆臂、持物、自然垂侧、搭栏杆等 | 本段内频繁切换状态（如：举月饼→放口袋→又举起来） |

### 2.2 右手铁律

**右手永远只有一个功能：持机。**

- ✅ 可以写："画面前景下边缘仅有一小段右侧手臂袖袍入画"
- ✅ 可以写："手臂随呼吸轻微晃动"
- ❌ 绝对不能写："右手挥了挥""右手比了个OK""右手撑着下巴"
- ❌ 绝对不能写："右手端着碗""右手翻书""右手拿手机"（手机本来就在右手里！）

**检查方法：** 搜索 Prompt 中所有"右手""右""右臂"的描述，确认只有持机相关的内容。

### 2.3 左手状态管理

左手是动作冲突的重灾区。**每一段的开头，必须明确标注左手的状态。**

#### 常见左手状态

| 状态 | 说明 | 能做什么 | 不能做什么 |
|------|------|---------|-----------|
| **自然摆臂** | 走路时的状态 | 随步伐前后摆动 | 持物、精细动作 |
| **自然垂侧** | 站着不动时的状态 | 垂在身体一侧，偶尔微动 | 大幅度动作 |
| **持物固定** | 手里拿着东西举着 | 保持那个姿势 | 再做其他动作（除非放下） |
| **持物下垂** | 手里端着/提着东西 | 保持持物，自然下垂位置 | 举高、挥动 |
| **插兜** | 手在口袋里 | 保持插兜状态 | 拿东西、做手势 |
| **搭/扶** | 手扶着栏杆/墙/门框 | 保持搭扶状态 | 再拿东西、挥手 |

#### 状态切换规则

- 一段内左手状态切换**不超过1次**
- 切换必须有明确的动作描述（如"放下书""把手插进口袋"）
- 切换后本段剩余时间维持新状态
- 禁止反复切换（举→放→举→放）

### 2.4 物理冲突的典型案例

#### 案例1：持物固定 vs 挥手

```
❌ 错误：左手举着月饼固定不动 → 左手挥了挥
（冲突：举着月饼怎么挥手？）

✅ 正确：左手举着月饼固定不动 → 往前点了一下下巴（用头部动作替代）
```

#### 案例2：持物固定 vs 拍衣服

```
❌ 错误：左手举着月饼固定不动 → 拍了拍衣服上的灰
（冲突：举着月饼怎么拍灰？）

✅ 正确（先后顺序）：先左手拍了拍衣服上的灰 → 再举起来一块缺角月饼
（有先后就不冲突，但要确保道具出现合理）
```

#### 案例3：走路摆臂 vs 持物

```
❌ 错误：走路时左手自然摆臂 → 左手举着月饼
（冲突：摆臂和持物是两种状态）

✅ 正确：走路时左手自然摆臂 → 停下来时左手从怀里掏出一块月饼
（状态切换有明确动作）
```

## 三、全身物理冲突检查清单

不只是手，全身都要做物理校验。

### 3.1 四肢冲突

| 检查项 | 通过标准 | 反例 |
|--------|---------|------|
| 双手状态明确 | 每段开头明确左右手在做什么 | "左手举着月饼"同时"左手拍衣服" |
| 走路时手脚协调 | 走路时双臂自然摆动，双脚交替 | 走路时双手都举着东西 |
| 坐下/站起合理 | 坐姿时腿部弯曲，站姿时直立 | 坐着的时候"大步向前走" |
| 转身方向一致 | 上半身和下半身转向一致 | 身体朝左走，脸朝右看但脖子不拧 |
| 持物与动作兼容 | 手里拿着东西时，动作要考虑那东西 | 端着一碗汤的时候"用力挥手" |

### 3.2 道具物理

| 检查项 | 通过标准 | 反例 |
|--------|---------|------|
| 道具不凭空出现 | 道具要么开头就在，要么有"拿出来"的动作 | 上一秒空着手，下一秒手里多了个月饼 |
| 道具不凭空消失 | 道具要么一直在，要么有"放下去"的动作 | 举着月饼说话，说完月饼不见了 |
| 道具状态一致 | 道具的位置、角度、数量前后一致 | 上一秒左手举月饼，下一秒月饼跑到右手了 |
| 道具物理合理 | 道具的大小、重量、用法符合常识 | 一只手举着一头大象 |

### 3.3 空间物理

| 检查项 | 通过标准 | 反例 |
|--------|---------|------|
| 人物朝向一致 | 身体朝向和动作方向匹配 | 面朝镜头往前走=倒着走 |
| 行走方向正确 | 往前走时身体朝前，脸可以侧 | 身体朝后倒退着走还面向镜头 |
| 视线与转头匹配 | 看旁边需要转头/转眼，不是眼睛单独飘 | 脸朝正前方，眼睛看到了身后的东西 |
| 空间关系合理 | 人物与环境的前后左右关系一致 | 上一秒在城门里，下一秒在城门外 |

### 3.4 时间物理

| 检查项 | 通过标准 | 反例 |
|--------|---------|------|
| 动作有先后 | 两个动作如果用同一部位，必须有先后 | 左手同时举月饼和拍灰 |
| 动作有持续 | 大动作需要时间完成，不是瞬间的 | "转身"只用了0.1秒 |
| 状态有残留 | 动作结束后身体状态不会立即归零 | 笑完立刻变回面无表情 |
| 行走状态连续 | 走就是走，停就是停，不要反复 | "继续走"→"转回身体继续走"→"往前走" |

## 四、手部动作的行为链融合法（核心方法论）

> **核心洞见：左手动作有冲突，不是"换个部位做同一个动作"，而是"把动作的表达意图融入行为链，让连贯的动作自然完成表达"。**
>
> **低水平替代：** 左手指 → 改成下巴点（还是一个孤立的"指"的动作，只是换了部位）
> **高水平融合：** 人物朝那个方向走，视线看过去，边走边说"你看前面那座楼"——指向性已经在行为链里了，根本不需要额外的"指"的动作。

### 4.1 三层融合法

遇到左手动作有冲突时，从下往上找解决方案：

```
第一层：删除 —— 这个动作真的必要吗？能不能直接去掉？
    ↓ 如果必要
第二层：融入行为链 —— 这个动作的意图，能不能通过已有的连贯动作自然表达？
    ↓ 如果实在不行
第三层：部位替代 —— 用身体其他部位的微动替代（最后手段）
```

**90%的手部动作，在第一层或第二层就解决了，不需要走到第三层。**

### 4.2 第一层：先问"这个动作真的必要吗"

很多手部动作是写Prompt的人下意识加上去的，删掉了完全不影响表达。

| 常见多余动作 | 删掉后的效果 |
|-------------|-------------|
| "左手挥了挥手" | 不说"挥手"，直接说"打完招呼转身走了"——打招呼的意思已经在台词里了 |
| "左手比了个OK" | 不说手势，直接说"咧嘴一笑点点头"——确认感已经在表情里了 |
| "左手拍了拍胸脯" | 不说拍胸，直接说"胸脯往前一挺，声音拔高"——自豪感已经在身体语言里了 |
| "左手挠了挠头" | 不说挠头，直接说"换了个重心，视线飘向别处"——尴尬感已经在身体状态里了 |
| "左手整理了一下衣服" | 不说整理衣服，直接说"肩膀往后一收正了正身子"——整理仪表感已经有了 |

**判断方法：** 把这个动作删掉，再读一遍行为链——表达的意思有没有少？如果没少，说明这个动作是多余的。

### 4.3 第二层：融入行为链（推荐方案）

这是最高级的做法。动作意图不是通过"某个部位做某个动作"来表达，而是通过**整个行为链的连贯流动**自然呈现。

#### 4.3.1 指向/示意类 → 融入行走+视线

| 原动作（有风险） | 行为链融合方案（安全且更自然） | 为什么更好 |
|----------------|-----------------------------|-----------|
| 左手指向前方 | 脚步加快朝那个方向走，视线看过去，边走边说：{走，去那边看看！} | 指向性通过行走方向+视线方向+台词方向三者共同完成，完全不需要"指"这个动作 |
| 左手指自己 | 说到自己时，胸脯自然往前一挺，声音里带着得意 | 自豪感通过身体姿态+语气变化表达，比"指自己"更生动 |
| 左手比数字 | 说到数字时，语速放慢加重，挑眉强调 | 强调感通过语速变化+表情完成，比手势更有感染力 |
| 左手招手 | 脚步加快迎上去，嘴角笑着扬起来 | 招呼感通过行走方向+表情完成，比挥手更真实 |

**核心逻辑：** 真人Vlog里，想去哪就直接走，想看什么就直接看，不会专门停下来做个手势。手势是"表演给别人看"的，行为链是"自己在生活"的。

#### 4.3.2 情绪表达类 → 融入情绪渐变链

| 原动作（有风险） | 行为链融合方案（安全且更戳人） | 为什么更好 |
|----------------|-----------------------------|-----------|
| 左手抹眼泪 | 说到这里声音低下来，视线移开，喉结动了一下，停了一秒再继续说 | 悲伤通过语气+视线+吞咽+停顿四层叠加表达，比"抹眼泪"克制但更戳人 |
| 左手拍胸脯（激动） | 说话越来越快，声音越来越高，眼睛发亮，肩膀微微往前倾 | 激动通过语速+音量+眼神+身体姿态四层表达，比拍胸更有层次 |
| 左手捂嘴笑 | 偏过头笑出声，越笑越厉害，笑完了转回来还在喘气 | 笑意通过转头+笑声+喘气三层表达，比捂嘴更有真实感 |
| 左手握拳（愤怒） | 下颌越咬越紧，声音从平稳慢慢变沉，鼻翼微张 | 愤怒通过下颌+声音+呼吸三层渐变表达，比握拳更有张力 |

**核心逻辑：** 情绪不是"一个动作"，是一个过程。从语气开始变，到表情变化，到身体姿态调整，是一条完整的情绪渐变链。手部动作只是这个链条里最表层的一环，去掉它，链条反而更干净。

#### 4.3.3 整理/互动类 → 融入状态变化

| 原动作（有风险） | 行为链融合方案（安全且更自然） | 为什么更好 |
|----------------|-----------------------------|-----------|
| 左手正帽子 | 站直身体，肩膀往后一收，整个人的状态从放松变端正 | 整理仪表的感觉通过"身体状态变化"完成，比正帽子更整体 |
| 左手扶栏杆 | 走到栏杆边，身体微微靠过去，重心移到一侧 | 倚靠感通过行走→停靠→重心转移的行为链完成，比"手扶"更真实 |
| 左手翻书 | 低头看，书页翻动的声音配合，视线从一行扫到下一行 | 翻书感通过视线移动+声音配合完成，手的动作是隐含的 |
| 左手端碗走路 | 脚步放稳，身体晃动幅度减小，走得比刚才更小心 | 端东西的感觉通过行走状态的变化表达，不需要真的看到手 |

**核心逻辑：** 状态变了，观众自然能推断发生了什么。不需要把每个动作都画出来——观众的脑补能力很强，给够线索就行。

### 4.4 第三层：部位替代（最后手段）

只有当动作意图实在无法通过行为链融合时，才考虑部位替代。而且替代动作必须是**微动**，不能是大动作。

| 类型 | 替代微动（谨慎使用） | 适用场景 |
|------|-------------------|---------|
| 确认/赞同 | 微微点头 | 同意、确认的瞬间 |
| 否定/无奈 | 轻轻摇头 | 否定、不以为然的瞬间 |
| 强调/加重 | 挑眉 | 说重点的时候 |
| 思考/犹豫 | 抿嘴 + 视线移开 | 想事情的时候 |
| 惊喜/意外 | 眼睛睁大 + 微微吸气 | 突然看到什么的时候 |

> **注意：** 这些都是"表情层"的微动，不是"动作层"的大动作。微动的好处是不占肢体预算，而且更真实。

### 4.5 融合法自检清单

- [ ] 先尝试删除了吗？（这个动作真的必要吗？）
- [ ] 再尝试融入行为链了吗？（动作意图能不能通过行走/视线/情绪链自然表达？）
- [ ] 部位替代是最后手段吗？（实在融不进去才用）
- [ ] 替代动作是微动吗？（不是大动作）
- [ ] 融入后的行为链更连贯了吗？（不是更别扭了）

## 五、物理校验流程

### 5.1 四步校验法

```
第一步：标状态
    ↓
每段开头标左手状态（持物/摆臂/垂侧/插兜/搭扶）

第二步：过安检
    ↓
逐动作检查：用哪只手？这只手有空吗？

第三步：查道具
    ↓
道具有没有凭空出现/消失？状态有没有跳变？

第四步：验全身
    ↓
行走方向/空间关系/时间顺序有没有矛盾？
```

### 5.2 校验模板

每段 Prompt 写完后，填写以下表格：

| 项目 | 内容 | 是否通过 |
|------|------|:--------:|
| 左手状态（段首） |  |  |
| 左手状态（段末） |  |  |
| 状态切换次数 |  |  |
| 冲突动作数量 |  |  |
| 道具是否凭空出现 |  |  |
| 行走方向是否正确 |  |  |
| 空间关系是否一致 |  |  |
| **总体结论** |  | **通过/不通过** |

## 六、物理校验自检清单（快速版）

- [ ] 每段开头明确标注了左手状态吗？
- [ ] 右手永远只有持机功能，没有做其他动作吗？
- [ ] 左手在本段内状态切换不超过1次吗？
- [ ] 所有动作都过了"这只手有空吗"的安检吗？
- [ ] 道具没有凭空出现或消失吗？
- [ ] 道具的位置/数量/状态前后一致吗？
- [ ] 人物走路方向是朝前的，不是倒退着走吗？
- [ ] 身体朝向和动作方向一致吗？
- [ ] 两个用同一部位的动作有先后顺序吗？
- [ ] 行走状态是连续的，没有"转回身体继续走"这种否定式描述吗？

> **以上任一项不通过，在行为链层面修正，不要进入Prompt编译。**

## 七、常见误区

### 误区1："动作越多越生动"

**错。** 动作冲突比动作少更糟糕。3个不冲突的自然动作 > 8个互相打架的动作。

### 误区2："左手闲着也是闲着，给它找点事做"

**错。** 真人走路时左手就是在摆臂，站着时就是垂在身侧。"闲着"是正常状态，不需要填满。硬加动作反而不自然。

### 误区3："表达情绪必须用手"

**错。** 最有力的情绪表达是眼睛、呼吸、下颌、肩颈。手部动作是辅助，不是必须。用身体替代手部，既安全又更高级。

### 误区4："物理校验通过就万事大吉了"

**错。** 物理不冲突只是底线。过了物理校验，还要过**行为链连贯性校验**——动作之间有没有因果关系？情绪是不是渐变的？符不符合真人的行为逻辑？
