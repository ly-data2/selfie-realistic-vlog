# Seedance 注意力预算优化实战手册

> **来源**：关汉卿中秋Vlog创作经验沉淀（2026-09）
> **核心原则**：注意力预算不是越多越好，是越精准越好。
> **适用场景**：写实人物对话类Vlog提示词的定性优化，与 `08-attention-budget-audit.md` 定量审核配合使用。

---

## 一、核心原则

**注意力预算不是越多越好，是越精准越好。**

模型的注意力是有限的。你写的每一条指令都在消耗预算，但不是每条指令的执行权重相同。指令越多，单条指令的权重越低，执行率越差。

> **误区**：以为写得越详细效果越好。
> **真相**：写得越精准，关键指令的权重越高，执行率越好。

优化的目标不是"减少指令数量"，而是**把预算花在刀刃上**——砍掉低价值指令，保住高价值指令的执行率。

---

## 二、微表情优化铁律

### 2.1 一个镜头一个核心情绪，最多2个微表情节点

每个镜头只允许有**一个核心情绪**（笑/严肃/惊讶/无奈等），微表情锚点最多写2个：

| 节点 | 作用 | 写法 |
|------|------|------|
| 起始状态 | 情绪的起点 | "绷着脸" |
| 关键转折点 | 情绪切换的那个瞬间 | "说完咧嘴笑" |

**错误写法**（4个节点，预算爆了）：
```
嘴角慢慢上扬→咧开→笑出声→笑到弯腰
```

**正确写法**（2个节点，执行率高）：
```
绷着脸→说完咧嘴笑
```

> **为什么有效**：模型不需要理解"渐变过程"，它会自动在两个状态之间补帧。你给两个锚点，它能补出自然过渡；你给五个锚点，它一个都执行不好。

### 2.2 不要写连续渐变，写状态切换

| 错误（连续渐变） | 正确（状态切换） |
|-----------------|-----------------|
| 嘴角慢慢上扬→咧开→笑出声 | 绷着脸→咧嘴笑 |
| 眼眶渐渐泛红→泪水涌出→滑落 | 眼眶泛红→泪掉下来 |
| 眉头慢慢皱起→咬紧牙关 | 轻松说着→突然皱眉 |

**底层逻辑**：模型是"关键帧插值"思维，不是"逐帧渲染"思维。你给关键状态，它自动补过渡。你写过程描写，它会把过程当关键帧处理，反而跳。

### 2.3 微表情执行率0.5权重，超过3条基本全丢

微表情属于**低权重指令**，执行率约为动作指令的0.5倍。

- 1条微表情：执行率约70%
- 2条微表情：执行率约50%
- 3条及以上：执行率骤降至20%以下，基本全丢

> **铁律**：单镜头微表情指令≤2条。如果必须有3条以上，拆成两个镜头。

## 三、动作层优化铁律

### 3.1 5秒镜头动作指令≤3条

以5秒为一个基本单位，动作指令数量上限：

| 时长 | 动作指令上限 |
|------|-------------|
| 5秒 | 3条 |
| 10秒 | 5条 |
| 15秒 | 7条 |

> **注意**：这里的"动作指令"指有明确位移/姿态变化的动作，不包括"呼吸""眨眼"这类微动作。

### 3.2 动作优先级

当动作超预算时，按以下优先级砍：

```
主运动（走路/转身/站起） > 关键手部动作（拿东西/指方向） > 头部动作（转头/低头） > 身体微动（肩膀/重心调整）
```

**砍法示例**：

原指令（5条，超预算）：
```
往前走 + 手里举着月饼 + 转头看左边 + 肩膀微微晃动 + 重心左右交替
```

优化后（3条，保高优先级）：
```
往前走 + 手里举着月饼 + 转头看左边
```

> 肩膀晃动和重心交替是"走路"的自然结果，模型会自动补。写出来反而稀释了主运动的权重。

### 3.3 砍掉所有过程描写，直接写动作结果

| 错误（过程描写） | 正确（结果状态） |
|-----------------|-----------------|
| 不自觉地抬起手 | 抬起手 |
| 慢慢地转过身 | 转过身 |
| 缓缓地举起酒杯 | 举起酒杯 |
| 轻轻地点了点头 | 点头 |

**为什么"慢慢地""缓缓地"是毒药**：
1. 这些词不产生视觉结果，只消耗注意力预算
2. 模型对"慢"的理解是模糊的，执行率低
3. 真人自拍的"慢"是通过整体节奏体现的，不是靠指令写出来的

> **检验标准**：把副词删掉后，画面还成立吗？如果成立，就删掉。

## 四、口型层优化铁律

### 4.1 5秒镜头台词≤2句，优先1句

| 时长 | 台词上限 | 推荐 |
|------|---------|------|
| 5秒 | 2句 | 1句 |
| 10秒 | 3句 | 2句 |
| 15秒 | 5句 | 3-4句 |

> **基准语速**：6字/秒。5秒约30字，1句刚好（15-20字），2句很挤（每句10-15字）。

### 4.2 口型+微表情抢预算，二选一

口型同步和微表情变化共享同一块面部肌肉预算，两者叠加会互相抢权重：

| 组合 | 预算消耗 | 执行率 |
|------|---------|--------|
| 多台词 + 少微表情 | 中等 | 高（口型准，表情平） |
| 少台词 + 多微表情 | 中等 | 高（表情丰富，口型够用） |
| 多台词 + 多微表情 | 爆炸 | 低（口型崩，表情僵） |

**策略**：
- 信息密集段（讲知识点）：多台词 + 1个微表情（保持情绪基调）
- 情绪爆发段（笑/哭/惊讶）：少台词 + 2个微表情（状态切换）

### 4.3 双说话人必须硬切分隔

两个说话人同框对话时，**不要写在同一段时间区间里**，必须用镜头硬切分开：

**错误写法**（同段双人对话，口型必崩）：
```
0-5秒，主角说：{你猜这月饼多少钱？}
店小二说：{十文钱一个！}
主角惊讶地看着他
```

**正确写法**（硬切分隔，各算各的预算）：
```
镜头1（0-3秒）：主角举着月饼说：{你猜这月饼多少钱？}
镜头2（3-5秒）：店小二探头说：{十文钱一个！}
镜头3（5-7秒）：主角愣住，嘴角抽了一下
```

> **为什么**：模型无法同时精准控制两张脸的口型。硬切不是妥协，是正确做法——真人Vlog拍对话也是正反打。

## 五、比喻陷阱

### 5.1 绝对禁止比喻

**"像XX一样""如同""仿佛""好似"这类比喻词，是提示词中的毒药。**

### 5.2 为什么比喻是陷阱

AI模型是**视觉思维**，它看到的是具象画面，不是抽象修辞。

当你写"像举着令牌一样举着月饼"时，模型看到的是：
- 一个人举着东西
- 令牌 + 月饼
- 然后它把这两个概念**合成**到一起

结果可能是：月饼上长出令牌的纹路，或者手的姿势不自然。

> **核心原理**：比喻是观众大脑完成的，不是模型渲染的。
>
> 你写物理动作 → 模型渲染画面 → 观众看到画面 → 观众自己产生联想
>
> 中间那步"联想"是观众的工作，你替观众做了，模型会当真。

### 5.3 正反对比

| 错误（比喻） | 正确（物理动作） |
|-------------|-----------------|
| 像举着令牌一样举着月饼 | 往前虚点一下 |
| 如同皇帝登基一般走上台 | 背着手，步子放慢 |
| 眼睛像星星一样亮 | 抬头看天，眼中有光 |
| 声音如同洪钟 | 声音放大，中气十足 |

### 5.4 检验方法

写完一条指令后问自己：
> **如果我是一个只会画画、不会中文修辞的人，我能画出这个画面吗？**

- 能 → 合格（是物理动作/状态）
- 不能 → 不合格（是比喻/抽象概念）

## 六、镜头风险评级表

按5秒镜头为单位评估风险等级：

| 风险等级 | 动作数 | 台词数 | 微表情数 | 预期执行率 | 处理建议 |
|---------|--------|--------|---------|-----------|---------|
| **低风险** | ≤2 | 1句 | ≤2 | 80%+ | 直接用 |
| **中风险** | 3-4 | 2句 | 2-3 | 50-70% | 合并同义指令后使用 |
| **高风险** | ≥5 | ≥3句 | ≥4 | <40% | 必须拆镜头或大幅精简 |

**快速计算法**：
- 低风险 = 动作≤2 且 台词≤1 且 微表情≤2
- 中风险 = 任意一项达到中风险阈值，但没有高风险项
- 高风险 = 任意一项达到高风险阈值

## 七、优化步骤

### Step 1：列出所有指令，分类计数

把提示词中的所有指令拆出来，按三类计数：

```
动作层：往前走、举月饼、转头、抬手、耸肩 → 5条
口型层："你猜多少钱""十文钱""这么贵？" → 3句
微表情层：疑惑、惊讶、挑眉、嘴角抽动 → 4个
```

### Step 2：与风险评级表对比

对照第六节的评级表，判断当前镜头的风险等级。

- 低风险：跳过优化，直接用
- 中风险：执行Step 3-5
- 高风险：先考虑拆镜头，再执行Step 3-5

### Step 3：砍掉过程描写，留状态切换

逐条检查每条指令：
- 是"过程描写"还是"状态/结果"？
- 过程描写 → 改成状态切换，或直接删掉
- 副词（慢慢地/缓缓地/不自觉地）→ 全删

### Step 4：合并同义指令

把表达同一个意思的指令合并：

```
往前走 + 走路时重心交替 + 手臂自然摆动
→ 往前走（后两条是走路的自然结果，模型自动补）
```

```
笑着说 + 嘴角上扬 + 眼睛带笑
→ 笑着说（后两条包含在"笑"里）
```

### Step 5：重新计算权重

优化完成后，重新计数，确认风险等级降到中风险或以下。

**优化前后对比模板**：

| 维度 | 优化前 | 优化后 | 减少 |
|------|--------|--------|------|
| 动作数 | 5 | 2 | -3 |
| 台词数 | 3 | 2 | -1 |
| 微表情数 | 4 | 2 | -2 |
| 风险等级 | 高风险 | 中风险 | ↓ |
