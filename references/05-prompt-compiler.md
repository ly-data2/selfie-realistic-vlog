# Prompt 编译器（Prompt Compiler）

> 本文档定义如何将结构化的事件、行为、时间轴编译成最终可执行的视频生成Prompt。
>
> **核心原则：先定调，再补细节。写具体可观察的行为，不写抽象形容词。**

---

## 零、重要提示：双模式输出

本编译器支持两种输出模式：

| 模式 | 用途 | 结构 | 什么时候用 |
|------|------|------|-----------|
| **Vlog长文模式** | 分镜设计、方案沟通、时间轴展示 | 10层结构，按时间轴展开 | 需要展示完整设计思路时 |
| **Seedance模式** | 直接调用Seedance 2.0生成视频 | 5层结构（Subject→Action→Camera→Style→Constraints），单镜头一句话 | 真正要生成视频时 |

> **关键区别：** Seedance 2.0 是单镜头模型，一条Prompt只负责一个镜头。一条15秒Vlog需要拆成3-5个Seedance单镜头分别生成。
>
> 详细适配规则见：`references/07-seedance-adapter.md`

## 一、编译核心逻辑

### 1.1 输入与输出

**输入（结构化描述）：**
```
EVENT        —— 核心事件
VALUE        —— 价值类型
EMOTION      —— 核心情绪
CHARACTER    —— 人物设定
TIME         —— 时间设定
PLACE        —— 地点设定
DIALOGUE     —— 台词
BEHAVIOR     —— 行为链
ENVIRONMENT  —— 环境设定
```

**输出（两种格式）：**

Vlog长文模式：
```
GLOBAL REALISM LOCK    —— 全局真实感约束
+
SELFIE CAMERA LOCK     —— 自拍摄影约束
+
EVENT LOCK             —— 事件约束
+
SHOT TIMELINE          —— 分镜时间轴
+
SOUND                  —— 声音设计
+
LIGHT                  —— 光线设计
+
NEGATIVE CONSTRAINTS   —— 负面约束
```

### 1.2 编译原则

1. **从抽象到具体** —— 先有整体框架，再填充细节
2. **从内容到形式** —— 先确定发生什么，再确定怎么拍
3. **从人物到镜头** —— 先确定人物行为，再映射到镜头变化
4. **从正向到负向** —— 先写要什么，再写不要什么

---

## 二、10层编译顺序

最终Prompt按照以下优先级从高到低编译，上层决定下层，下层服从上层。

### 第一层：人物关系

> **谁在拍、谁在说、谁在行动。**

这是最顶层的设定，决定整个视频的视角逻辑。

**必须明确：**
- 人物是主角 + 摄影者 + 叙述者 + 事件参与者
- 使用前置摄像头自拍视角
- 手机属于人物本人

**编译输出示例：**
> 单人自拍Vlog视角，28岁女生自己拿手机用前置摄像头拍摄，她同时是主角、摄影者和叙述者。

---

### 第二层：事件

> **发生什么。**

核心事件，一句话说清楚这条视频在讲什么。

**编译输出示例：**
> 深夜加班回到家的女生打开冰箱，发现里面空空如也，被自己的狼狈逗笑了。

---

### 第三层：行为

> **人物正在做什么。**

完整的行为链：看到 → 反应 → 行动 → 说话 → 再行动。包含微动作和行为残留。

**编译输出示例：**
> 女生拉开冰箱门，看到空冰箱愣住，站直身体，抿了一下嘴，转头看镜头，靠在冰箱门上笑着说话，说完后呼一口气，关上冰箱门。

---

### 第四层：台词

> **人物正在说什么。**

真人说话方式，不是播音腔。包含语速、停顿、情绪变化。

**编译输出示例：**
> 台词："你猜怎么着...（笑）我家冰箱比我脸还干净。" 语气带着自嘲的笑意，中间有停顿和笑声，语速中等，不是播音腔。

---

### 第五层：自拍摄影

> **手机如何跟随人物。**

人物先动，镜头后动。每个镜头变化都有对应的人物行为触发。

**编译输出示例：**
> 人物前倾开门时手机跟着身体微微前倾，画面略微变紧；站直身体时手机跟着向上；转头看镜头时手机跟着转过来；笑的时候身体晃动带动画面轻微晃动。

---

### 第六层：情绪

> **人物怎么变化。**

情绪过程：触发 → 变化 → 表达 → 残留。用可观察行为描述，不用抽象情绪词。

**编译输出示例：**
> 从疲惫到错愕，再到无奈，然后笑出来，最后是带点苦涩的释然。情绪通过眼神变化、嘴角动作、呼吸变化表现。

---

### 第七层：环境

> **周围发生什么。**

环境通过人物自拍自然出现，不是独立B-roll。有自然生活互动。

**编译输出示例：**
> 厨房环境，暖黄色灯光，冰箱内部冷光，背景隐约可见灶台和橱柜，有生活气息，不是空壳。

---

### 第八层：声音

> **听到什么。**

环境底噪 + 人物声音 + 行为声音 + 互动声音。声音必须同步行为。

**编译输出示例：**
> 冰箱门开关声、压缩机嗡嗡声、笑声、说话声、呼吸声、衣服摩擦声、远处隐约的车流声。

---

### 第九层：视觉真实感

> **手机摄影、皮肤、光线、曝光。**

质感总纲 + 手机摄影特征 + 真实感缺陷预算。

**编译输出示例：**
> 真实手机前置摄像头计算摄影质感，真实皮肤纹理，轻微曝光不均，暖光下肤色自然，轻微自然手持呼吸感。

---

### 第十层：负面约束

> **禁止AI感、第三人称、独立摄影机等。**

全局负面清单，确保不出现违反真实感的内容。

**编译输出示例：**
> 禁止第三人称、禁止独立摄影机、禁止稳定器云台感、禁止塑料皮肤磨皮、禁止广告灯光、禁止机械动作。

## 二点五、双行字幕信息层设计（完播率关键）

> **核心洞见：快节奏多场景视频中，观众需要"坐标感"。上一行字幕告诉观众"现在是哪一年、他在哪、他多大"，下一行才是台词。两条信息同时输入，观众不会迷路。**

40万赞爆款验证：杜甫vlog每一帧都是双行字幕——上栏是背景信息（"50岁被一群孩子欺负""46岁成功投奔唐肃宗当上谏官""公元712年我出生啦"），下栏是人物台词（"我老无力啊""我就说一个人""笑这么开心"）。没有这个双行结构，13个场景快速切换时观众会晕。

### 2.5.1 双行字幕的结构

```
┌─────────────────────────────┐
│  上栏：背景信息层（白色粗体大字）   │  ← 给观众"坐标感"：我现在在哪
│                             │
│                             │
│     （人物画面）              │
│                             │
│                             │
│  下栏：台词层（常规字幕）       │  ← 给观众"代入感"：人物在说什么
└─────────────────────────────┘
```

**上栏 = 导航信息，下栏 = 情绪信息。**

### 2.5.2 上栏信息的五种类型

上栏不是随便写标题，而是精准给观众提供"这个时间段的关键背景"：

| 类型 | 说明 | 示例 | 什么时候用 |
|------|------|------|-----------|
| **年龄型** | 当前年龄 + 关键事件 | "50岁 被一群孩子欺负" | 人生阶段切换时 |
| **地点型** | 当前地点 + 情境 | "成都 草堂刚建成" | 场景切换时 |
| **身份型** | 当前身份 + 状态 | "46岁 投奔唐肃宗 当上谏官" | 身份变化时 |
| **时间型** | 具体年份/时代 | "公元712年 河南巩县" | 时间跨度大的跳转时 |
| **名场面型** | 经典诗句/典故提示 | "茅屋为秋风所破歌" | 名场面出现时 |

**选择原则：哪个信息是观众最需要的"锚点"，就用哪种类型。**

### 2.5.3 上栏信息的写作原则

1. **精炼原则** —— 上栏不超过12个字（两行以内），快速扫一眼就能看懂
2. **增量原则** —— 上栏说的信息，下栏台词里不说（信息不重复）
3. **钩子原则** —— 上栏可以制造悬念（"最惨的一天来了""他没想到这是最后一面"）
4. **节奏原则** —— 不是每个时间段都要换，同一阶段可以共用上栏（避免信息过载）
5. **共情原则** —— 上栏用上帝视角说一句观众想说的话（"心疼""太惨了""谁懂"）

### 2.5.4 双行字幕的节奏设计

**错误做法（信息过载）：** 每个时间段都换上栏，观众看字来不及看画面

**正确做法（呼吸感）：**
- 开篇钩子：上栏点明场景（"50岁 茅屋被秋风破"）
- 身份锚定：上栏可以没有，全靠人物自我介绍
- 时间线开始：每个新阶段换一次上栏（不是每句都换）
- 名场面：上栏点题（"茅屋为秋风所破歌"）
- 高潮/结尾：上栏可以消失，全靠情绪

**一般规律：13个场景的视频，上栏信息大约换6-8次，不是13次全换。**

### 2.5.5 Seedance适配说明

> **重要：** Seedance 2.0 本身不生成字幕。双行字幕是后期剪辑时加上的。

本Skill设计双行字幕的目的：
1. **Prompt阶段就规划好信息密度** —— 知道哪些信息靠画面说，哪些靠上栏说，哪些靠台词说
2. **避免台词超载** —— 如果全靠台词交代背景，台词会又长又臭。上栏分担信息，台词就可以专注情绪
3. **输出字幕稿** —— Prompt编译完成后，同步输出上栏文案，方便后期加字幕

### 2.5.6 双行字幕自检清单

- [ ] 每个大的剧情阶段有对应的上栏信息吗？
- [ ] 上栏和下栏信息不重复吗？（上栏说背景，下栏说情绪）
- [ ] 上栏字数控制在12字以内吗？
- [ ] 上栏不是每个时间段都换，有呼吸感吗？
- [ ] 名场面出现时上栏有点题吗？
- [ ] 观众只看上栏也能看懂故事脉络吗？

## 三、质感总纲优先原则

### 3.1 为什么先定调

质感总纲是整体感觉的锚点。必须先确定整体质感，再用细节规则做约束。

如果先写细节再补质感，很容易出现细节对了但整体感觉不对的情况。

### 3.2 质感总纲内容

> **画幅与画质：** 9:16 竖屏，8K 超高清，iPhone 原生摄像头真实 Vlog 质感，4K 原生分辨率，30fps，高动态范围 HDR。
>
> **影像真实性：** 真实手机动态范围、真实曝光、真实白平衡、真实肤色、真实皮肤纹理、真实环境声音，轻微自然手持呼吸感。

### 3.3 整体视觉目标

整体效果：
> **真实手机原生直出摄影质感 + 高级真实感 + 轻微电影感，而不是广告片。**

- 真实感不是粗糙
- 高级感不是虚假
- 比普通手机随手拍稍微好看一点，但绝不能像专门设计出来的广告

> **口诀：先定调，再补细节。整体对了，细节才有意义。**

---

## 四、语言原则：具体可观察，拒绝抽象

### 4.1 核心原则

不要写抽象词，要写可观察的具体描述。

> **观众看到的是画面，不是形容词。**

### 4.2 三组对照示例

**第一组：不要写"电影感十足"**

| 抽象写法（禁止） | 具体写法（应该） |
|------------------|------------------|
| "电影感十足" | 暖金夕阳从侧后方照入，人物脸部受到真实环境光照，背景高光略有过曝，手机自动曝光轻微调整，阴影保留自然脏感 |

**为什么要具体：**
"电影感"每个人理解不一样。但"暖金夕阳侧后方照入"是明确的、可生成的、可检验的。

---

**第二组：不要写"自然运镜"**

| 抽象写法（禁止） | 具体写法（应该） |
|------------------|------------------|
| "自然运镜" | 人物先转身，身体带动握手机的手，画面慢半拍向右偏移，转身瞬间衣领和眼镜边缘出现极轻微动态模糊 |

**为什么要具体：**
"自然运镜"可能被理解成稳定器运镜、云台运镜。但"人物先转身，身体带动握手机的手"明确了因果关系和自拍逻辑。

---

**第三组：不要写"表现伤感"**

| 抽象写法（禁止） | 具体写法（应该） |
|------------------|------------------|
| "表现伤感" | 说到妻子时视线慢慢移开，嘴角笑意收住，吸一口气，再重新看向镜头，声音明显低下来 |

**为什么要具体：**
"伤感"是抽象情绪，AI可能生成夸张的哭戏。但"视线移开、笑意收住、吸气、声音低下来"是具体的、有过程的、真实的微表情变化。

---

### 4.3 抽象词 → 具体描述转化表

| 抽象词 | 转化方向 | 具体描述示例 |
|--------|----------|--------------|
| 开心 | 面部肌肉变化 + 声音变化 + 身体变化 | 嘴角上扬，眼睛弯了，笑出声，身体微微晃动 |
| 难过 | 视线变化 + 呼吸变化 + 声音变化 | 视线移开，吸一口气，声音低下来，喉结动了一下 |
| 紧张 | 手部动作 + 吞咽 + 语速变化 | 手指无意识抠手机壳，咽了一下，语速变快 |
| 电影感 | 光线 + 曝光 + 色彩 | 侧逆光，高光轻微过曝，阴影有细节，暖色调 |
| 高级感 | 质感 + 细节 + 光线 | 真实皮肤纹理，自然环境光，衣服有质感褶皱 |
| 真实感 | 不完美 + 细节 + 同步 | 轻微构图偏移，有环境底噪，声音和动作同步 |
| 自然 | 有原因 + 有过程 + 有残留 | 人物先动镜头后动，情绪有过程，动作有残留 |

## 五、全局负面清单

### 5.1 按类别分组的38项禁止项

#### 类别1：摄影方式禁止（11项）

- 第三人称摄影
- 独立摄影师
- 专业电影摄影机
- 稳定器
- 云台
- Dolly
- Crane
- Drone
- 航拍
- 自动追踪
- 镜头主动寻找人物

#### 类别2：镜头运动禁止（7项）

- 数字变焦
- 机械变焦
- 无原因推拉
- 无原因摇镜
- 漂浮镜头
- AI漂移
- 过度防抖

#### 类别3：视觉质感禁止（6项）

- 过度HDR
- 塑料皮肤
- 磨皮
- 广告灯光
- 过度电影化
- 美颜

#### 类别4：人物表演禁止（5项）

- 过度表演
- 连续盯镜头
- 机械微表情
- 机械动作
- 无意义慢动作

#### 类别5：剪辑与连续性禁止（6项）

- 突然瞬移
- 无原因跳切
- 人物身份漂移
- 服装漂移
- 场景漂移
- 不合时代道具

#### 类别6：内容元素禁止（3项）

- 强行加入陌生人特写
- 独立环境B-roll
- 字幕 / Logo / 水印 / UI文字

### 5.2 使用方法

- 默认全部生效
- 除非用户明确要求某项可以放开
- 在Prompt最后统一列出
- 优先级：硬规则 > 软效果

## 六、默认视频参数

### 6.1 完整参数列表

除非用户另有要求，默认使用以下参数：

| 参数类别 | 参数值 | 说明 |
|----------|--------|------|
| **画幅比例** | 竖屏 9:16 | 手机竖屏自拍比例 |
| **分辨率** | 8K 超高清（4K 原生分辨率渲染） | 超高清采样，4K实际输出 |
| **帧率** | 30fps | 手机视频标准帧率 |
| **动态范围** | 高动态范围 HDR | 真实手机计算摄影效果 |
| **摄像头** | iPhone 原生前置摄像头自拍 | 模拟真实手机前置 |
| **质感** | 真实 Vlog 质感（手机直出） | 不是广告片、不是电影 |
| **手持感** | 轻微自然手持呼吸感 | 稳定但不完美 |
| **字幕** | 无字幕 | 不加后期字幕 |
| **水印** | 无水印 | 不加平台水印 |
| **Logo** | 无Logo | 不加品牌Logo |
| **UI** | 无UI | 不加界面元素 |
| **商业感** | 无商业广告感 | 不是广告片质感 |

### 6.2 特殊情况

如果用户指定Seedance等具体模型，则优先遵循用户指定模型的参数限制。

## 七、编译流程完整示例

### 示例：深夜空冰箱

**第一步：输入事件**
> 用户说："一个女生深夜加班回家，打开冰箱发现是空的，然后笑了。"

---

**第二步：事件提炼（参考01-event-schema.md）**

| 要素 | 内容 |
|------|------|
| 谁 | 28岁都市女白领 |
| 什么时间 | 周五晚上11点 |
| 什么地点 | 出租屋厨房 |
| 正在做什么 | 拖着疲惫的身体打开冰箱找吃的 |
| 遇到了什么 | 冰箱空空如也 |
| 发生了什么变化 | 愣了一下，然后被自己的状态逗笑了 |
| 最终情绪 | 疲惫中带点自嘲的释然 |

核心事件：加班到深夜的女生打开空冰箱，被自己的狼狈逗笑了。
主价值：共鸣价值
普适性：打工人都懂的那种累到哭笑不得的瞬间

---

**第三步：行为链设计（参考02-behavior-chain.md）**

## 九、Seedance 模式编译规则（实测版）

> 本节定义如何将Vlog长文模式的10层内容，翻译成Seedance 2.0听得懂的语言。
>
> **核心原则：用模型擅长的方式写，避开模型的短板。人物锚点放最前面，粗粒度时间区间，精简禁令。**
>
> 详细适配规则见：`references/07-seedance-adapter.md`

### 9.1 核心认知更新

| 旧认知 | 实测修正 |
|--------|---------|
| 单镜头5层结构 | **支持15秒直出，用时间区间+连续动作** |
| 精细时间码控制节奏 | 粗粒度时间区间（0–4秒/4–9秒），不要小数分段 |
| 负面约束用no xxx格式 | 中文Prompt用逗号分隔的负面提示词，单独放最后 |
| 英文Prompt更好 | **中文Prompt效果更好**，尤其是国风题材 |
| 禁令越多越安全 | **禁令太多会稀释权重**，核心禁令保留即可 |
| 人物描述放中间 | **人物锚点必须放最开头**，权重最高 |

### 9.2 Seedance 黄金结构（权重从高到低）

```
【第1位·权重最高】人物身份锚点 + 场景锁定
    ↓
【第2位】拍摄形式声明（自拍视角 + 质感）
    ↓
【第3位】表演风格
    ↓
【第4位】时间区间 + 动作 + 台词（按顺序写）
    ↓
【第5位·权重最低】负面提示词（单独放最后）
```

### 9.3 编译步骤

**第一步：写人物身份锚点（最重要，放最开头）**
- 姓名 + 年龄 + 固定五官脸型
- 胡须/发型 + 皮肤质感 + 服装
- 身处场景 + 关键道具锁定
- 明确声明：人物样貌服装发型全程稳定，禁止漂移

**第二步：写拍摄形式声明**
- 谁在拍：人物本人手持手机前置自拍
- 距离：一臂手持距离
- 手机不可见：手机手腕手臂尽量不出现在画面
- 运镜来源：镜头变化完全来自身体移动带来的自然手持晃动
- 禁止项：无稳定器云台、无第三人称视角（只说一次，不重复）
- 质感：原生手机前置直出质感 + 计算摄影特征

**第三步：写表演风格**
- 人物气质
- 表演方式（生活化聊天，不是舞台表演）
- 视线规则（不持续盯镜头，思考时移开）

**第四步：写时间区间 + 动作 + 台词**
- 用**智能节奏切分法**确定切片长度（2秒/3秒/4-5秒，跟着内容节奏走）
- 三因素判定：台词密度 + 动作幅度 + 情绪浓度 → 决定切片长度
- 叙述段用整数秒，情绪渐变段可以用小数秒（小数秒是平滑过渡暗示，不是卡剪辑点）
- **场景切换：15秒至少2个不同场景，一段一场景，视觉不重复**（见 `04-shot-timeline.md` 第2.5章）
- 每个区间内：场景 + 动作 + 台词 + 情绪 + 镜头变化（用动作暗示镜头）
- **台词铁律检查（最重要）：**
  - 台词是"正在发生"还是"回忆过去"？（正在发生 ✅，见 `02-behavior-chain.md` 第7.5章）
  - 有至少1次"打断感"吗？（被打断/突然想起/环境干扰）
  - 有至少1次环境互动吗？（NPC对话/物件交互/环境反应）
  - 台词之间逻辑链通顺吗？（没有跳跃）
  - 有反差感设计吗？（古人+现代用语/典故当段子）
- **写表情写过程，不写结果**（"眉头慢慢下压"不是"他很生气"）
- **情绪段用蓄力-爆发模型**：前半段无声蓄力，后半段台词爆发，极短收尾
- **句尾锚点模型**：很早就开口，但情绪爆发点在句尾关键词上
- 按时间顺序写，自然流畅
- 节奏是波浪形的，不是均匀的
- 相邻切片构图变化要小，景别不要跳变（同一场景内）
- 场景切换时有过渡动作（走路/转身），不是硬切
- 详细算法见 `04-shot-timeline.md` 第二章、第2.5章和第三章

**第五步：写负面提示词（放最后）**
- 单独列出，不混在正文里
- 中文逗号分隔格式
- 只保留核心禁令，不重复

### 9.4 常见坑点规避

| 坑点 | 规避方法 |
|------|---------|
| 时间切片策略错误 | 智能切分，内容驱动；整数秒为主，情绪段用小数秒做平滑暗示 |
| 表情生硬跳变 | **写状态锚点不写渐变过程**：写"眼眶泛红，嘴角自嘲"（一次执行），不写"嘴角一点点上扬→眼眶缓慢泛红"（逐帧渐变成本极高） |
| 唇形错位/崩脸 | 台词后置，前半段无声蓄力建立面部基准；短句更容易对齐 |
| 抽象禁令权重冲突 | 用正面描述代替负面禁令，禁令精简合并，**负面约束≤3条核心** |
| 人物一致性漂移 | 人物锚点放最开头，权重最高；有参考图一定要用 |
| "手机不可见"矛盾 | 简化描述，一句话带过，重点放在正面的"手持自拍"上 |
| 环境描写重复浪费预算 | **环境只写一次**：开头定调后不再每镜重复灯光/场景/声音分层描述 |
| 连续运镜塞多事件 | **硬切代替连续运镜**：硬切让每个镜头是干净独立任务，复杂度更低 |
| 特效幻化与口型同段 | **幻化特效独占一段**：特效消耗大量注意力，与口型同步同段必崩 |
| 单段信息过载 | **九维安全线**：≤2场景+≤2说话人+≤4句+≤30字（详见07-seedance-adapter.md第十五~十八章） |

### 9.4.1 九维优化速查（V3.1新增 — 实测经验）

> 以下规则基于两轮实际生成视频的逐帧评估，详见 `07-seedance-adapter.md` 第十三~十八章。

**Seedance Prompt编译时必须检查的9个维度：**

| 维度 | 安全线 | 编译动作 |
|------|--------|---------|
| 信息密度 | ≤2场景+≤2说话人+≤4句+≤30字（竖屏25字） | 超限则拆段或减台词 |
| 指令数量 | 总≤20条/段（微表情≤5+动作≤5+负面≤3） | 砍低价值指令 |
| 计算复杂度 | 物体+空间层为主，口型层拆段独占 | 判断每条指令的层级 |
| 指令冲突 | 无物理矛盾（不写"晃动"又"稳定"） | 检查同时间段互斥指令 |
| 抽象层级 | 情绪写状态锚点不写渐变过程 | "眼眶泛红"代替"眼眶缓慢泛红" |
| 时序模糊性 | ≤2锚点/段，用"镜头1/2"顺序不写秒数 | 删掉精确时间码 |
| 参考素材分工 | 图管外貌，字管动作，环境只写一次 | 删掉Prompt中重复的环境描写 |
| 画面比例 | 竖屏降密度补偿（≤25-30字/段） | 竖屏额外砍台词量 |
| 负面约束 | ≤3条核心（无字幕/无水印/面部稳定） | 删掉多余负面约束 |

**核心公式：** 0台词=预算释放40%+（水下短片证明）。Vlog不能0台词，但可以缩减到最低必要量。

### 9.5 15秒直出 vs 拆条生成

| 方式 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| **15秒直出** | 省事，一次生成 | 人物一致性压力大 | 人物变化不大、场景简单 |
| **拆两段（0–8 + 8–15）** | 一致性更好，每段更稳 | 需要后期拼接 | 人物表情变化大、场景复杂 |

> **建议：** 先试15秒直出，如果人物一致性有问题再拆。

### 9.6 Seedance Prompt 自检清单（实测版）

- [ ] 叙述段用整数秒，情绪段用小数秒做平滑过渡暗示吗？
- [ ] 小数秒只用x.0或x.5格式吗？（不用x.1/x.2/x.3等）

- [ ] 连续2秒切片不超过4个吗？
- [ ] 相邻切片构图变化小吗？（同一场景内景别/角度没有跳变）
- [ ] 镜头变化是通过人物动作描述的吗？（不是"镜头向右移"）

**表情与情绪检查：**
- [ ] **情绪写的是"状态锚点"吗？**（"眼眶泛红，嘴角自嘲" ✅ / "嘴角一点点上扬→眼眶缓慢泛红" ❌）
- [ ] 情绪段有蓄力-爆发的层次吗？（不是一上来就拉满）
- [ ] 用了句尾锚点模型吗？（很早开口，情绪爆发在句尾关键词）
- [ ] 前面大部分台词时面部表情保持稳定吗？（只动嘴唇）

**Seedance密度检查（九维安全线）：**
- [ ] 15秒台词总量≤30字？（竖屏≤25字）
- [ ] 每镜头对话NPC≤1个？
- [ ] 说话人总数≤2人？（3人是风险线）
- [ ] 微表情≤5条/段？
- [ ] 负面约束≤3条核心？（无字幕/无水印/面部稳定）
- [ ] 环境描写只写一次？（开头定调后不再重复）
- [ ] 用"镜头1/2/3"顺序不写精确秒数？
- [ ] 无特效幻化与台词同段？

**台词铁律检查（爆款核心）：**
- [ ] **台词是"正在发生"还是"回忆过去"？**（正在发生 ✅）
- [ ] **有至少1次"打断感"吗？**（被打断/突然想起/环境干扰）
- [ ] **有至少1次环境互动吗？**（NPC对话/物件交互/环境反应）
- [ ] **台词之间逻辑链通顺吗？**（没有跳跃）
- [ ] **有反差感设计吗？**（古人+现代用语/典故当段子）
- [ ] 有固定开场词吗？（"家人们"之类）
- [ ] 台词单句在15-20字以内吗？
