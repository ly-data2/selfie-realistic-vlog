# 质量检查清单（Quality Checklist）

> 本文档定义最终生成Prompt之前的质量检验标准和流程。
>
> **核心原则：硬规则100%通过，否则直接打回；结构化检查确保完整；质量评分追求卓越。**

---

## 〇、7条强制质检清单（最高优先级 · 每段必过）

> **铁律：写完一段Prompt后，必须逐条过这7条，全部通过才能输出。不是"想起来就检查"，是强制流程。**
>
> 对应输出格式：每段末尾必须附【质检通过】区块，7条全✅才算合格。

| # | 质检项 | 检查标准 | 不通过的后果 | 对应文档 |
|---|--------|---------|------------|---------|
| 1 | 🤳 自拍视角 | 右手持机+腕部裁切+镜头运动=人物动作+无手掌/手机出镜 | 视角穿帮，整段重做 | 03-selfie-camera-mapping.md |
| 2 | 🧠 注意力预算 | 核心情绪50%+动作运镜25%+细节15%+环境10%；无独立冲突小动作 | 预算浪费，面部蜡化/动作僵硬 | 08-attention-budget-audit.md / 12-attention-budget-optimization.md |
| 3 | 🔗 动作链连贯 | 每个动作有前因后果，没有孤立动作；动作是情绪的外在表现 | 人物像提线木偶 | 02-behavior-chain.md |
| 4 | ⚖️ 物理兼容 | 左右手分工+道具逻辑+视线方向+空间关系+行走方向全对 | 穿帮、违和、出戏 | 15-physical-compatibility.md |
| 5 | ⚡ 节奏结构 | 段内起承转合+3秒钩子+结尾金句+微呼吸停顿 | 平、慢、没人看 | 18-short-video-rhythm.md |

## 一、10大检查维度总览

最终生成Prompt之前，必须按照以下12个维度逐项检查：

| 维度 | 代号 | 检查重点 | 对应模块 |
|------|------|----------|----------|
| **自拍关系** | A | 自拍视角是否正确，有没有第三人称泄漏 | 自拍摄影映射 |
| **内容** | B | 核心事件是否明确，有没有价值和普适性 | 事件Schema |
| **人物行为** | C | 身份是否稳定，行为是否合理自然 | 行为链 |
| **物理兼容性** | J | 左右手/道具/空间是否有物理冲突 | 物理校验体系 |
| **行为链连贯性** | K | 动作是否有因果、情绪是否渐变、道具是否有逻辑 | 行为链连贯性 |
| **镜头** | D | 是否人物先动镜头后动，有没有漂浮感 | 自拍摄影映射 |
| **台词当下感** | E | 台词是否"正在发生"，不是回忆总结 | 行为链 |
| **打断与互动** | E+ | 有没有打断感、环境互动、反差感设计 | 行为链 |
| **环境** | F | 是否有空壳感，有没有自然生活痕迹 | 自拍摄影映射 |
| **场景切换** | I | 一段一场景，视觉不重复，场景即节奏 | 时间轴 |
| **声音** | G | 是否有环境底噪和行为声音，是否同步 | 时间轴 / Prompt编译 |
| **视觉** | H | 是否真实手机质感，有没有广告片感 | Prompt编译 |

> **E与E+拆分说明：** E检查台词的"时态"（当下感），E+检查台词的"质感"（打断/互动/反差）。两者独立打分，因为一段台词可能口语化但仍然是回忆式，也可能当下感够但缺少打断。

## 二、硬规则检查清单（必须100%通过）

> **硬规则 = 一票否决。任何一项不通过，直接打回重做，不进入评分环节。**

### 2.1 自拍关系硬规则（5项）

| 序号 | 检查项 | 检验标准 | 不通过的后果 |
|------|--------|----------|--------------|
| A1 | 人物自己拿手机 | 明确说明人物是摄影者，手机在人物手里 | 视角错误，整段重做 |
| A2 | 前置摄像头 | 明确是前置摄像头自拍视角 | 视角错误，整段重做 |
| A3 | 人物是摄影者 | 人物同时是主角+摄影者+叙述者 | 身份混淆，重做人物关系层 |
| A4 | 没有第三人称泄漏 | 任何描述中都不能出现第三人称摄影视角 | 视角泄漏，重做摄影层 |
| A5 | 没有独立摄影机 | 没有稳定器、云台、专业摄影机、航拍等 | 摄影方式错误，重做摄影层 |

**自检方法：**
1. 搜索Prompt中是否有"镜头""摄影机""画面向右"等被动表述
2. 每一个画面变化，都能找到对应的人物动作触发
3. 全程都是"人物做了什么，所以画面怎么样"的逻辑

## 三、结构化检查清单（检查完整性）

> 结构化检查 = 确保每个模块都完整，没有缺项。
> 不是打分制，而是"完整/不完整"的二元判断。

### 3.1 事件完整性（对应01-event-schema.md）

| 序号 | 检查项 | 完整标准 |
|------|--------|----------|
| B1 | 七要素完整 | 谁/时间/地点/做什么/遇到什么/什么变化/什么情绪，全部明确 |
| B2 | 一句话核心事件 | 能用一句话说清楚这条视频发生了什么 |
| B3 | 只有一个核心事件 | 没有信息堆积，没有多个并行主题 |
| B4 | 明确主价值类型 | 从7种价值类型中选了一个主价值 |
| B5 | 普适性转化完成 | 特殊事件已翻译成普通人能理解的情绪 |
| B6 | 前1秒留存锁 | 第一秒有有效信息，观众知道为什么值得继续看 |

---

### 3.2 行为链完整性（对应02-behavior-chain.md）

| 序号 | 检查项 | 完整标准 |
|------|--------|----------|
| C1 | 思考链完整 | 看到→感受→联想→犹豫→决定→行动→事后反应，有清晰的心理逻辑 |
| C2 | 行为链完整 | 看到→反应→行动→说话→再行动，不是一动不动说完 |
| C3 | 行为三要素 | 每个行为都有原因、有结果、有残留 |
| C4 | 微动作自然 | 加入了2-4个微动作，服务于情绪，不是机械添加 |
| C5 | 视线符合规则 | 不是一直盯镜头，说话时看、思考时移、行走时看前方 |
| C6 | 情绪有过程 | 触发→变化→表达→残留，不是瞬间切换情绪 |
| C7 | 情绪用行为描述 | 没有"悲伤""开心"等抽象词，全部是可观察的具体行为 |
| C8 | 台词自然 | 不是播音腔，有语速变化、停顿、换气等口语特征 |
| C9 | 语速合理 | 15秒55-70字以内，留出了行为和情绪的时间 |
| C10 | **台词当下感** | 台词是"正在发生"的当下体验，不是回忆/总结/旁白 |
| C11 | **打断感** | 至少1次被打断/突然想起/环境干扰，不是一条线说到底 |
| C12 | **环境互动** | 至少1次与NPC/物件/环境的互动，台词不是悬空说的 |
| C13 | **逻辑链通顺** | 台词之间的逻辑链通顺，没有跳跃（如前文说做幕僚，后文才能提在幕府认识某人） |
| C14 | **反差感设计** | 有古今对照/网络用语等反差设计（古代人物用现代口吻） |
| C15 | **固定开场词** | 有"家人们"之类的固定开场词，建立系列辨识度 |
| C16 | **台词密度安全线** | 15秒单段台词≤30字（竖屏≤25字），超限=必崩 |
| C17 | **NPC对话密度** | 每镜头对话NPC≤1个，背景不说话NPC≤2个 |
| C18 | **情绪状态化** | 情绪写"状态锚点"（眼眶泛红、嘴角自嘲），不写"渐变过程"（嘴角一点点上扬） |
| C19 | **微表情密度** | 微表情≤5条/段，负面约束≤3条 |

### 3.3 物理兼容性（对应15-physical-compatibility.md）

> **核心：物理冲突是崩坏的第一大源头。物理不通过，后面一切免谈。**

| 序号 | 检查项 | 通过标准 |
|------|--------|---------|
| J1 | 右手纯持机 | 右手永远只有持机功能，不做任何额外动作 |
| J2 | 左手状态明确 | 每段开头明确标注左手状态（摆臂/垂侧/持物/插兜/搭扶） |
| J3 | 左手状态稳定 | 一段内左手状态切换不超过1次 |
| J4 | 动作无肢体冲突 | 所有动作都过了"用哪只手？这只手有空吗？"的安检 |
| J5 | 道具不凭空出现 | 道具有明确的出现方式（开头就在/拿起来/别人递过来） |
| J6 | 道具不凭空消失 | 道具有明确的消失方式（一直在/放下去/送出画面） |
| J7 | 道具状态一致 | 道具的位置、数量、形态前后一致，不跳变 |
| J8 | 行走方向正确 | 身体朝前走、脸微微偏向镜头，不是面朝镜头倒退走 |
| J9 | 行走状态连续 | 没有"转回身体继续走"这种否定前态的描述 |
| J10 | 空间关系合理 | 人物与环境的前后左右关系一致，没有瞬移或穿模 |

---

### 3.4 行为链连贯性（对应02-behavior-chain.md 第十章）

> **核心：物理不冲突 ≠ 行为链连贯。连贯的行为链 = 真人会按这个顺序做这些事。**

| 序号 | 检查项 | 通过标准 |
|------|--------|---------|
| K1 | 动作有因果 | 每个动作之间都能说出"因为A所以B"，不是孤立列表 |
| K2 | 主动作密度合理 | 每5秒3-4个主动作，总动作节点不超6个 |
| K3 | 情绪是渐变的 | 不是开关式切换，有过程有残留，符合生理规律 |
| K4 | 道具有出现逻辑 | 不凭空出现/消失/换手/状态跳变 |
| K5 | 行走状态连续 | 走就是走，停就是停，状态变化有明确过渡 |
| K6 | 人设前后统一 | 行为符合人物性格和身份，前后不像两个人 |
| K7 | 符合真人逻辑 | 把自己代入人物，会按这个顺序做这些事 |
| K8 | 动作有主次 | 有1-2个核心主动作，其他是辅助微动，不是全都一样重要 |
| K9 | 行为链是闭环的 | 有开头（触发）→ 中间（发展）→ 结尾（收尾/残留） |

### 3.5 镜头因果完整性（对应03-selfie-camera-mapping.md）

| 序号 | 检查项 | 完整标准 |
|------|--------|----------|
| D1 | 人物先动，镜头后动 | 每个镜头变化都能找到对应的人物行为触发 |
| D2 | 镜头变化有原因 | 没有无原因的推拉摇移 |
| D3 | 自拍距离合理 | 通过手臂/身体/转动改变画面大小，没有数字变焦 |
| D4 | 构图自然 | 人物占60%-75%，头顶留白5%-10%，不是机械锁死 |
| D5 | 焦段选择合理 | 默认28mm，变化不超过2次，没有滥用长焦 |
| D6 | 真实感预算 | 有轻微的手部呼吸/身体带动/构图偏移等不完美 |
| D7 | 没有漂浮/云台感 | 画面稳定但不完美，不是机器般的稳定 |
| D8 | 手机不可见 | 手机不抢画面，没有明显的手臂/手指入画 |
| D9 | 画外事件规则 | 画外事件通过人物转动进入画面 |
| D10 | 没有追拍陌生人 | 手机不主动追拍其他人 |
| D11 | 环境不是B-roll | 环境通过人物自拍自然出现，没有独立空镜 |

### 3.4 时间轴完整性（对应04-shot-timeline.md）

| 序号 | 检查项 | 完整标准 |
|------|--------|----------|
| F1 | 总时长明确 | 有明确的总秒数 |
| F2 | 时间段划分合理 | 根据行为/情绪/空间/信息变化划分，不是机械均分 |
| F3 | 9要素完整 | 每个时间段都包含9个要素，没有缺项 |
| F4 | 两条动作链同步 | 叙事动作→摄影动作，因果关系清晰 |
| F5 | 切镜有触发原因 | 每个切镜都有行为/情绪/空间/信息变化触发 |
| F6 | 时间段内有自然变化 | 一个时间段内有多个画面变化，不是一个静态镜头 |
| F7 | 台词不堆镜头 | 不是一句台词换一个镜头 |
| F8 | 人物身份连续 | 五官/发型/服装/年龄等在不同时间段一致 |
| F9 | 场景连续 | 地点/光线/道具/空间关系一致（除非剧情明确变化） |

| F11 | **一段一场景** | 每个时间段对应一个独立场景，两个时间段不能在同一地点 |
| F12 | **视觉不重复** | 各场景的构图/背景/光线/色调都有明显差异 |
| F13 | **叙事驱动切换** | 场景变化由叙事推进驱动，不是为切而切 |
| F14 | **场景密度合理** | 15秒视频2-4个场景；10秒视频2-3个场景；不是1个场景到底 |
| F15 | **场景有烟火味** | 每个场景都有环境元素（人/物件/动植物/天气）增强生活气息 |

## 四、质量评分标准

> 评分制：每项1-10分
> 6分以下：不合格，需要重做
> 6-8分：合格，可以使用
> 9-10分：优秀，值得复用

### 4.1 A. 自拍关系（10分）

| 分数 | 标准 |
|------|------|
| 9-10 | 全程自拍逻辑严密，每一个画面变化都有清晰的人物行为触发，完全感觉不到"摄影机"的存在 |
| 7-8 | 自拍关系正确，大部分镜头变化有原因，偶尔有不够严谨的地方但不影响整体 |
| 5-6 | 自拍关系基本正确，但有几处镜头变化原因不够充分，需要加强因果关系 |
| 4及以下 | 有明显的第三人称泄漏或独立摄影机感，需要重做 |

### 4.2 B. 内容（10分）

| 分数 | 标准 |
|------|------|
| 9-10 | 核心事件极其清晰，价值感强，普适性高，倒叙钩子精准，名场面密度合理（20-35秒/个），类型搭配得当，看完让人久久不忘，愿意分享 |
| 7-8 | 核心事件明确，有明确价值，有钩子有名场面，能让人产生情绪或思考 |
| 5-6 | 有核心事件但不够聚焦，价值感一般，名场面偏少或节奏不对，看完印象不深 |
| 4及以下 | 事件模糊或信息堆积，没有钩子没有名场面，没有明确价值，观众不知道为什么要看 |

### 4.3 C. 人物行为（10分）

| 分数 | 标准 |
|------|------|
| 9-10 | 人物行为极其真实，像一个活人在生活，微动作自然，情绪有层次，有"情绪表里不一"的设计，外形随剧情阶段变化（服装/发型/精神状态），完全不像AI生成的 |
| 7-8 | 人物行为合理，有微动作，情绪有过程，外形有阶段变化，整体自然 |
| 5-6 | 人物行为基本合理，但微动作偏少或偏机械，情绪变化略生硬，外形变化不明显 |
| 4及以下 | 人物像在表演或念台词，行为不自然，外形一成不变，需要重做 |

### 4.4 J. 物理兼容性（10分）

> **检查核心：左右手/道具/行走/空间有没有物理冲突。物理冲突=必崩。**

| 分数 | 标准 |
|------|------|
| 9-10 | 全程物理逻辑严密，右手纯持机，左手状态明确且稳定，道具不凭空出现/消失，行走方向正确，空间关系合理，完全找不到物理矛盾 |
| 7-8 | 物理基本兼容，偶尔有不够严谨的地方但不影响整体，没有明显冲突 |
| 5-6 | 有几处物理冲突的隐患，需要修正（如左手动作偏多、道具出现逻辑不够清晰） |
| 4及以下 | 有明显的物理冲突（如左手既要持物又要挥手、倒着走路、道具凭空出现），必须修正 |

### 4.5 K. 行为链连贯性（10分）

> **检查核心：动作之间有没有因果关系？情绪是不是渐变的？真人会不会按这个顺序做这些事？**

| 分数 | 标准 |
|------|------|
| 9-10 | 行为链极其流畅，每个动作都有因果，情绪自然渐变，动作密度恰到好处，完全像一个真人在做事，观众感觉不到"这是设计好的" |
| 7-8 | 行为链基本连贯，动作有先后逻辑，情绪有过程，整体自然 |
| 5-6 | 行为链有些地方不够连贯，动作偏零散或密度不合理，情绪略生硬 |
| 4及以下 | 动作是孤立堆砌的，没有因果关系，情绪是开关式的，像机器人 |

### 4.6 D. 镜头（10分）

| 分数 | 标准 |
|------|------|
| 9-10 | 人物先动镜头后动的逻辑贯穿始终，真实感预算恰到好处，完全是"手机被带动"的感觉 |
| 7-8 | 镜头因果关系清晰，有真实感不完美，整体符合自拍逻辑 |
| 5-6 | 镜头基本符合自拍逻辑，但部分变化原因牵强，真实感不足 |
| 4及以下 | 有明显的漂浮感、云台感或第三人称视角，需要重做 |

### 4.5 E. 台词当下感（10分）

> **检查核心：台词是"正在发生"的当下体验，还是"站在终点回顾"的回忆总结。**

| 分数 | 标准 |
|------|------|
| 9-10 | 全程台词都是"正在经历此事"的当下感受，像直播连线，观众感觉和人物一起在现场 |
| 7-8 | 大部分台词是当下式，偶有总结性语句但不突兀 |
| 5-6 | 有当下感台词但回忆式句子偏多，时态混乱 |
| 4及以下 | 全程回忆式/旁白式/总结式，像在读日记，需要重写 |

**自检方法：**
- 逐句检查台词时态——是"正在做"还是"曾经做"？
- 回忆式特征词：我曾经、后来才知道、回想起、总结一下、现在想想
- 当下式特征词：师傅慢点、今天、哎你看、等会、我先

### 4.6 E+. 打断与互动（10分）

> **检查核心：台词有没有被打断的真实感、有没有与环境互动、有没有反差设计。**

| 分数 | 标准 |
|------|------|
| 9-10 | 有2次以上打断感（被环境干扰/突然想起/被打断），有1次以上环境互动（NPC/物件/环境反应），有古今反差设计，台词之间逻辑链通顺 |
| 7-8 | 有至少1次打断感+1次环境互动，逻辑通顺 |
| 5-6 | 有打断或互动但偏少，反差感不够明显 |
| 4及以下 | 台词一条线说到底，没有打断、没有互动、没有反差，像念稿 |

**打断感的三种形式：**
1. 被环境打断：说到一半被路过的声音/人/物件吸引注意力
2. 自己打断自己：突然想起另一件事，岔开话题后拉回
3. 被打断后拉回：被打断后说"哎我刚才说到哪了"

### 4.7 F. 环境（10分）

| 分数 | 标准 |
|------|------|
| 9-10 | 环境充满生活气息，有自然互动，感觉是一个真实有人生活的空间，不是布景 |
| 7-8 | 环境有细节，有生活痕迹，不是空壳 |
| 5-6 | 环境基本成立，但细节不够，略空 |
| 4及以下 | 环境像空壳或布景，完全没有生活气息，需要重做 |

### 4.8 G. 声音（10分）

| 分数 | 标准 |
|------|------|
| 9-10 | 声音层次丰富，与行为完全同步，让人有身临其境的感觉 |
| 7-8 | 有环境声、行为声和人声，整体同步自然 |
| 5-6 | 有声音设计，但层次不够丰富或同步不够精确 |
| 4及以下 | 声音缺失或像后期贴上去的，需要重做 |

### 4.9 H. 视觉（10分）

| 分数 | 标准 |
|------|------|
| 9-10 | 真实手机质感，皮肤纹理自然，光线真实，曝光有不完美但恰到好处，比随手拍好看但不像广告 |
| 7-8 | 整体是真实手机摄影质感，细节到位，没有明显的AI感 |
| 5-6 | 基本是手机质感，但部分细节偏塑料或偏广告感 |
| 4及以下 | 有明显的塑料皮肤、广告灯光或AI质感，需要重做 |

### 4.10 I. 场景切换（10分）

> **检查核心：视觉节奏不靠运镜带，靠场景切换带。一段一场景，场景即节奏。**

| 分数 | 标准 |
|------|------|
| 9-10 | 15秒2-4个场景，每个场景视觉差异明显，场景变化由叙事驱动，每个场景都有烟火味环境元素 |
| 7-8 | 有场景切换且视觉不重复，叙事逻辑清晰 |
| 5-6 | 有切换但场景差异不够明显，或个别场景偏空 |
| 4及以下 | 单场景到底，或场景跳跃无逻辑，需要回退时间轴重建 |

**场景切换检查方法：**
1. 列出所有时间段对应的场景名称
2. 检查是否有两个时间段在同一场景（有则不合格）
3. 检查场景之间是否有叙事推进（不是随机切）
4. 检查每个场景是否有环境元素（人/物件/动植物/天气）

## 五、回退机制

哪个维度不合格，回退到哪个模块重新生成。不是全部推倒重来，而是精准回退。

### 5.1 回退路径表

| 不合格维度 | 回退到哪个模块 | 重新做什么 |
|------------|----------------|------------|
| A. 自拍关系 | 03-selfie-camera-mapping.md | 重新设计自拍摄影映射，确保人物先动镜头后动 |
| B. 内容 | 01-event-schema.md | 重新提炼核心事件，加强价值和普适性 |
| C. 人物行为 | 02-behavior-chain.md | 重新设计行为链，加强微动作和情绪过程 |
| J. 物理兼容性 | 15-physical-compatibility.md | 逐动作做物理安检，修正左右手冲突和道具逻辑 |
| K. 行为链连贯性 | 02-behavior-chain.md 第十章 | 重新梳理行为链因果关系，调整动作密度和情绪渐变 |
| D. 镜头 | 03-selfie-camera-mapping.md | 重新设计镜头因果，加强真实感预算 |
| E. 台词当下感 | 02-behavior-chain.md 第七章7.5 | 把回忆式台词改写为当下式，逐句检查时态 |
| E+. 打断与互动 | 02-behavior-chain.md 第七章7.5 | 加入打断感、环境互动、反差设计，重写台词节奏 |
| F. 环境 | 03-selfie-camera-mapping.md | 重新设计环境呈现方式，增加生活互动 |
| G. 声音 | 04-shot-timeline.md / 05-prompt-compiler.md | 重新设计声音层次和同步 |
| H. 视觉 | 05-prompt-compiler.md | 重新调整视觉真实感描述和负面约束 |
| I. 场景切换 | 04-shot-timeline.md 第2.5章 | 重新设计场景切换节奏，确保一段一场景、视觉不重复 |

### 5.2 回退原则

1. **精准回退** —— 哪个模块的问题回退到哪个模块，不牵连其他
2. **保留成果** —— 合格的部分保留，只改不合格的部分
3. **逐层回退** —— 如果深层问题（如事件）导致表层问题（如镜头），先解决深层
4. **最多三轮** —— 同一维度最多回退三次，仍不合格则整体重新设计

### 5.3 回退流程

```
质量检查发现问题
    ↓
判断是哪个维度的问题
    ↓
判断是硬规则问题还是质量评分问题
    ↓
硬规则问题 → 直接回退对应模块重做
质量评分问题 → 6分以下回退，6分以上可通过但记录改进点
    ↓
回退后重新生成
    ↓
再次检查
    ↓
通过 → 输出最终结果
不通过 → 再次回退（最多三轮）
```

```

    ↓ 是

    ↓ 是

    ↓

    ↓

    ↓

    ↓
通过 → 输出最终Prompt
```
