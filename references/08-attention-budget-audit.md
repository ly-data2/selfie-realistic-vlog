# Seedance 注意力预算审核系统（V1.0）

> **系统定位**：定量分析 Seedance 2.0/2.5 提示词的注意力预算分配，识别瓶颈段、冗余指令和优化空间。
>
> **核心方法**：逐指令拆解 → 通道分层 → 预算估算 → 冗余识别 → 优化建议
>
> **适用范围**：写实风格、人物为主、对话/情绪类、无特效、15秒竖屏。其他场景需人工修正。
>
> **上游文档**：[00-four-track-framework.md](./00-four-track-framework.md) 四轨评估体系 — 注意力预算是技术手段，内容价值才是目的。删指令时先删"不服务于任何一轨的低价值指令"

## 一、指令通道分层体系

### 1.1 七大通道

| 通道 | 子层级 | 执行率 | 说明 |
|------|--------|--------|------|
| **视觉-物体层** | 人物外观、服装、道具、参考图绑定 | 高 | 模型最擅长的，参考图已含的文字重复消耗低 |
| **视觉-空间层** | 场景、光源方向、色温、前景遮挡、景深 | 高 | 环境空间信息，模型执行率高 |
| **动作层** | 走路、转头、拿东西、转身等 | 中 | 连续动作消耗中等，高爆发动作消耗翻倍 |
| **微表情层** | 嘴角上扬、眼眶泛红、皱眉等 | 低 | 执行率最低，加了不一定做得到 |
| **口型层** | 台词口型同步、嘴唇合拢、嘴唇紧闭 | 中 | 每句台词占用一条，是注意力预算的主要消耗项 |
| **视觉-约束层** | 画质要求、负面约束、风格描述 | 低 | 消耗预算但不直接产生画面，价值递减 |
| **音频通道** | 音效、配乐、环境音 | 不占画面预算 | 音频和画面是两条独立通道，互不干扰 |

### 1.2 执行率权重参考

| 层级 | 单条指令权重 | 说明 |
|------|-------------|------|
| 物体层（高） | 1.0 | 基础消耗单位 |
| 空间层（高） | 1.0 | 同物体层 |
| 动作层（中） | 1.2 | 比物体层略高 |
| 口型层（中） | 1.5 | 每句台词=1.5单位，是最大消耗项 |
| 微表情层（低） | 0.5 | 执行率低，实际消耗也低 |
| 约束层（低） | 0.3 | 价值递减，前3条有效，之后几乎没用 |
| 音频通道 | 0 | 完全不占画面预算 |

> **注意**：以上权重为经验估算，误差范围±30%。

## 二、逐段指令清单法

### 2.1 审核步骤

```
1. 把提示词拆成全局层 + 第1段 + 第2段 + 第3段……
    ↓
2. 每段内逐条列出所有指令，编号（如G1/G2/G3全局，1-1/1-2第一段）
    ↓
3. 给每条指令标注：通道 + 层级 + 权重
    ↓
4. 计算每段总权重 = Σ(单条权重)
    ↓
5. 乘以修正系数（竖屏×1.25）
    ↓
6. 与安全线对比，判定状态
```

### 2.2 安全线基准（15秒竖屏·写实风格）

| 预算占用率 | 状态 | 说明 |
|-----------|------|------|
| ≤ 60% | 健康 | 大量余量，可加细节 |
| 60-70% | 安全 | 正常水平，效果稳定 |
| 70-85% | 临界 | 可能有小问题，注意不要再加了 |
| 85-95% | 超载风险 | 大概率有指令丢失，建议删减 |
| ≥ 95% | 高风险 | 信息过载，模型可能放弃部分指令。不必然导致整体崩坏，取决于哪些指令被放弃 |

> **基准来源**：基于Seedance 2.5实测经验反推，非官方数据。不同模型版本可能有差异。

### 2.3 特殊惩罚系数

> **以下系数为粗略估算，误差范围±30%以上，不可作为精确计算依据。仅用于相对风险比较。**

| 情况 | 惩罚系数 | 说明 |
|------|---------|------|
| 竖屏9:16 | ×1.25 | 竖屏注意力效率约为横屏的80% |
| 3人说话 | ×1.3 | 多角色面部追踪+口型切换，额外消耗 |
| 有简单特效（光影/雾气） | ×1.4 | 特效消耗远高于普通动作 |
| 高爆发动作 | ×1.5 | 狂奔/跳跃等模型不擅长的动作 |
| 强风格化 | ×1.8 | 卡通/水墨等，所有指令执行率都下降 |

> **多个惩罚叠加用乘法**：竖屏+3人+简单特效 = ×1.25 ×1.3 ×1.4 = ×2.275

## 三、冗余指令识别法

### 3.1 五类高概率冗余

| 冗余类型 | 特征 | 典型例子 |
|---------|------|---------|
| **全局重复型** | 段内描写和全局层已声明的信息重复 | 全局写了"烛光右侧暖光"，每段又写"烛光照亮右半脸" |
| **自身重复型** | 同一段内说了两遍意思相同的话 | "转回面朝镜头"和"面朝镜头"连续出现 |
| **价值递减型** | 参考图已经包含的信息，文字重复描述 | "布料有自然褶皱，毛发分明"——超写实参考图天然有 |
| **低执行率型** | 模型执行率极低，写了也大概率不做 | "脚步轻盈"——竖屏中景里根本看不清脚步细节 |
| **冲突抵消型** | 两条指令互相矛盾，互相抵消 | "手持轻微晃动"和"画面稳定清晰" |

### 3.2 冗余删除优先级

1. **先删冲突抵消型** — 不删反而有害
2. **再删全局重复型** — 删了不损失画面信息
3. **再删自身重复型** — 同上
4. **再删价值递减型** — 损失极小，收益大
5. **最后删低执行率型** — 酌情处理

## 四、参考图省预算规则（V1.1新增）

> **核心原理：参考图能代替文字指令的地方，尽量用参考图。一张好图胜过500字描述。**

### 4.1 参考图与文字的分工边界

| 信息类型 | 参考图效率 | 文字效率 | 推荐方式 |
|---------|:---------:|:-------:|---------|
| **人物外貌**（脸型/五官/发型） | ⭐⭐⭐⭐⭐ | ⭐⭐ | 参考图为主，文字只补参考图没有的细节（如痣、疤痕） |
| **服装款式**（颜色/领口/袖口/裙型） | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | 参考图为主，文字补充身份属性 |
| **场景风格**（建筑/家具/整体调性） | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | 参考图定调，文字补动态元素（如风吹、火光） |
| **光线基调**（光源方向/色温/明暗对比） | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 参考图定大方向，文字精确指定（如"左前方暖光"） |
| **动作姿态**（走/坐/站/手势） | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 文字为主，参考图只做姿态参考 |
| **表情情绪**（微笑/愤怒/悲伤） | ⭐⭐ | ⭐⭐⭐⭐⭐ | 文字为主，参考图不能含表情（会干扰ID锁定） |
| **台词口型** | ❌ 完全不能 | ⭐⭐⭐⭐⭐ | 只能用文字 |
| **时序节奏**（先后顺序/时间间隔） | ❌ 完全不能 | ⭐⭐⭐⭐⭐ | 只能用文字 |

### 4.2 参考图省预算的计算方法

**基准：** 假设没有参考图时，描述一个角色外貌+服装需要5-8条文字指令。
有参考图后，这5-8条指令全部被图片代替，**文字只需要1条（"参考@图片1的形象作为XXX"）**。

**省预算公式：**
```
节省指令数 = (无参考图时的描述指令数) - 1（参考图引用）
```

**典型场景的省预算估算：**

| 场景 | 无参考图所需指令 | 有参考图所需指令 | 节省 |
|------|:---:|:---:|:---:|
| 主角外貌+服装 | 6-8条 | 1条 | 省5-7条 |
| NPC外貌+服装 | 4-6条 | 1条 | 省3-5条 |
| 场景+家具布置 | 5-7条 | 1条 | 省4-6条 |
| 合计（1主角+2NPC+1场景） | 20-27条 | 4条 | **省16-23条** |

> 这就是为什么"参考图+简洁文字"的组合远胜"纯文字长篇描述"——参考图是**注意力预算的超级放大器**。

### 4.3 参考图的正确用法（省预算最大化）

✅ **正确做法（省预算）：**
```
参考@图片1的形象作为蒲松龄（眉角有痣、下颌有浅痘印）
```
— 参考图管90%的外貌，文字只补10%的独特细节

❌ **错误做法（浪费预算）：**
```
参考@图片1的形象作为蒲松龄，面容清瘦、法令纹明显、须发半白、
穿旧青布长衫有补丁、戴黑色旧方巾、眼神疲惫、右手有老茧……
```
— 把参考图已经有的信息又用文字重写一遍，白白消耗预算

### 4.4 参考图配置的性价比排序

| 配置 | 数量 | 省预算效果 | 性价比 | 推荐度 |
|------|:---:|:---:|:---:|:---:|
| 主角大头照（面部锁定） | 1张 | 高 | 极高 | ⭐⭐⭐⭐⭐ 必加 |
| 场景参考图（环境定调） | 1张 | 高 | 高 | ⭐⭐⭐⭐ 推荐 |
| 主角全身照（服装锁定） | 1张 | 中 | 中 | ⭐⭐⭐ 有预算再加 |
| 主要NPC参考图 | 1张/人 | 中 | 中 | ⭐⭐⭐ NPC重要就加 |
| 道具参考图 | 1张/件 | 低 | 低 | ⭐⭐ 不重要就用文字 |
| 运镜参考视频 | 1段 | 低 | 低 | ⭐ 非必要 |

> **黄金配置：** 主角大头照 + 场景图 = 2张图，省10-14条指令预算，性价比最高。

### 4.5 参考图的反向成本（ID漂移风险）

参考图不是越多越好，太多反而有成本：

| 风险 | 说明 | 安全线 |
|------|------|--------|
| **ID漂移** | 多张相似人物图会让模型混淆，人物脸会串 | 同一角色建议≤2张核心参考图，标注清晰用途时更多不必然漂移 |
| **风格冲突** | 不同参考图的画风/色调不一致，画面会撕裂 | 所有参考图风格统一（都是写实/都是古风） |
| **注意力分散** | 参考图太多，模型每张图都分配注意力，反而每张都不精准 | 建议4-5张起步配置，多角色/多场景可扩展到7张。每张用途明确+标注禁止事项时不必然分散 |
| **重复绑定** | 同一段里多次"参考@图片X"，重复消耗 | 每段开头绑定一次即可，后续直接用名称 |

## 五、预算富裕段的优化方向

### 5.1 加什么最划算（按性价比排序）

| 候选指令类型 | 通道 | 预算消耗 | 效果提升 | 性价比 |
|-------------|------|---------|---------|--------|
| 环境光影变化 | 空间-环境层 | 1.0 | 画面动态感大幅提升 | ★★★★★ |
| 前景物品微动 | 环境-互动层 | 1.0 | 真实感提升明显 | ★★★★☆ |
| 收尾小动作 | 动作层 | 1.2 | 防止说完后画面呆滞 | ★★★★☆ |
| 环境互动反应 | 动作层 | 1.2 | 活人感提升 | ★★★☆☆ |
| 增加微表情 | 微表情层 | 0.5 | 情绪更细腻，但执行率低 | ★★☆☆☆ |
| 增加画质约束 | 约束层 | 0.3 | 边际效益递减 | ★☆☆☆☆ |

### 5.2 加指令原则

- **不同通道优先**：富裕段加指令，优先加和当前主要消耗不同通道的
  - 如果段内主要是口型层（台词多），就加空间层（光影）
  - 如果段内主要是动作层，就加微表情层（情绪）
- **每段最多加2-3条**：不要因为有预算就堆到满，留余量更稳
- **加了之后重新算预算**：确保加完后仍在70%安全线以内

## 六、局限性说明

### 6.1 三大内在局限

| 局限 | 说明 | 误差范围 |
|------|------|---------|
| **经验估算，不是精确测量** | 70%安全线、1.25系数、每条指令权重都是从外部反推的，不是模型内部实际数据 | ±15% |
| **忽略协同效应** | 按线性叠加算，但实际"油灯+古籍+长衫"三者互相强化，消耗低于3；"晃动+稳定"互相冲突，消耗远大于2 | ±20% |
| **对模型版本不敏感** | 安全线基于Seedance 2.5标定，2.0/3.0可能不同，大版本更新后需重新校准 | 版本差±30% |

### 6.2 需显著修正系数的场景（审核结果置信度降低）

1. **特效幻化类** — 白狐变人/粒子特效/魔法光效（特效消耗显著高于普通动作，具体倍数因特效类型而异）
2. **高爆发动作类** — 狂奔/跳跃/翻滚/打斗（动作强度差异巨大，线性模型失效）
3. **多人群像类** — 5人以上同框（每个人物都是追踪锚点，指数级增长）
4. **文字密集类** — 大量字幕/招牌/书籍文字（文字和口型共享语言通道，互相挤压）
5. **纯风景空镜类** — 没有人的纯场景（人物层全空，预算分配方式完全不同）
6. **强风格化类** — 卡通/水墨/油画/像素风（执行率体系完全不同）

### 6.3 使用建议

- 本系统是**辅助工具**，不是金标准
- 审核结果和直觉矛盾时，优先信直觉和实测
- 每次实际生成后，把结果和预算预估对比，不断校准你的个人基准
- 每换一个模型大版本，重新校准安全线和权重

**净效果**：删X条 + 加X条 = 净[增/减]X条，整体预算更[健康/紧张]

## 八、道具叙事省预算规则（V2.0新增 — 爆款拆解）

> **核心发现**：10万赞爆款视频不靠台词多，靠道具展示代替台词。每用1个道具动作替代1句解释性台词，省下约1条口型指令预算。

### 8.1 道具叙事 vs 台词叙事的预算对比

| 叙事方式 | 举例 | 通道 | 预算消耗 | 效果 |
|---------|------|------|:---:|------|
| **台词讲述** | "我中秀才了！" | 口型层 | 1条口型+1条声线 | 一般，观众听完就忘 |
| **道具展示** | 手指在榜单上划，停在"蒲松龄"三个字上 | 动作层 | 1条动作 | 强，画面即叙事，观众记住画面 |
| **台词+道具** | 边说话边用道具展示 | 口型+动作 | 1.5条（动作和口型并行） | 最强，双通道叙事 |

**关键结论：** 道具动作走"动作层"通道，不挤占口型层预算。用道具替代解释性台词=省口型预算=可以塞更多快嘴台词。

### 8.2 道具叙事的省预算计算

**典型场景：蒲松龄中秀才**

| 写法 | 口型指令 | 动作指令 | 总画面指令 | 预算占用 |
|------|:---:|:---:|:---:|:---:|
| 纯台词版："我中秀才了！" | 1条 | 0条 | 1条 | 高（口型通道压力） |
| 道具展示版：手指划榜单停在自己名字 | 0条 | 1条 | 1条 | 低（动作通道压力小） |
| 混合版：边说话边划榜单 | 1条 | 1条 | 2条 | 中（双通道并行，不冲突） |

**省预算效果：** 纯台词版→道具展示版，口型通道从1条降到0条，省下的口型预算可以用来塞更多快嘴台词。

### 8.3 每段至少1个道具展示动作的原则

**为什么每段都要有道具动作？**
1. **画面不空** — 纯说话画面会"死"，有道具动就"活"
2. **预算双通道** — 口型走口型通道，道具走动作通道，并行不冲突
3. **观众记忆锚点** — 观众记住的是画面，不是台词
4. **隐喻载体** — 道具可以承载隐喻（空白的贡生牌=五十年一场空）

### 8.4 道具选择优先级

| 道具类型 | 省预算效果 | 叙事效果 | 举例 |
|---------|:---:|:---:|------|
| 人物直接持有的道具 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 手握毛笔/攥推荐信/捧书稿 |
| 环境中的道具（需走过去/弯腰触碰） | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 从书橱抽书/弯腰捡纸团 |
| 背景道具（不触碰只做前景） | ⭐⭐⭐ | ⭐⭐⭐ | 破碗/药罐/喜果盘做虚化前景 |
| 纯装饰道具 | ⭐ | ⭐ | 桌上的花瓶/墙上的画 |

**优先选择人物直接持有的道具**——预算消耗最低（动作层），叙事效果最好（和人物绑定）。

## 九、打脸梗节奏模型（V2.0新增 — 爆款拆解）

> **核心发现**：10万赞爆款的每一段内部都有"立flag→打脸"的微循环，小波浪嵌套大波浪，观众情绪永远在动。

### 9.1 打脸梗的预算结构

**一个完整的打脸梗需要3个元素：**

| 元素 | 通道 | 预算消耗 | 作用 |
|------|------|:---:|------|
| Flag（立） | 口型层 | 1条 | 建立预期，让观众期待 |
| 转折（翻） | 口型层或画面层 | 1条 | 打破预期，制造反差 |
| 反应 | 表情层或动作层 | 0.5条 | 人物的真实反应，活人感 |

**总预算消耗：约2.5条**，但效果=1个完整的喜剧节拍。

### 9.2 打脸梗的三种实现方式

**方式A：台词内打脸（Flag和翻都在同一句台词里）**
```
"新手村三连鸡，排位赛稳了！" →（下一段落榜）"稳个屁"
```
预算：2条口型（flag句+打脸句），最省。

**方式B：台词+画面打脸（Flag用台词，翻用画面）**
```
"排位赛开启，冲上王者！" → 榜单纸角被风吹起，露出后面密密麻麻的落榜名字
```
预算：1条口型+1条画面动作，双通道，不冲突。

**方式C：画面内打脸（Flag和翻都用画面）**
```
手指在榜单上划→停在空白处→表情僵住
```
预算：1条动作+0.5条表情，最省，但信息量有限。

**推荐：** 优先用方式B（台词+画面），双通道叙事，预算最省效果最好。

### 9.3 每段内部节奏模型

**15秒段落的理想节奏结构：**

```
第0-5秒：立Flag（语速快，情绪高）
    ↓
第5-10秒：转折/互动（语速变慢或NPC插话，制造起伏）
    ↓
第10-15秒：打脸或金句收尾（语速最快或最慢，收在情绪极点）
```

**三种典型节奏曲线：**

| 曲线类型 | 第1段 | 第2段 | 第3段 | 适用场景 | 举例 |
|---------|------|------|------|---------|------|
| 快→慢→更快 | Flag | 互动停顿 | 冲顶打脸 | 意气风发段 | 科举天胡 |
| 慢→快→慢 | 铺垫 | 暴击 | 嘴硬收尾 | 打击失落段 | 首次落榜 |
| 中→快→最快 | 铺垫 | 加速 | 金句冲顶 | 吐槽爆发段 | 分家破产 |

**核心原则：** 每段的3个5秒段必须有节奏起伏（快慢变化），不能3段一样快或一样慢。

### 9.4 打脸梗的预算红线

**什么情况打脸梗会超预算：**
1. Flag和打脸都用长台词 → 口型通道2条长指令，超载
2. Flag和打脸都配大动作 → 动作通道2条大指令，超载
3. Flag段和打脸段之间没有停顿 → 节奏没有起伏，打脸没冲击力

**安全写法：**
1. Flag用短句（5-10字），打脸也用短句（5-10字），中间留停顿
2. Flag配小动作（挑眉/攥拳），打脸配大表情（僵住/苦笑/翻白眼）
3. Flag段和打脸段之间插入1个环境音或NPC互动，制造节奏停顿

## 十、快嘴Vlog模式的预算重分配（V2.0新增）

> **核心变化**：从"动作+场景+口型三足鼎立"改为"口型为主，动作极简，场景一次写完"。

### 10.1 快嘴模式的预算分配

| 通道 | 旧模式占比 | 快嘴模式占比 | 变化 |
|------|:---:|:---:|:---:|
| 口型层 | 30% | **50-60%** | ⬆️ 翻倍 |
| 动作层 | 25% | **10-15%** | ⬇️ 砍半 |
| 场景层 | 20% | **10%** | ⬇️ 砍半 |
| 表情层 | 15% | **15-20%** | 持平/略增 |
| 画质层 | 10% | **5%** | ⬇️ 砍半（参考图已含） |

**为什么口型预算可以翻倍：** 动作砍到极简（每段1-2个关键动作），场景只写一次不再重复，画质约束交给参考图——省下来的30%全部砸给口型。

### 10.2 快嘴模式的动作极简原则

**旧模式（动作多）：**
> 蒲松龄低头看了一眼襁褓中的婴儿，又抬头看向镜头，嘴角上扬一脸欣慰，右手轻轻搭在母亲肩上，表情认真带期待。

**快嘴模式（动作少）：**
> 蒲松龄面朝镜头说话，偶尔低头看一眼婴儿，嘴角上扬。

**原则：** 每段只写1-2个关键动作锚点（点头/摇头/挑眉/攥拳/翻白眼），其余交给"正常说话的自然状态"。

### 10.3 快嘴模式的气口节奏

**快嘴不等于一口气说完。** 句子内必须有"气口"（停顿），用标点控制节奏：

| 标点 | 停顿长度 | 作用 |
|------|:---:|------|
| `，`（逗号） | 0.1秒 | 短停顿，换气，信息单元切分 |
| `、`（顿号） | 0.05秒 | 并列词快速连读，几乎不停 |
| `——`（破折号） | 0.2秒 | 中停顿，强调/转折/卖关子 |
| `！`（感叹号） | 0.15秒 | 收尾重音，情绪落点 |

**错误写法（无气口）：**
```
{家人们新手村三连鸡县府道三试第一秀才解锁！}
```
✗ 23字一口气，像机关枪，观众听不清

**正确写法（有气口）：**
```
{家人们，新手村三连鸡——县、府、道三试第一，秀才，直接解锁！}
```
✓ 信息单元切开，快但不挤，有节奏感

### 10.4 快嘴模式的NPC互动原则

**快嘴模式下的NPC只能"一句话闪现"：**
- NPC说1句话（5-10字）就走，不占画面
- NPC只做1个小动作（瞥一眼/翻白眼/递东西），不做大动作
- NPC说完立刻消失（转身走开/缩回头/退出门框）

**为什么：** NPC的口型指令会占用口型通道预算，1句话=1条口型指令。NPC说2句=2条=口型通道超载。

**安全公式：** 主角快嘴（50-60字）+ NPC一句话（5-10字）= 总计55-70字，口型通道约2-3条指令，不超载。
