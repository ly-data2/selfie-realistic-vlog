# 分镜时间轴模板 Shot Timeline Template

> **版本**：V1.0
> **用途**：将事件DTO拆解为逐秒时间轴，每个时间段同时包含叙事动作与摄影动作两条动作链。
> **核心原则**：叙事动作 → 摄影动作。人物先动，手机后动。行为决定切镜。
> **使用说明**：按时间段复制以下模板，逐段填写。时间段长度根据行为变化自然划分，不强制均等。一个时间段内部可以包含多次景别/构图变化，但必须由人物行为触发。

---

## 时间段模板（单段）

```
### 第 X-Y 秒：[一句话概括这几秒发生了什么]

| 维度 | 内容 |
|------|------|
| **核心事件** | 这几秒发生了什么事？（事件推进的最小单位） |
| **人物行为** | 动作链：看到 → 反应 → 行动 → 说话 → 再行动（必须有因果，禁止机械动作） |
| **微动作** | 眨眼/吞咽/抿嘴/视线移动/吸气/手指动作/换重心/整理衣物等（少量、服务于真实，不为丰富而加） |
| **视线方向** | 看镜头 / 看旁边 / 看地面 / 看远处 / 看手中事物 / 看环境中某个具体东西 |
| **台词** | 具体文字 + 语速标注（自然/快/慢/轻声/含糊/带笑意等）。语速基准：1秒≈5汉字 |
| **自拍动作** | 手机如何被人物带动：手臂伸缩 / 身体转动 / 前倾后仰 / 行走 / 抬手 / 放下。必须说明"为什么动" |
| **画面变化** | 景别变化 / 构图变化 / 环境进入画面。起始景别→结束景别，变化原因来自人物行为 |
| **情绪变化** | 触发 → 变化 → 表达 → 残留。这几秒内情绪如何流动，结束时残留什么 |
| **环境元素** | 有什么自然互动：路人 / 动物 / 植物 / 物件。互动是自然发生的，不是为了丰富画面硬塞 |
| **声音** | 环境底噪 + 行为声音 + 台词 + 互动声音。声音必须同步行为 |
| **光线** | 环境光类型 + 曝光变化。允许手机自动曝光产生轻微变化 |
```

## 完整示例：15秒烤红薯Vlog分镜时间轴

> **场景**：下班路上，傍晚梧桐街道，女生买烤红薯想起前任
> **总时长**：15秒
> **焦段基准**：28mm（默认主力自拍焦段）

---

### 第 0-3 秒：闻到香味，转头发现烤红薯推车

| 维度 | 内容 |
|------|------|
| **核心事件** | 女生走在路上，闻到烤红薯香味，转头发现路边的推车 |
| **人物行为** | 往前走 → 闻到香味吸鼻子 → 脚步放慢 → 转头向右看 → 眼睛一亮 → 嘴角上扬 |
| **微动作** | 鼻翼微动（闻到香味）、眨眼两次、嘴角轻微上扬（半笑不笑的状态） |
| **视线方向** | 前1秒看前方走路 → 闻到后视线向右偏移 → 聚焦到烤红薯推车上 |
| **台词** | "（吸鼻子）哇，好香啊——"（第2秒起，语速自然，带点惊喜的尾音上扬） |
| **自拍动作** | 行走中持手机自拍 → 转头时身体先向右转 → 握手机的手跟着身体转动 → 镜头慢半拍向右偏移 |
| **画面变化** | 起始：胸部以上行走自拍（28mm，人物占65%）→ 结束：身体右转后，推车和老板进入画面右侧，人物略偏左 |
| **情绪变化** | 触发（闻到香味）→ 变化（疲惫→惊喜）→ 表达（眼睛亮了、嘴角上扬）→ 残留（笑意停在脸上） |
| **环境元素** | 梧桐落叶在脚边、远处有行人走过、烤红薯推车的烟在冒 |
| **声音** | 环境底噪：街道远处车声、风声、落叶沙沙 / 行为声音：脚步声、衣服摩擦声 / 台词声 / 互动声音：远处飘来的烤红薯炭火噼啪声 |
| **光线** | 傍晚夕阳暖金色，从侧后方照入，人物头发边缘有金色光晕，手机自动曝光轻微偏暖 |

---

### 第 3-7 秒：走到推车前，买烤红薯

| 维度 | 内容 |
|------|------|
| **核心事件** | 女生走到推车前，跟老板说要一个烤红薯，老板递过来 |
| **人物行为** | 加快脚步走过去 → 停下 → 低头看红薯 → 抬头对老板说话 → 伸手接红薯 → 换手捧住（因为烫） |
| **微动作** | 停下时身体轻微晃一下（惯性）、接红薯时手指缩了一下（烫到）、双手捧着时手指轻轻交替（散热） |
| **视线方向** | 走路时看前方 → 停下后低头看红薯 → 抬头看老板（画面外）→ 接红薯时看手中 |
| **台词** | "老板，来一个烤红薯，要最甜的那个。"（第4秒，自然语速，带笑意）/ "（吹气）好烫好烫——"（第6秒，语速偏快，孩子气的） |
| **自拍动作** | 向前行走带动手机上下轻微起伏 → 停下后手机稳定 → 接红薯时双手离开手机？不——手机举在面前，另一只手接红薯，手机角度略向下（因为低头看红薯） |
| **画面变化** | 行走近景 → 停下后推车更完整进入画面 → 低头时手机角度微向下，红薯和手进入画面下方 |
| **情绪变化** | 期待 → 满足（拿到红薯）→ 小小的抱怨（烫）→ 开心 |
| **环境元素** | 烤红薯推车细节（铁皮、炭火、烤焦的红薯皮）、老板的手递过来、旁边有另一个顾客的背影 |
| **声音** | 环境底噪：街道声 / 行为声音：脚步停下的摩擦声、纸袋窸窣声、接红薯时的触碰声 / 台词声 / 互动声音：老板模糊的回应声、炭火声 |
| **光线** | 推车上方灯泡的暖光 + 夕阳余晖，人物脸部光线更暖，烤红薯表面有光泽，手机自动曝光轻微调整 |

---

### 第 7-11 秒：剥开红薯皮，吃第一口，幸福感

| 维度 | 内容 |
|------|------|
| **核心事件** | 女生捧着红薯边走边剥，吃了第一口，满脸满足 |
| **人物行为** | 边走边剥红薯皮 → 热气冒上来 → 对着红薯吹气 → 咬了一口 → 闭上眼睛满足地嚼 → 点头 |
| **微动作** | 热气熏到眼睛眨了一下、咬的时候腮帮子鼓起来、嚼的时候点头（下意识的满足动作） |
| **视线方向** | 剥红薯时看手中 → 吹气时看红薯 → 咬的时候看红薯 → 嚼着嚼着视线回到镜头 |
| **台词** | "（嚼着，含糊）嗯……好甜。"（第9-10秒，语速慢，满足的，声音有点含糊因为嘴里有东西） |
| **自拍动作** | 行走中持手机 → 低头剥红薯时身体前倾 → 手机角度随之下倾 → 咬完抬头看镜头时手机回正 |
| **画面变化** | 胸部以上行走自拍 → 低头剥红薯时红薯和双手进入画面下方，人物占比减少 → 抬头回正后回到近景 |
| **情绪变化** | 期待（剥的时候）→ 满足感上升（咬下去）→ 幸福感峰值（嚼着点头）→ 笑意残留 |
| **环境元素** | 梧桐叶在身边飘落、地面落叶、远处遛狗的人影经过 |
| **声音** | 环境底噪：街道声、风声 / 行为声音：走路声、剥红薯皮的声音、吹气声、咀嚼声 / 台词声（含糊）/ 互动声音：远处狗叫一声 |
| **光线** | 夕阳侧光，红薯热气在光线下可见，人物脸部暖光，背景高光轻微过曝（手机计算摄影特征） |

---

### 第 11-15 秒：突然想起前任，笑容消失，沉默后对镜头笑

| 维度 | 内容 |
|------|------|
| **核心事件** | 吃着吃着突然想起前任，笑容收住，沉默两秒，然后自我解嘲地对镜头笑了一下 |
| **人物行为** | 还在嚼 → 突然停下咀嚼 → 视线慢慢移开 → 嘴角笑意消失 → 吸一口气 → 沉默两秒 → 重新看向镜头 → 自我解嘲地笑 → 轻声说话 |
| **微动作** | 喉结吞咽（把嘴里的东西咽下去）、吸一口气（鼻子微动）、视线移开时眼珠先动再转头、笑的时候嘴角只有一边上扬（苦笑） |
| **视线方向** | 看着镜头（满足状态）→ 突然移向左下方（回忆状态）→ 停留两秒 → 慢慢拉回镜头 |
| **台词** | （第11-13秒）沉默，只有呼吸声 / "（轻声笑）没事，就是……突然想起一个人。"（第12.5-14.5秒，语速慢，声音放轻，尾音有点飘）/ "（对着红薯吹了口气）走吧，回家。"（第14.5-15秒，很轻） |
| **自拍动作** | 行走中 → 停下脚步（情绪触发）→ 手机随之停下 → 视线移开时身体轻微向左转 → 手机被带动向左微偏 → 转回看镜头时手机回正 |
| **画面变化** | 行走近景 → 停下后画面稳定 → 情绪变化时人物略偏左（视线方向）→ 转回后人物回到中心，景别略微变紧（因为身体向前倾了一点，35mm感觉） |
| **情绪变化** | 触发（吃到某一口突然想起）→ 变化（满足→怅然，笑容消失）→ 表达（沉默、视线移开、轻声说话）→ 残留（苦笑，平静中带一点怅然） |
| **环境元素** | 风吹动梧桐叶、一片叶子从画面上方飘过、远处行人模糊走过 |
| **声音** | 环境底噪：风声、远处街道声（变得更安静，因为人物停下了）/ 行为声音：咀嚼声停止、吞咽声、吸气声、呼吸声变清晰 / 台词声（轻声）/ 互动声音：风吹树叶声 |
| **光线** | 夕阳暖光依旧，但情绪变化后画面整体感觉略微冷下来（不是实际色温变，而是人物状态带来的观感），手机曝光保持稳定 |

## 时间轴自检清单

- [ ] 每个时间段都有明确的核心事件，不是"人物在说话"这种空描述
- [ ] 行为链完整：看到 → 反应 → 行动 → 说话 → 再行动
- [ ] 微动作少量且有意义，不为丰富而加
- [ ] 视线自然变化，没有连续盯镜头
- [ ] 自拍动作都有原因（人物行为触发），没有无原因的镜头移动
- [ ] 画面变化由人物行为驱动，人物先动、手机后动
- [ ] 情绪有过程：触发 → 变化 → 表达 → 残留
- [ ] 环境互动自然，不是硬塞
- [ ] 声音分层且同步行为
- [ ] 光线基于真实环境光，允许轻微曝光变化
- [ ] 前约1秒出现有效信息（Retention Lock）
- [ ] 台词总量符合语速基准（1秒≈5字，实际推荐55-70字/15秒）
