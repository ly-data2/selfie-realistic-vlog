# 质量评分报告模板 Quality Score Template

> **版本**：V1.1
> **用途**：对生成的单人自拍Vlog视频（或Prompt）进行质量评估，识别问题并给出修改建议。
> **评分原则**：以真实感为最高准则，以自拍关系为底线。8大维度各10分，满分80分。硬规则为一票否决项。
> **两种评分模式**：
> - **Vlog长文模式**：评估完整分镜设计的质量
> - **Seedance模式**：评估单镜头Prompt的Seedance适配质量（更严格）
> **判定标准**：
> - 通过：总分 ≥ 64分（80%）且所有硬规则通过
> - 需修正：总分 48-63分 或 硬规则存在1-2项不通过（可修复）
> - 不通过：总分 < 48分 或 硬规则存在3项及以上不通过（或核心自拍关系被破坏）

## 零、Seedance模式专项检查（实测版）

> 如果是Seedance模式的Prompt评分，先做以下专项检查。任何一项不通过直接降为"需修正"。
>
> 基于Seedance 2.0实测经验总结。

| 检查项 | 通过/不通过 | 说明 |
|--------|------------|------|
| S1. 人物锚点前置 | | 人物身份描述在Prompt最开头吗？（权重最高位置） |
| S2. 人物描述完整 | | 包含五官、脸型、胡须/发型、年龄、服装、体型吗？ |
| S3. 场景道具锁定 | | 环境和关键道具也锁定了吗？（全程保持不变） |
| S4. 自拍视角声明 | | 明确声明了"人物本人手持手机前置自拍"吗？ |
| S5. 粗粒度时间 | | 时间区间是粗粒度的吗？（0–4秒这种，不要小数分段） |
| S6. 动作暗示镜头 | | 镜头变化是通过人物动作描述的吗？（不是"镜头向右移"） |
| S7. 负面单独放置 | | 负面提示词单独放最后了吗？（不混在正文里） |
| S8. 禁令精简 | | 没有重复禁止项、没有一大堆同类禁止吗？ |
| S9. 长度适中 | | 整体不会太长稀释人物权重吗？ |
| S10. 台词长度 | | 单句台词在15-20字以内吗？（唇形匹配上限） |

**Seedance专项评分（10分）：** 每通过1项得1分，满分10分。

**4大翻车点快速排查：**
- [ ] 精细时间码 → 有则扣分
- [ ] 抽象禁令堆叠 → 有则扣分
- [ ] 人物描述在中间/末尾 → 有则扣分
- [ ] 手机不可见描述太长 → 有则扣分

- 手机属于人物本人，人物在控制画面：1分（部分角度手臂位置不自然）

**评语**：自拍关系基本成立，但第8秒行走时画面过于稳定，缺乏手持呼吸感；第11秒情绪转折处画面变紧的因果关系不够清晰，需要强化"身体前倾→距离缩短→画面变紧"的动作链。

---

### B. 内容价值（得分：9/10）

- 核心事件明确：2分
- 有明确的价值类型：2分（情绪+共鸣）
- 有普适性主题：2分（旧物故人的余温，成年人的想念）
- 前1秒出现有效信息：2分（第1秒"好香啊"立即建立悬念）
- 没有无意义的信息堆积：1分（收尾"走吧回家"略微有点刻意）

**评语**：核心事件清晰，普适性强，观众容易代入。前1秒钩子有效。收尾可以更自然一些，不用刻意说"走吧回家"，也许直接往前走效果更好。
